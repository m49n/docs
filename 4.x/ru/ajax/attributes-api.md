# API атрибутов данных

API атрибутов данных позволяет отправлять AJAX-запросы без какого-либо JavaScript. Во многих случаях API атрибутов данных менее многословен, чем JavaScript API: тот же результат достигается меньшим количеством кода. Поддерживаются следующие AJAX-атрибуты данных:

Атрибут data-request | Описание
------------- | -------------
**data-request** | задаёт имя AJAX-обработчика.
**data-request-confirm** | задаёт сообщение подтверждения. Перед отправкой запроса отображается диалог подтверждения. Если пользователь нажимает кнопку Cancel, запрос не отправляется.
**data-request-redirect** | задаёт URL, на который будет перенаправлен браузер после успешного AJAX-запроса.
**data-request-url** | задаёт URL, на который отправляется запрос. По умолчанию: `window.location.href`.
**data-request-update** | задаёт список частичных представлений и элементов страницы (CSS-селекторов), которые нужно обновить. Формат: `partial: selector, partial: selector`. В некоторых случаях требуются кавычки, например: `'my-partial': '#myelement'`. Строка селектора должна начинаться с символа `#` или `.`, также можно добавить префикс `@` для добавления содержимого к элементу, `^` — для вставки в начало, `!` — для замены и `=` — для использования любого CSS-селектора.
**data-request-data** | задаёт дополнительные параметры POST, отправляемые на сервер. Формат: `var: value, var: value`. При необходимости используйте кавычки: `var: 'some string'`. Атрибут может располагаться на элементе, инициирующем событие, например на кнопке с атрибутом `data-request`, на ближайшем элементе к инициатору и на родительской форме. Фреймворк объединяет значения атрибутов `data-request-data`. Если атрибуты на разных элементах определяют параметры с одинаковым именем, применяется следующий приоритет: `data-request-data` инициирующего элемента, `data-request-data` ближайших родительских элементов, данные полей формы.
**data-request-query** | задаёт дополнительные параметры GET, отправляемые на сервер и добавляемые в текущую строку запроса URL.
**data-request-before-update** | задаёт JavaScript-код, выполняемый непосредственно перед обновлением содержимого страницы.
**data-request-success** | задаёт JavaScript-код, выполняемый после успешного завершения запроса. В этой функции доступна переменная `data`, содержащая данные ответа.
**data-request-error** | задаёт JavaScript-код, выполняемый при ошибке запроса. В этой функции доступна переменная `data`, содержащая данные ответа.
**data-request-complete** | задаёт JavaScript-код, выполняемый как при успешном завершении запроса, так и при ошибке. В этой функции доступна переменная `data`, содержащая данные ответа.
**data-request-cancel** | задаёт JavaScript-код, выполняемый, если пользователь прерывает запрос или отменяет его через диалог подтверждения.
**data-request-message** | отображает сообщение о прогрессе с указанным текстом во время выполнения запроса. Опция используется [функциями всплывающих сообщений](./features/flash-messages.md).
**data-request-loading** | задаёт CSS-селектор элемента, отображаемого во время выполнения запроса. Этот параметр можно использовать для показа индикатора загрузки AJAX. Возможность управляет видимостью элемента с помощью CSS-свойств `display: block` и `display: none`.
**data-request-progress-bar** | включает [индикатор прогресса](./features/loaders.md) при выполнении AJAX-запроса.
**data-request-form** | явно задаёт элемент формы, из которого нужно взять данные формы. Если не указано, используется ближайшая форма относительно элемента-триггера, включая сам элемент, если он является формой.
**data-request-flash** | при включении инструктирует сервер очистить и отправить любые всплывающие сообщения вместе с ответом. Опция используется [функциями всплывающих сообщений](./features/flash-messages.md).
**data-request-files** | при указании позволяет запросу принимать загрузку файлов через интерфейс `FormData`.
**data-request-download** | при указании допускает загрузку файлов с ответом `Content-Disposition`. Атрибут можно добавить без значения или задать имя скачиваемого файла.
**data-request-bulk** | при указании отправляет запрос в формате JSON для пакетных операций с данными.
**data-browser-target** | при совместном использовании с `data-request-download` вывод будет направлен в данное окно, например `_blank`.
**data-browser-validate** | при указании запускает проверку данных на стороне браузера до отправки запроса.
**data-browser-redirect-back** | при перенаправлении, если предыдущий URL браузера доступен, используется он вместо указанного URL перенаправления.
**data-auto-submit** | автоматически инициирует AJAX-запрос для элементов с атрибутом `data-request`. Запрос отправляется, когда окно браузера активно, с использованием [Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API). Необязательное значение атрибута задаёт интервал в миллисекундах, который фреймворк ждёт перед отправкой запроса.
**data-track-input** | можно применить к полю ввода текста, числа или пароля с атрибутом `data-request`. При указании поле автоматически отправляет AJAX-запрос, когда пользователь вводит данные. Необязательное значение атрибута задаёт интервал в миллисекундах, который фреймворк ждёт перед отправкой запросов.

Если для элемента задан атрибут `data-request`, элемент инициирует AJAX-запрос при взаимодействии с пользователем. В зависимости от типа элемента запрос инициируется следующими событиями:

Element | Событие
------------- | -------------
**Forms** | при отправке формы.
**Links, buttons** | при щелчке по элементу.
**Text, number, and password fields** | при изменении текста и только при наличии атрибута `data-track-input`.
**Dropdowns, checkboxes, radios** | при выборе элемента.

## Примеры использования

Вызвать обработчик `onCalculate` при отправке формы. Обновить элемент с идентификатором «result» частичным представлением **calcresult**.

```html
<form data-request="onCalculate" data-request-update="{ calcresult: '#result' }">
```

Запросить подтверждение перед отправкой запроса при щелчке по кнопке Delete.

```html
<form ... >
    ...
    <button data-request="onDelete" data-request-confirm="Are you sure?">Delete</button>
```

Перенаправить на другую страницу после успешного запроса.

```html
<form data-request="onLogin" data-request-redirect="/admin">
```

Показать всплывающее окно после успешного запроса.

```html
<form data-request="onLogin" data-request-success="alert('Yay!')">
```

Отправить параметр POST `mode` со значением `update`.

```html
<form data-request="onUpdate" data-request-data="{ mode: 'update' }">
```

Отправить параметр POST `id` со значением `7` через несколько элементов.

```html
<div data-request-data="{ id: 7 }">
    <button data-request="onDelete">Delete</button>
    <button data-request="onSave">Update</button>
</div>
```

Отправить параметр GET `page` со значением `6` в текущем запросе.

```html
<button data-request="onSetPage" data-request-query="{ page: 6 }">
    Page 6
</button>
```

Показать [всплывающее сообщение](./features/flash-messages.md) во время выполнения запроса.

```html
<button data-request="onUpdate" data-request-message="Loading...">
    Save Changes
</button>
```

Добавить к запросу [загрузку файлов](../../extend/services/request-input.md).

```html
<form data-request="onSubmit" data-request-files>
    <input type="file" name="photo" accept="image/*" />
    <button type="submit">Submit</button>
</form>
```

Добавить к ответу [загрузку файлов](../../extend/services/response-view.md).

```html
<button data-request="onDownloadFile" data-request-download>
    Download
</button>
```

Указать собственное имя файла и открыть загрузку в новом окне, например для предпросмотра PDF.

```html
<button
    data-request="onDownloadFile"
    data-request-download="sample.pdf"
    data-browser-target="_blank">
    Download
</button>
```
