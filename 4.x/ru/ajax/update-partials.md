# Обновление частичных представлений

Когда выполняется обработчик, он может подготовить частичные представления, которые обновляются на странице путём «вытягивания» или «выталкивания» и рендерятся с переданными переменными.

## Получение обновлений частичных представлений

Браузер клиента может запросить обновление частичных представлений с сервера при выполнении AJAX-запроса — это называется *получением обновления содержимого*.

Используя [`{% partial %}`](../../markup/tag/partial.md), следующий код рендерит частичное представление **mytime** внутри элемента `#myDiv` на странице при вызове [обработчика события](./handlers.md) `onRefreshTime`.

```twig
<div id="myDiv">
    {% partial 'mytime' %}
</div>
```

[API атрибутов данных](./attributes-api.md) использует атрибут `data-request-update`.

```html
<!-- Attributes API -->
<button
    data-request="onRefreshTime"
    data-request-update="{ mytime: '#myDiv' }">
    Go
</button>
```

[JavaScript API](./javascript-api.md) использует параметр конфигурации `update`:

```js
// JavaScript API
oc.request('#mybutton', 'onRefreshTime', {
    update: { mytime: '#myDiv' }
});
```

### Самообновляющиеся частичные представления

[`{% ajaxPartial %}`](../../markup/tag/ajax-partial.md) предназначен для рендеринга AJAX-частичных представлений.

```twig
{% ajaxPartial 'mytime' %}
```

При использовании этого тега содержимое автоматически оборачивается в контейнер, поэтому частичное представление можно обновлять только по имени. Просто передайте значение `true` вместо селектора контейнера.

```html
<button
    data-request="onRefreshTime"
    data-request-update="{ mytime: true }">
    Go
</button>
```

Можно использовать имя частичного представления `_self`, чтобы обновить частичное представление из него самого.

```js
{ _self: true }
```

::: tip
Подробнее о теге `{% ajaxPartial %}` см. в статье [Twig-тег AJAX Partial](../../markup/tag/ajax-partial.md).
:::

### Глобальные обновления частичных представлений

В некоторых случаях, например для [всплывающих сообщений](./features/flash-messages.md), требуется включать конкретное обновление частичного представления в каждый ответ. Чтобы объединить определение обновления со всеми AJAX-запросами, добавьте в раздел head страницы метатег `ajax-request-update` и задайте атрибуту content определение обновления.

```html
<head>
    <meta name="ajax-request-update" content="{ flash-messages: true }" />
</head>
```

## Определение обновления

Определение того, что нужно обновить, задаётся в виде объекта, похожего на JSON, где:

- левая часть (ключ) — **имя частичного представления**;
- правая часть (значение) — **целевой элемент**, который требуется обновить.

Следующий пример запросит обновление элемента `#myDiv` содержимым частичного представления **mypartial**.

```js
{ mypartial: '#myDiv' }
```

::: tip
Селектор должен начинаться с символа `#` или `.`.
:::

Несколько частичных представлений разделяются запятыми.

```js
{ firstpartial: '#myDiv', secondpartial: '#otherDiv' }
```

Если имя частичного представления содержит косую черту или дефис, важно заключить левую часть в кавычки.

```js
{ 'folder/mypartial': '#myDiv', 'my-partial': '#myDiv' }
```

Целевой элемент всегда указывается справа, поскольку в JavaScript им может быть HTML-элемент.

```js
{ 'folder/mypartial': document.getElementById('myDiv') }
```

### Добавление и вставка содержимого

Если перед селектором стоит символ `@`, содержимое, полученное с сервера, добавляется в конец элемента вместо замены текущего содержимого.

Если перед селектором стоит символ `^`, содержимое вставляется в начало.

```js
{ 'folder/append-partial': '@#myDiv' }

{ 'folder/prepend-partial': '^#myDiv' }
```

Также можно добавить атрибут `data-ajax-update-mode` целевому элементу.

```html
<div id="myDiv" data-ajax-update-mode="append"></div>

<div id="myDiv" data-ajax-update-mode="prepend"></div>
```

### Использование произвольных селекторов HTML

Если селектор начинается с символа `=`, можно указать любой произвольный HTML-селектор для выбора элемента.

```js
{ 'folder/append': '=[data-field-name="address"]' }
```

## Отправка обновлений частичных представлений

[AJAX-обработчики](./handlers.md) могут отправлять обновления содержимого в браузер клиента с сервера. Для отправки обновления обработчик возвращает массив, где ключом является HTML-элемент для обновления (простой CSS-селектор), а значением — содержимое.

::: aside
Имя ключа должно начинаться с идентификатора `#` или символа класса `.` — только тогда произойдёт обновление содержимого.
:::

Следующий пример обновит элемент страницы с идентификатором **myDiv** содержимым частичного представления **mypartial**. Обработчик `onRefreshTime` вызывает метод `renderPartial`, чтобы отрендерить частичное представление в PHP.

```php
function onRefreshTime()
{
    return [
        '#myDiv' => $this->renderPartial('mypartial')
    ];
}
```

## Передача переменных в частичные представления

В зависимости от контекста выполнения [AJAX-обработчик события](./handlers.md) предоставляет переменные частичным представлениям по-разному.

- Используйте `$this[]` в [PHP-секции](../themes/themes.md) страницы или макета.
- Используйте `$this->page[]` в [классе компонента](../themes/components.md).
- Используйте `$this->vars[]` в [бэкенде](../../extend/system/controllers.md).

Следующие примеры передают переменную **result** в частичное представление для каждого контекста:

```php
// From page or layout PHP code section
$this['result'] = 'Hello world!';

// From a component class
$this->page['result'] = 'Hello world!';

// From a backend controller or widget
$this->vars['result'] = 'Hello world!';
```

Затем это значение можно прочитать в частичном представлении через Twig:

```twig
<!-- Hello world! -->
{{ result }}
```
