# JavaScript API

JavaScript API мощнее, чем API атрибутов данных. Метод `oc.request` можно использовать с любым элементом внутри формы или с самой формой. Если метод применяется к элементу внутри формы, вызов перенаправляется на форму.

`oc.request` принимает целевой элемент и имя AJAX-обработчика в качестве первого и второго аргументов. Целевой элемент может быть строкой-селектором или элементом HTML. Например:

```html
<form onsubmit="oc.request(this, 'onProcess'); return false;">
    ...
```

Третий аргумент метода `oc.request` — объект параметров. Ниже перечислены параметры, специфичные для фреймворка October CMS.

Параметр | Описание
------------- | -------------
**update** | объект, задаёт список частичных представлений и элементов страницы (CSS-селекторы), которые нужно обновить: `{'partial': '#select'}`. Строка селектора должна начинаться с символа `#` или `.`, также можно добавить префикс `@` для добавления содержимого к элементу, `^` — для вставки в начало, `!` — для замены и `=` — для использования любого CSS-селектора.
**confirm** | строка подтверждения. Если указана, перед отправкой запроса отображается диалог подтверждения. Если пользователь нажмёт кнопку Cancel, запрос отменяется.
**data** | необязательный объект с данными, отправляемыми на сервер вместе с данными формы: `{var: 'value'}`. В этот объект также можно включить файлы для загрузки, используя [объекты `Blob`](https://developer.mozilla.org/en-US/docs/Web/API/Blob). Чтобы указать имя файла для объекта `Blob`, задайте свойство `filename` у самого объекта `Blob`. (Например: `var blob = new Blob(variable); blob.filename = 'test.txt'; var data = {uploaded_file: blob};`)
**query** | необязательный объект с данными, добавляемыми в текущую строку запроса URL.
**headers** | необязательный объект с заголовками, отправляемыми на сервер вместе с запросом.
**redirect** | строка с URL, на который будет перенаправлен браузер после успешного запроса.
**beforeUpdate** | функция-обработчик, выполняемая перед обновлением элементов страницы. Переменная `this` внутри функции указывает на содержимое запроса — объект с двумя свойствами: `handler` и `options`, соответствующими исходным параметрам `request()`.
**afterUpdate** | функция-обработчик, аналогичная `beforeUpdate`, но выполняется после обновления элементов страницы.
**success** | функция-обработчик, выполняемая при успешном запросе. Если этот параметр указан, он переопределяет стандартное поведение фреймворка: элементы не обновляются, обработчики `beforeUpdate` и `afterUpdate` не вызываются, события `ajax:update` и `ajax:update-complete` не инициируются. Чтобы вызвать стандартное поведение фреймворка, используйте `this.success(...)` внутри своей функции.
**error** | функция-обработчик, выполняемая при ошибке. По умолчанию отображается сообщение предупреждения. Если параметр переопределён, сообщение предупреждения отображаться не будет.
**complete** | функция-обработчик, выполняемая как при успехе, так и при ошибке.
**cancel** | функция-обработчик, выполняемая, если пользователь прерывает запрос или отменяет его через диалог подтверждения.
**form** | элемент формы, используемый как источник данных формы, отправляемых с запросом; может быть передан строкой-селектором или элементом формы.
**flash** | при значении true инструктирует сервер очистить и отправить любые всплывающие сообщения вместе с ответом. По умолчанию: `false`.
**files** | при значении true запрос принимает загрузку файлов с использованием интерфейса `FormData`. По умолчанию: `false`.
**download** | при значении true допускает загрузку файлов с ответом `Content-Disposition`. Если указана строка, можно задать имя скачиваемого файла. По умолчанию: `false`.
**bulk** | при значении true запрос отправляется в формате JSON для пакетных операций с данными. По умолчанию: `false`.
**browserValidate** | при значении true выполняет проверку данных на стороне браузера перед отправкой запроса. Применимо только к запросам, инициированным в контексте элемента `<form>`.
**browserRedirectBack** | при значении true и наличии перенаправления, если предыдущий URL из браузера доступен, используется он вместо указанного URL перенаправления. По умолчанию: `false`.
**message** | отображает сообщение о прогрессе с указанным текстом во время выполнения запроса. Опция используется [функциями всплывающих сообщений](./features/flash-messages.md).
**loading** | необязательная строка или объект, отображаемые во время выполнения запроса. Строка должна содержать CSS-селектор элемента, объект должен поддерживать функции `show()` и `hide()` для управления видимостью.
**progressBar** | включает [индикатор прогресса](./features/loaders.md) при выполнении AJAX-запроса.

Параметры **beforeUpdate**, **afterUpdate**, **success**, **error** и **complete** принимают функции с тремя аргументами: объект данных, полученный от сервера, код состояния HTTP и объект XHR.

```js
success: function(data, responseCode, xhr) { }
```

Можно переопределить часть логики запроса, передав новые функции в параметрах. Доступны следующие обработчики логики.

Обработчик | Описание
------------- | -------------
**handleConfirmMessage(message, promise)** | вызывается при запросе подтверждения у пользователя.
**handleErrorMessage(message)** | вызывается, когда нужно показать сообщение об ошибке.
**handleValidationMessage(message, fields)** | устанавливает фокус на первое неверное поле при использовании проверки данных.
**handleFlashMessage(message, type)** | вызывается, когда всплывающее сообщение передаётся с параметром **flash** (см. выше).
**handleRedirectResponse(url)** | вызывается, когда нужно перенаправить браузер в другое место.

## Примеры использования

Запросить подтверждение перед отправкой запроса `onDelete`.

```js
oc.request('#myform', 'onDelete', {
    confirm: 'Are you sure?',
    redirect: '/dashboard'
});
```

Выполнить обработчик `onCalculate` и вставить отрендеренное частичное представление **calcresult** в элемент страницы с CSS-классом **result**.

```js
oc.request('#myform', 'onCalculate', {
    update: { calcresult: '.result' }
})
```

Выполнить обработчик `onCalculate` и передать дополнительные данные.

```js
oc.request('#myform', 'onCalculate', { data: { value: 55 } })
```

Выполнить обработчик `onCalculate` и запустить собственный код до обновления элементов страницы.

```js
oc.request('#myform', 'onCalculate', {
    update: { calcresult: '.result' },
    beforeUpdate: function() { /* do something */ }
})
```

Выполнить обработчик `onCalculate` и при успешном завершении запустить собственный код после обновления элементов страницы.

```js
oc.request('#myform', 'onCalculate', {
    afterUpdate: function() { /* do something */ }
})
```

Использовать метод `oc.ajax`, чтобы выполнить запрос без элемента FORM.

```js
oc.ajax('onCalculate', {
    success: function() {
        console.log('Finished!');
    }
})
```

Выполнить обработчик `onCalculate` и при успехе запустить собственный код после завершения стандартной функции `success`.

```js
oc.request('#myform', 'onCalculate', {
    success: function(data) {
        this.success(data).done(function() {
            // ... do something after parent success() is finished ...
        });
    }
})
```

## Глобальные события AJAX

AJAX-фреймворк инициирует события на обновлённых элементах, элементе-триггере, форме и объекте window. События вызываются независимо от того, какой API использовался — API атрибутов данных или JavaScript API.

Дополнительные сведения доступны в свойстве `event.detail` обработчика события. Если не указано иначе, в детали обработчика входят объект `context`, объект `data`, полученный с сервера, `responseCode` и объект `xhr`.

Event | Описание
------------- | -------------
**ajax:before-send** | инициируется на объекте window перед отправкой запроса. Детали обработчика содержат объект `context`.
**ajax:before-update** | инициируется на объекте формы сразу после завершения запроса, но до обновления страницы.
**ajax:update** | инициируется на элементе страницы после обновления фреймворком.
**ajax:update-complete** | инициируется на объекте window после того, как фреймворк обновит все элементы.
**ajax:request-success** | инициируется на объекте формы после успешного завершения запроса. Обработчик получает 5 параметров: объект события, объект контекста, объект данных, полученный от сервера, строку статуса и объект XHR.
**ajax:request-error** | инициируется на объекте формы при ошибке запроса.
**ajax:error-message** | инициируется на объекте window при ошибке запроса. У обработчика есть деталь `message` с текстом ошибки, возвращённой сервером.
**ajax:confirm-message** | инициируется на объекте window, если указан параметр `confirm`. У обработчика есть деталь `message` с текстом, назначенным обработчику через параметр `confirm`. Также предоставляется деталь `promise`, позволяющая отложить или отменить результат — полезно при реализации собственной логики подтверждения или пользовательского интерфейса вместо стандартного диалога подтверждения JavaScript.

Эти события инициируются на элементе-триггере:

Event | Описание
------------- | -------------
**ajax:setup** | инициируется до формирования запроса. Детали обработчика содержат объект `context`, позволяющий изменять параметры через свойство `context.options`.
**ajax:promise** | инициируется непосредственно перед отправкой AJAX-запроса. Детали обработчика содержат объект `context`.
**ajax:fail** | инициируется в завершение, если AJAX-запрос завершается ошибкой.
**ajax:done** | инициируется в завершение, если AJAX-запрос выполнен успешно.
**ajax:always** | инициируется независимо от того, завершился ли AJAX-запрос ошибкой или успехом.

## Примеры использования

Выполнить код JavaScript при срабатывании события `ajax:update` на элементе.

```js
document.querySelector('#result').addEventListener('ajax:update', function() {
    console.log('Updated!');
});
```

Выполнить одиночный запрос, который показывает всплывающее сообщение с помощью обработчика логики.

```js
oc.ajax('onDoSomething', {
    flash: true,
    handleFlashMessage: function(message, type) {
        oc.flashMsg({ message: message, type: type });
    }
});
```

Применить конфигурацию ко всем AJAX-запросам глобально.

```js
addEventListener('ajax:setup', function(event) {
    const { options } = event.detail.context;

    // Enable AJAX handling of Flash messages on all AJAX requests
    options.flash = true;

    // Disable the progress bar for all AJAX requests
    options.progressBar = false;

    // Handle Error Messages by triggering a flashMsg of type error
    options.handleErrorMessage = function(message) {
        oc.flashMsg({ message: message, type: 'error' });
    };

    // Handle Flash Messages by triggering a flashMsg of the message type
    options.handleFlashMessage = function(message, type) {
        oc.flashMsg({ message: message, type: type });
    };
});
```

Использовать предоставленный `promise` из деталей события.

```js
addEventListener('ajax:confirm-message', function(event) {
    const { message, promise } = event.detail;

    // Prevent default behavior
    event.preventDefault();

    // Handle promise
    if (confirm(message)) {
        promise.resolve();
    }
    else {
        promise.reject();
    }
});
```

Анимировать элемент после завершения обновления конкретным AJAX-обработчиком.

```js
addEventListener('ajax:update-complete', function(event) {
    const { handler } = event.detail.context;

    // If the handler is either of the following
    if (['onRemoveFromCart', 'onAddToCart'].includes(handler)) {

        // Run an animation for 2 seconds
        var el = document.querySelector('#miniCart');
        el.classList.add('animate-shockwave');
        setTimeout(function() { el.classList.remove('animate-shockwave'); }, 2000);
    }
});
```
