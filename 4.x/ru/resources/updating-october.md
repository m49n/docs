# Обновление October CMS

Команда `october:update` запрашивает обновления у шлюза October, обновляет файлы ядра и плагинов, а затем запускает миграции базы данных.

```bash
php artisan october:update
```

## Миграция базы данных

Команда `october:migrate` выполняет миграции базы данных: создаёт таблицы и запускает скрипты наполнения, которые предоставляются системой и [историей версий плагинов](../plugin/updates.md). Команду миграции можно запускать многократно — каждая миграция или сидер выполняется лишь однажды, поэтому применяются только новые изменения.

```bash
php artisan october:migrate
```

Параметр `--rollback` отменяет все миграции, удаляя таблицы и данные. Используйте его осторожно. Для отладки отдельного плагина удобнее воспользоваться [командой обновления плагина](./installing-packages.md).

```bash
php artisan october:migrate --rollback
```

Параметр `--skip-errors` игнорирует исключения, возникающие в процессе миграции. Это полезно, когда таблицы уже существуют, но нужно применить информацию о версиях.

```bash
php artisan october:migrate --skip-errors
```

## Экспериментальные обновления

Чтобы получать экспериментальные (bleeding edge) обновления October CMS, измените параметр минимальной стабильности на `dev`.

```bash
composer config minimum-stability dev
```

После этого укажите ветку `develop` в файле composer.json. Например:

```json
"october/all": "dev-develop",
"october/rain": "dev-develop",
```

Ветка `develop` содержит изменения, которые ещё не опубликованы в стабильном канале. Там могут находиться свежие исправления и функции, но одновременно — незавершённые работы. Включать экспериментальные обновления не рекомендуется для боевых серверов.

::: tip
Запись `dev-develop` может потребоваться и для некоторых плагинов или тем.
:::

## Руководства по обновлению с v1, v2 и v3

Если вы обновляетесь с October CMS 3.0, изучите следующие материалы:

- [Руководство по обновлению до October CMS v4.0](https://octobercms.com/support/article/rn-39)

Если вы начинаете с October CMS 2.0, изучите эти руководства, а затем переходите к материалам выше.

- [Руководство по обновлению до October CMS v3.0](https://octobercms.com/support/article/rn-30)
- [Стабильный релиз October CMS v3.1](https://octobercms.com/support/article/rn-32)

Если отправной точкой является October CMS 1.0, ознакомьтесь со следующими статьями перед тем, как двигаться дальше:

- [Руководство по обновлению до October CMS v2.0](https://octobercms.com/support/article/rn-13)
- [Стабильный релиз October CMS v2.1](https://octobercms.com/support/article/rn-27)
