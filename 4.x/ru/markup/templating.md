# Шаблоны

October CMS расширяет [язык шаблонов Twig](https://twig.symfony.com/doc/) набором функций, тегов, фильтров и переменных. Эти расширения позволяют использовать возможности CMS и получать сведения об окружении страницы внутри шаблонов.

## Переменные

Переменные шаблона выводятся на странице с помощью *двойных фигурных скобок*.

```twig
{{ variable }}
```

Переменные также могут представлять *выражения*.

```twig
{{ isAjax ? 'Yes' : 'No' }}
```

Переменные можно конкатенировать символом `~`.

```twig
{{ 'Your name: ' ~ name }}
```

October предоставляет глобальные переменные в переменной `this`, они перечислены в разделе **Переменные**.

## Теги

Теги — уникальная возможность Twig, они обрамляются символами `{% %}`.

```twig
{% tag %}
```

Теги позволяют более наглядно описывать логику шаблона.

```twig
{% if stormCloudComing %}
    Stay inside
{% else %}
    Go outside and play
{% endif %}
```

Тег `{% set %}` можно использовать для задания переменных внутри шаблона.

```twig
{% set activePage = 'blog' %}
```

Теги допускают множество вариантов синтаксиса, они перечислены в разделе **Теги**.

## Фильтры

Фильтры выступают модификаторами переменных для отдельного случая и применяются с помощью *символа вертикальной черты* и имени фильтра.

```twig
{{ 'string'|filter }}
```

Фильтры могут принимать аргументы как функция.

```twig
{{ price|currency('USD') }}
```

Фильтры можно применять последовательно.

```twig
{{ 'October Glory'|upper|replace({'October': 'Morning'}) }}
```

Фильтры перечислены в разделе **Фильтры**.

## Функции

Функции позволяют выполнить логику, а возвращаемый результат выступает как переменная.

```twig
{{ function() }}
```

Функции могут принимать аргументы.

```twig
{{ dump(variable) }}
```

Функции перечислены в разделе **Функции**.

## Логика доступа

::: v-pre
Самое важное, что нужно знать о Twig, — это то, как он обращается к слою PHP. Для удобства запись `{{ foo.bar }}` выполняет следующие проверки на объекте PHP:
:::

1. Проверяет, что `foo` — массив и `bar` является допустимым элементом.
1. Если нет и `foo` — объект, проверяет, что `bar` — допустимое свойство.
1. Если нет и `foo` — объект, проверяет, что `bar` — допустимый метод (даже если bar — конструктор; в этом случае используйте `__construct()`).
1. Если нет и `foo` — объект, проверяет, что `getBar` — допустимый метод.
1. Если нет и `foo` — объект, проверяет, что `isBar` — допустимый метод.
1. Если ни одно условие не выполняется, возвращает значение `null`.

## Неподдерживаемые возможности

Некоторые возможности Twig не поддерживаются в October CMS. Они перечислены ниже вместе с эквивалентом.

Тег | Эквивалент
------------- | -------------
`{% extend %}` | Используйте [макеты](../cms/themes/layouts.md) или `{% placeholder %}`
`{% include %}` | Используйте `{% partial %}` или `{% content %}`
