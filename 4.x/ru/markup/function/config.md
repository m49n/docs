# config()

Получить значения конфигурации можно через вспомогательную функцию `config()`. Она возвращает текущее значение из хранилища конфигурации.

Следующий пример выведет значение, сохранённое в `app.locale`.

```twig
{{ config('app.locale') }}
```

Эквивалент на PHP выглядит так:

```php
<?= Config::get('app.locale') ?>
```

## env()

Дополняющая функция `env()` позволяет обращаться к переменным окружения.

Следующий пример выведет значение, сохранённое в переменной окружения `APP_ENV`. Второй аргумент — значение по умолчанию, если ключ окружения отсутствует.

```twig
{{ env('APP_ENV', 'production') }}
```

Эквивалент на PHP выглядит так:

```php
<?= env('APP_ENV', 'production') ?>
```

::: warning
Функции `config()` и `env()` недоступны при [включённом безопасном режиме](../../setup/configuration.md).
:::
