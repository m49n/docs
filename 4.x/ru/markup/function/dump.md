# dump()

Функция `dump()` выводит сведения о переменной шаблона. Это полезно при отладке шаблонов, которые ведут себя не так, как ожидается.

```twig
{{ dump(user) }}
```

Можно передать несколько переменных в дополнительных аргументах:

```twig
{{ dump(user, categories) }}
```

Если аргументы не переданы, будут выведены все переменные текущего контекста:

```twig
{{ dump() }}
```

## d()

Функция `d()` — сокращённый синтаксис для отладки в Twig. Она отображает меньше деталей об объекте, но позволяет увидеть значения сразу. Переменные выводятся рекурсивно так же, как в PHP-функции `dd()`.

```twig
{{ d(user) }}
```

Можно передать несколько переменных аргументами.

```twig
{{ d(variable1, variable2) }}
```

Функция `dd()` — альтернативный вариант, который выводит значения и завершает выполнение.

```twig
{{ dd('dump and die') }}
```

::: warning
Функции `dump()` и `d()` недоступны при [включённом безопасном режиме](../../setup/configuration.md).
:::
