# carbon()

Функция `carbon()` позволяет работать с датами и временем в Twig, используя [объект Carbon](https://carbon.nesbot.com/docs/) и все доступные методы.

Переданное значение автоматически конвертируется в текущий часовой пояс согласно настройке `cms.timezone`, которую можно задать через [определение сайта](../../cms/resources/multisite.md).

Чтобы вывести текущее значение даты и времени:

```twig
{{ carbon('now') }}
```

Чтобы задать собственное значение:

```
{{ carbon('2024-01-01 02:13:23') }}
```

## format

Метод `format` позволяет применять различные форматы.

```twig
Meeting starts at {{ carbon(event.start_at).format('H:i') }} in Johannesburg.
```

## formatLocalized

Форматирует локальное время/дату в соответствии с настройками локали; эквивалент функции `strftime` в PHP.

```twig
{{ carbon(article.created_at).formatLocalized('%d.%m.%Y %H:%M:%S') }}
```

## diffForHumans

Метод `diffForHumans` выводит разницу между датой и текущим моментом в удобочитаемом виде.

```twig
{{ carbon(post.published_at).diffForHumans() }}
```

## URL для обхода кэша

Форматирование можно использовать для построения URL, обновляющегося при каждой загрузке.

```twig
// Outputs: 10.26.22.22.53.31
carbon('now').format('m.d.y.H.i.s')
```

Затем сформируй URL следующим образом.

```twig
<img src="{{ 'assets/images/image_file.jpg'|theme }}?{{ carbon('now').format('m.d.y.H.i.s') }}" alt="" />
```

## Шпаргалка по форматам даты

При форматировании дат и времени доступны следующие значения. Эти коды можно использовать с методом `format`.

Формат дня | Пример
----------- | -------------
`d` | 01…31
`D` | Mon…Sun
`j` | 1…31
`l` | Sunday…Saturday
`N` | 1 (Monday)…7 (Sunday)
`S` | st, nd, rd, th
`w` | 0 (Sunday)…6 (Saturday)
`z` | 0…365

Формат недели | Пример
------------ | -------------
`W` | 42 (42-я неделя года)

Формат месяца | Пример
------------- | -------------
`F` | January…December
`m` | 01…12
`M` | Jan…Dec
`n` | 1…12
`t` | 28…31

Формат года | Пример
------------ | -------------
`Y` | 1985, 1991, 2012, 2014, …
`y` | 85, 91, 12, 14, …
`o` | То же, что `Y`, но на основе недели
`L` | 1 (високосный год), иначе 0

Формат времени | Пример
------------ | -------------
`a` | am или pm
`A` | AM или PM
`B` | 000…999
`g` | 1…12
`G` | 0…23
`h` | 01…12
`H` | 01…23
`i` | 00…59
`u` | 123456 (микросекунды)

Формат часового пояса | Пример
---------------- | -------------
`e` | UTC, GMT, Atlantic/Azores
`I` | 1 (летнее время), иначе 0
`O` | +0200
`P` | +02:00
`T` | EST, MDT, …
`Z` | -43200…50400 (смещение)

Формат даты и времени | Пример
----------------- | -------------
`c` | 2004-02-12T15:19:21+00:00
`r` | Thu, 21 Dec 2000 16:01:07 +0200
`U` | Секунды с 1 янв 1970 00:00:00 GMT
