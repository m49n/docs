# abort()

Функция `abort()` прерывает успешный путь обработки запроса, меняя код и содержимое ответа. Это полезно, когда нужно задать пользовательский HTTP-код или показать страницу 404, если запись не найдена.

```twig
{% if record.notFound %}
    {% do abort(404) %}
{% endif %}
```

Чтобы установить код ответа и отобразить страницу 404 темы, укажи код `404`.

```twig
{% do abort(404) %}
```

Любой другой код покажет страницу ошибки, можно передать сообщение вторым аргументом.

```twig
{% do abort(403, 'Access Denied') %}
```

Чтобы установить HTTP-код в заголовке, не меняя содержимое ответа, передай вторым аргументом `false`.

```twig
{% do abort(404, false) %}
```
