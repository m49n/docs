# response()

Функция `response()` предотвращает отображение страницы и возвращает ответ, обычно в формате JSON.

```twig
{% do response({ foo: 'bar' }) %}
```

Этот вызов вернёт ответ с типом содержимого `application/json`.

```json
{
    "foo": "bar"
}
```

По умолчанию используется код состояния `200`. Можно указать другой код, передав его вторым аргументом.

```twig
{% do response('Bad Request', 400) %}
```

Пользовательские заголовки можно передать третьим аргументом.

```twig
{% do response('Bad Request', 400, {'X-Failure-Reason': 'Not wearing shoes'}) %}
```
