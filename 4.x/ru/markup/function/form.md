# form()

Функции с префиксом `form_` выполняют полезные операции с формами. Вспомогательная функция напрямую отображается на PHP-класс `Form` и его методы. Например:

```twig
{{ form_close() }}
```

Эквивалент на PHP выглядит так:

```php
<?= Form::close() ?>
```

> **Примечание.** Методы в формате *camelCase* следует записывать в формате *snake_case*.

## form_open()

Выводит стандартный открывающий тег `<form>` вместе со скрытыми полями `_session_key` и `_token` для защиты от CSRF. Если используется [AJAX-фреймворк](../../ajax/introduction.md), рекомендуется применять `form_ajax()`.

```twig
{{ form_open() }}
```

Атрибуты можно передать первым аргументом.

```twig
{{ form_open({ class: 'form-horizontal' }) }}
```

Результат будет таким:

```html
<form class="form-horizontal">
```

Можно использовать специальные опции вместе с атрибутами.

```twig
{{ form_open({ request: 'onUpdate' }) }}
```

Функция поддерживает следующие опции:

Опция | Описание
------------- | -------------
**method** | Метод запроса. Соответствует атрибуту тега FORM **method**. Например: POST, GET, PUT, DELETE
**request** | Имя обработчика, который выполнится на сервере при отправке формы. Подробнее об обработчиках см. в статье [AJAX-обработчики](../../ajax/handlers.md).
**url** | URL, на который отправляется форма. Соответствует атрибуту тега FORM **action**.
**files** | Определяет, отправляет ли форма файлы. Допустимые значения: **true** и **false**.
**model** | Объект модели для привязки формы к модели.

## form_ajax()

Выводит открывающий тег формы с поддержкой AJAX. Первый параметр функции `form_ajax()` — имя AJAX-обработчика. Обработчик можно определить в PHP-разделе макета или страницы, а также в компоненте. Подробнее об AJAX см. в статье [AJAX-фреймворк](../../ajax/introduction.md).

```twig
{{ form_ajax('onUpdate') }}
```

Атрибуты можно передать вторым аргументом.

```twig
{{ form_ajax('onSave', { class: 'form-horizontal'}) }}
```

Результат будет таким:

```html
<form data-request="onSave" class="form-horizontal">
```

Можно использовать специальные опции вместе с атрибутами.

```twig
{{ form_ajax('onDelete', { data: { id: 2 }, confirm: 'Really delete this record?' }) }}

{{ form_ajax('onRefresh', { update: { statistics: '#statsPanel' } }) }}
```

> **Примечание.** Если нужно передать псевдоним компонента с помощью `__SELF__` в `form_ajax()`, сначала соберите нужную строку вне вызова функции. Пример:

```twig
{% set targetPartial = "'" ~ __SELF__ ~ "::statistics': '#statsPanel'" %}
{{ form_ajax('onUpdate', { update: targetPartial }) }}
```

Функция поддерживает следующие опции:

Опция | Описание
------------- | -------------
**success** | Строка JavaScript, выполняемая при успешном ответе.
**error** | Строка JavaScript, выполняемая при ошибке.
**confirm** | Сообщение подтверждения, отображаемое перед отправкой запроса.
**redirect** | Перенаправление на указанный URL при успешном ответе.
**update** | Массив частичных представлений для обновления при успехе в формате { 'partial': '#element' }.
**data** | Дополнительные данные для запроса в формате { 'myvar': 'myvalue' }.

## form_close()

Выводит стандартный закрывающий тег формы. Этот тег предусмотрен для единообразия использования.

```twig
{{ form_close() }}
```

Результат будет таким:

```html
</form>
```

## Передача атрибутов генерируемому элементу

Дополнительные атрибуты можно передать в `Form::open()`, указав массив имён и значений, которые будут добавлены в итоговый элемент `<form>`.

```php
<?= Form::open(array('id' => 'example', 'class' => 'something')) ?>
    // ..
<?= Form::close() ?>
```

Результат будет следующим:

```html
<form method="POST" action="" accept-charset="UTF-8" id="example" class="something">

</form>
```
