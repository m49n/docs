# redirect()

Функция `redirect()` перенаправляет ответ на URL или страницу темы.

Чтобы выполнить перенаправление, передай первым аргументом пункт назначения — имя CMS-страницы или URL-адрес.

```twig
{% if record.notFound %}
    {% do redirect('404') %}
{% endif %}
```

Параметры страницы можно передать вторым аргументом.

```twig
{% do redirect('docs', { slug: 'home' }) %}
```

Чтобы перенаправить на URL, передай полный адрес вместо имени страницы.

```twig
{% do redirect('https://octobercms.com') %}
```

Чтобы указать код перенаправления, например `302` (временное) или `301` (постоянное), используй второй или третий аргумент. По умолчанию применяется код `302`.

```twig
{% do redirect('https://octobercms.com', 301) %}
```
