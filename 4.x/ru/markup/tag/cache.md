# {% cache %}

Тег `{% cache %}` используется для кеширования содержимого страницы или частичного представления. Ключ кеша, указанный в теге, может быть любой строкой, кроме зарезервированных символов `{}()/\@:;`.

```twig
{% cache "cache key" %}
    Кеш навсегда
{% endcache %}
```

Чтобы задать время жизни кеша, укажи модификатор `ttl` со значением в минутах.

```twig
{% cache "cache key" ttl(5) %}
    Кеш на 5 минут
{% endcache %}
```

Хорошая практика — включать в ключ полезную информацию, чтобы кеш автоматически сбрасывался при необходимости:

- Присвой каждому кешу уникальное имя и структурируй его по аналогии с шаблонами.
- Включи целое число, которое увеличивается при изменении кода шаблона (это инвалидирует существующие кеши).
- Добавь уникальный ключ, обновляемый при изменении переменных, используемых в шаблоне.

Так можно использовать дешёвую проверку ключа кеша (например, время обновления модели), чтобы закешировать более затратное содержимое.

```twig
{% cache "blog_post;v1;" ~ post.id ~ ";" ~ post.updated_at %}
    <!-- Здесь дорогая разметка записи блога -->
{% endcache %}
```

Важно помнить, что тег cache создаёт новую область видимости переменных. Изменения локальны для фрагмента шаблона.

```twig
{% set count = 1 %}

{% cache "cache key" ttl(5) %}
    {# Область видимости отличается от переменной count вне тега cache #}
    {% set count = 2 %}
    Некоторая логика
{% endcache %}

{# Вывод: 1 #}
{{ count }}
```
