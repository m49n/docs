# {% placeholder %}

Тег `{% placeholder %}` выводит содержимое плейсхолдера, который обычно [используется в макетах](../../cms/themes/layouts.md). Этот тег возвращает содержимое, добавленное тегом `{% put %}`, или (необязательно) значение по умолчанию.

```twig
{% placeholder name %}
```

Затем в любой странице или частичном представлении можно внедрить содержимое в этот плейсхолдер.

```twig
{% put name %}
    <p>Поместите этот текст в плейсхолдер name</p>
{% endput %}
```

## Замена содержимого

По умолчанию `{% put %}` добавляет содержимое к плейсхолдеру. Чтобы заменить содержимое полностью, укажи атрибут `replace`.

```twig
{% put name replace %}
    <p>Заменить всё содержимое на этот текст</p>
{% endput %}
```

## Повторные вызовы

Иногда тег `{% put %}` вызывается внутри частичного представления, чтобы подключить ресурсы на странице. Если такое частичное представление вставить несколько раз на одной странице, скрипт добавится повторно. Атрибут `once` гарантирует, что содержимое задаётся не более одного раза за шаблон. В качестве ключа кэша используется имя шаблона CMS.

```twig
{% put scripts once %}
    <script src="https://cdnjs.cloudflare.com/ajax/libs/tiny-slider/2.9.2/min/tiny-slider.js"></script>
{% endput %}
```

## Содержимое плейсхолдера по умолчанию

У плейсхолдеров может быть содержимое по умолчанию, которое страница может дополнить или заменить. Если на странице не определён тег `{% put %}` для плейсхолдера с содержимым по умолчанию, будет отображено стандартное содержимое. Пример определения плейсхолдера в макете:

```twig
{% placeholder sidebar default %}
    <p><a href="/contacts">Свяжитесь с нами</a></p>
{% endplaceholder %}
```

Страница может добавить дополнительное содержимое. Тег `{% default %}` указывает место, где выводится содержимое по умолчанию. Если тег не используется, стандартный контент полностью заменяется.

```twig
{% put sidebar %}
    <p><a href="/services">Услуги</a></p>
    {% default %}
{% endput %}
```

## Проверка наличия плейсхолдера

В макете можно проверить, определено ли содержимое плейсхолдера, используя функцию `hasPlaceholder()`. Это позволяет генерировать разную разметку в зависимости от того, предоставляет ли страница содержимое.

```twig
{% if hasPlaceholder('sidemenu') %}
    <!-- Разметка для страницы с боковой панелью -->
    <div class="row">
        <div class="col-md-3">
            {% placeholder sidemenu %}
        </div>
        <div class="col-md-9">
            {% page %}
        </div>
    </div>
{% else %}
    <!-- Разметка для страницы без боковой панели -->
    {% page %}
{% endif %}
```

## Использование плейсхолдеров как переменных

Плейсхолдеры полезны для передачи наследуемых переменных, например активной ссылки в навигации. Тег `{% put %}` позволяет задавать значения напрямую. Например, установка `activeNav` в значение **home** внутри шаблона страницы:

```twig
{% put activeNav = 'home' %}
```

В макете переменную можно получить функцией `placeholder()`. На основе значения, заданного страницей, определяется активная ссылка.

```twig
{% set active = placeholder('activeNav') %}

<ul>
    <li class="{{ active == 'home' ? 'active' }}">Home</li>
    <li class="{{ active == 'blog' ? 'active' }}">Blog</li>
    <li class="{{ active == 'contact' ? 'active' }}">Contact</li>
</ul>
```

Вторым аргументом можно передать значение по умолчанию.

```twig
{% set active = placeholder('activeNav', 'home') %}
```

## Системные плейсхолдеры

October CMS определяет статические плейсхолдеры, которые используются системой. Пакеты подключают свои зависимости к странице через эти плейсхолдеры — как из PHP, так и из Twig.

### {% scripts %}

Тег `{% scripts %}` вставляет ссылки на JavaScript-файлы, добавленные приложением. Обычно он размещается перед закрывающим тегом BODY.

```twig
<body>
    ...
    {% scripts %}
</body>
```

> **Примечание.** Этот тег должен появляться только один раз за цикл рендеринга, чтобы избежать дублирования ссылок.

#### Подключение скриптов

Ссылки на JavaScript-файлы можно программно добавить в PHP — через [компоненты](../../extend/cms-components.md) или [страницы](../../cms/themes/pages.md).

```php
function onStart()
{
    $this->addJs('assets/js/app.js');
}
```

Необработанную разметку можно вставить в тег `{% scripts %}` с помощью анонимного плейсхолдера **scripts** [в макете](../../cms/themes/layouts.md). Используйте тег `{% put %}` в страницах или макетах, чтобы добавить содержимое в плейсхолдер.

```twig
{% put scripts %}
    <script type="text/javascript" src="/themes/demo/assets/js/menu.js"></script>
{% endput %}
```

### {% styles %}

Тег `{% styles %}` выводит ссылки на таблицы стилей, добавленные приложением. Обычно он размещается в секции HEAD страницы или макета.

```twig
<head>
    ...
    {% styles %}
</head>
```

> **Примечание.** Этот тег должен появляться только один раз за цикл рендеринга, чтобы избежать дублирования ссылок.

#### Подключение стилей

Ссылки на таблицы стилей можно программно добавить в PHP — через [компоненты](../../extend/cms-components.md) или [страницы](../../cms/themes/pages.md).

```php
function onStart()
{
    $this->addCss('assets/css/hello.css');
}
```

Необработанную разметку можно вставить в тег `{% styles %}` с помощью анонимного плейсхолдера **styles** [в макете](../../cms/themes/layouts.md). Используйте тег `{% put %}` в страницах или макетах, чтобы добавить содержимое в плейсхолдер.

```twig
{% put styles %}
    <link href="/themes/demo/assets/css/page.css" rel="stylesheet" />
{% endput %}
```

### {% meta %}

Тег `{% meta %}` выводит метаданные, например Open Graph. Обычно он располагается в секции HEAD перед стилями и скриптами.

```twig
<head>
    {% meta %}
    ...
</head>
```

> **Примечание.** Этот тег должен появляться только один раз за цикл рендеринга, чтобы избежать дублирования ссылок.

#### Добавление метаданных

Необработанную разметку можно вставить в тег `{% meta %}` с помощью анонимного плейсхолдера **meta** [в макете](../../cms/themes/layouts.md). Используйте тег `{% put %}` в страницах или макетах, чтобы добавить содержимое в плейсхолдер.

```twig
{% put meta %}
    <meta name="turbo-visit-control" content="error">
{% endput %}
```

## Пользовательские атрибуты

Тег `placeholder` принимает два необязательных атрибута — `title` и `type`. Атрибут `title` самим CMS не используется, но может потребоваться другим плагинам. Атрибут `type` задаёт тип плейсхолдера. Сейчас поддерживаются два типа: **text** и **html**. Содержимое текстовых плейсхолдеров экранируется перед выводом. Атрибуты `title` и `type` указываются после имени плейсхолдера и атрибута `default`, если он присутствует. Пример:

```twig
{% placeholder ordering title="Ordering information" type="text" %}
```

Пример плейсхолдера с содержимым по умолчанию, заголовком и типом:

```twig
{% placeholder ordering default title="Ordering information" type="text" %}
    Информация о заказе для этого товара отсутствует.
{% endplaceholder %}
```
