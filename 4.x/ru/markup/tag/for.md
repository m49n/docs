# {% for %}

Теги `{% for %}` и `{% endfor %}` перебирают каждое значение коллекции. Коллекция может быть массивом или объектом, реализующим интерфейс `Traversable`.

```twig
<ul>
    {% for user in users %}
        <li>{{ user.username }}</li>
    {% endfor %}
</ul>
```

Можно получить и ключ, и значение:

```twig
<ul>
    {% for key, user in users %}
        <li>{{ key }}: {{ user.username }}</li>
    {% endfor %}
</ul>
```

Если коллекция пуста, можно вывести альтернативный блок через `else`:

```twig
<ul>
    {% for user in users %}
        <li>{{ user.username }}</li>
    {% else %}
        <li><em>Пользователи не найдены</em></li>
    {% endfor %}
</ul>
```

## Перебор коллекции

Чтобы итерировать диапазон чисел, используйте оператор `..`:

```twig
{% for i in 0..10 %}
    - {{ i }}
{% endfor %}
```

Этот код выведет все числа от 0 до 10.

Оператор можно применять и к буквам:

```twig
{% for letter in 'a'..'z' %}
    - {{ letter }}
{% endfor %}
```

Оператор `..` принимает любое выражение по обе стороны:

```twig
{% for letter in 'a'|upper..'z'|upper %}
    - {{ letter }}
{% endfor %}
```

## Добавление условия

В отличие от PHP, в цикле нельзя вызвать `break` или `continue`, однако коллекцию можно отфильтровать. Следующий пример пропускает всех пользователей `users`, у которых неактивный статус.

```twig
<ul>
    {% for user in users %}
        {% if user.active %}
            <li>{{ user.username }}</li>
        {% endif %}
    {% endfor %}
</ul>
```

## Переменная loop

Внутри блока `for` доступны специальные переменные.

Переменная | Описание
------------- | -------------
`loop.index` | Текущая итерация (нумерация с 1)
`loop.index0` | Текущая итерация (нумерация с 0)
`loop.revindex` | Количество итераций до конца (нумерация с 1)
`loop.revindex0` | Количество итераций до конца (нумерация с 0)
`loop.first` | `true`, если это первая итерация
`loop.last` | `true`, если это последняя итерация
`loop.length` | Количество элементов в коллекции
`loop.parent` | Родительский контекст

```twig
{% for user in users %}
    {{ loop.index }} - {{ user.username }}
{% endfor %}
```
