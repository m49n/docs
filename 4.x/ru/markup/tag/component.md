# {% component %}

Тег `{% component %}` выводит стандартную разметку [компонента CMS](../../cms/themes/components.md) на странице. Не все компоненты содержат разметку по умолчанию; документация плагина подскажет корректный способ использования.

```twig
{% component "blogPosts" %}
```

Этот тег отрендерит частичное представление компонента с фиксированным именем **default.htm** и фактически эквивалентен следующему вызову:

```twig
{% partial "blogPosts::default" %}
```

## Переменные

Некоторые компоненты поддерживают передачу переменных при рендеринге.

```twig
{% component "blogPosts" postsPerPage="5" %}
```

## Настройка компонентов

В большинстве случаев тег `{% component %}` не требуется: разметка служит примером использования API компонента. Компоненты предназначены для настройки, и это можно сделать двумя способами:

1. Перенести стандартную разметку в частичное представление.
1. Переопределить частичные представления компонента в теме.

Процесс настройки стандартной разметки описан в [статье о компонентах CMS](../../cms/themes/components.md).
