# {% flash %}

::: aside
Подробнее об использовании flash-сообщений см. в [статье о flash-сообщениях](../../ajax/features/flash-messages.md).
:::

Теги `{% flash %}` и `{% endflash %}` выводят flash-сообщения, сохранённые в сессии пользователя классом PHP `Flash`. Переменная `message` содержит текст сообщения, и разметка внутри повторяется для каждого сообщения.

```twig
<ul>
    {% flash %}
        <li>{{ message }}</li>
    {% endflash %}
</ul>
```

Можно использовать переменную `type`, представляющую тип сообщения — **success**, **error**, **info** или **warning**.

```twig
{% flash %}
    <div class="alert alert-{{ type }}">
        {{ message }}
    </div>
{% endflash %}
```

Также можно указать `type`, чтобы вывести сообщения определённого типа. Следующий пример показывает только сообщения **success**; если есть сообщение **error**, оно не появится.

```twig
{% flash success %}
    <div class="alert alert-success">{{ message }}</div>
{% endflash %}
```

## Сохранение flash-сообщений в переменную Twig

В любом шаблоне можно сохранить flash-сообщения в переменную с помощью функции `flash()`. Это позволяет обработать результат перед выводом. Функция возвращает массив с одним сообщением каждого типа.

```twig
{% set messages = flash() %}
```

Первый аргумент может задавать тип сообщения и возвращает строку.

```twig
{% set successMessage = flash('success') %}
```

Если передать **all**, функция вернёт массив типов, где каждый тип содержит массив всех сообщений.

```twig
{% set allMessages = flash('all') %}
```
