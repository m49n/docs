# {% if %}

Теги `{% if %}` и `{% endif %}` проверяют выражение и сопоставимы с операторами if в PHP. В простейшем случае их используют, чтобы убедиться, что выражение равно `true`:

```twig
{% if online == false %}
    <p>Сайт находится на обслуживании.</p>
{% endif %}
```

Можно проверить и то, что массив не пуст:

```twig
{% if users %}
    <ul>
        {% for user in users %}
            <li>{{ user.username }}</li>
        {% endfor %}
    </ul>
{% endif %}
```

> **Примечание.** Чтобы проверить, определена ли переменная, используйте `{% if users is defined %}`.

Оператор `not` помогает проверять значения, приводимые к `false`:

```twig
{% if not user.subscribed %}
    <p>Вы не подписаны на рассылку.</p>
{% endif %}
```

Для нескольких выражений доступны `{% elseif %}` и `{% else %}`:

```twig
{% if kenny.sick %}
    Kenny заболел.
{% elseif kenny.dead %}
    Ты убил Kenny! Негодяй!
{% else %}
    Kenny выглядит нормально.
{% endif %}
```

## Правила вычисления выражений

Правила определения истинности совпадают с PHP. Крайние случаи указаны ниже.

Значение | Булево значение
------------- | -------------
*пустая строка* | false
*числовой ноль* | false
*строка только с пробелами* | true
*пустой массив* | false
*null* | false
*непустой массив* | true
*объект* | true
