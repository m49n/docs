# |resize

Фильтр `|resize` пытается изменить размеры переданного источника изображения согласно указанной конфигурации и возвращает URL обработанного изображения.

```twig
{{ 'image.jpg'|resize(100, 100) }}
```

Фильтр принимает три аргумента: `|resize(width, height, options)`.

Если фильтр может изменить размеры указанного изображения, будет возвращён URL ресайзера изображений (например, `/resize/filename.png`). При последующих запросах возвращается прямой URL обработанного изображения. Если фильтр не может обработать указанное изображение, он вернёт исходный URL без изменений.

Следующий пример изменит изображение media banner.jpg до соотношения 1920 × 1080.

```twig
<img src="{{ 'banner.jpg'|media|resize(1920, 1080) }}" />
```

Можно передать третий аргумент `options`. В этом примере изображение будет обрезано.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, { mode: 'crop' }) }}" />
```

Дополнительные сведения о доступных параметрах `options` см. в [статье об изменении изображений](../../extend/services/resizer.md).

## Пользовательские имена файлов

По умолчанию ресайзер назначает обработанным изображениям случайное имя файла. Чтобы использовать исходное имя, передайте значение `true` в параметр `filename`.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, { filename: true }) }}" />
```

Параметр `filename` также поддерживает пользовательское имя файла в виде строки. Имя не должно содержать расширение, поскольку используется исходное.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, { filename: 'my-seo-friendly-name' }) }}" />
```

Расширение можно изменить через параметр `extension`. При этом выполняется попытка преобразовать тип файла, например JPG в PNG.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, {
    filename: 'my-seo-friendly-name',
    extension: 'png'
}) }}" />
```

## Пользовательские названия папок

При использовании пользовательских имён файлов к имени всё равно добавляется хеш для обеспечения уникальности в каталоге ресурсов ресайзера. В большинстве случаев этого достаточно для базовых SEO-требований. Например, файл будет храниться в системе так:

- `.../800_600_0_0_auto/my-seo-friendly-name_001a14981ffe90700046616c5f415467.png`

Можно указать `group` в качестве названия папки, чтобы разместить изображение в отдельной группе ресурсов.

```twig
<img src="{{ 'banner.jpg'|resize(800, 600, {
    filename: 'my-seo-friendly-name',
    group: '2024-banners'
}) }}" />
```

Например, в этом случае файл окажется в следующем каталоге:

- `.../800_600_0_0_auto/2024-banners/my-seo-friendly-name.png`

Однако имей в виду, что такой подход может привести к конфликтам имён. Если другое изображение будет обработано с тем же именем и параметрами изменения размера, вернётся исходный файл, поскольку уникальный хеш не добавляется к пути.

## Доступные источники

Можно ссылаться на изображения из разных источников, включая следующие пути:

- `/app`
- `/plugins`
- `/themes`
- `/modules`
- `/storage/app/uploads`
- `/storage/app/media`

Например:

```twig
{{ '/plugins/acme/blog/assets/images/someimage.png'|resize(...) }}
```

## Интерфейс PHP

Изображения можно изменять и в PHP с помощью `System\Classes\ResizeImages` и метода `resize`. Возвращаемое значение — URL обработанного изображения.

```php
ResizeImages::resize('path/to/asset.jpg');
```

Метод принимает ширину (второй аргумент), высоту (третий аргумент) и [параметры ресайзера](../../extend/services/resizer.md) (четвёртый аргумент).

```php
ResizeImages::resize('path/to/asset.jpg', 800, 600, ['mode' => 'crop']);
```
