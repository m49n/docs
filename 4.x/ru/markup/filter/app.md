# |app

Фильтр `|app` возвращает адрес относительно публичного пути сайта. Результатом будет абсолютный URL, включая доменное имя и протокол, к расположению, указанному в параметре фильтра. Фильтр можно применить к любому пути.

```twig
<link rel="icon" href="{{ '/favicon.ico'|app }}" />
```

Если адрес сайта — __https://octobercms.com__, приведённый пример выведет следующее:

```html
<link rel="icon" href="https://octobercms.com/favicon.ico" />
```

Фильтр можно использовать и для статических URL:

```twig
<a href="{{ '/about-us'|app }}">
    About Us
</a>
```

Результат будет таким:

```html
<a href="https://octobercms.com/about-us">
    About us
</a>
```

> **Примечание.** Для ссылок на другие страницы рекомендуется использовать фильтр `|page`.
