# |theme

Фильтр `|theme` возвращает адрес относительно пути активной темы сайта. Результатом будет абсолютный URL, включая домен и протокол, к ресурсу, указанному в параметре фильтра. Ресурсы темы обычно находятся в подкаталоге **assets** каталога темы.

```twig
<script type="text/javascript" src="{{ 'assets/js/menu.js'|theme }}"></script>
```

Если адрес сайта — __https://octobercms.com__, а активная тема называется `website`, приведённый выше пример выведет следующее:

```html
<script type="text/javascript" src="http://october.com/themes/website/assets/js/menu.js"></script>
```

## Комбинирование CSS и JavaScript

Фильтр также можно использовать для объединения ресурсов одного типа, передав массив файлов.

```twig
<link href="{{ [
    'assets/css/styles1.css',
    'assets/css/styles2.css'
]|theme }}" rel="stylesheet">
```

> **Примечание.** Минификацию ресурсов можно включить параметром `enableAssetMinify` в скрипте `config/cms.php`. По умолчанию минификация отключена.

### Псевдонимы для комбинирования

Комбайнер ресурсов поддерживает распространённые псевдонимы, которые подставляют пути к файлам и начинаются с символа `@`. Например, в комбайнер можно включить [ресурсы AJAX-фреймворка](../../cms/introduction.md).

```twig
<script src="{{ [
    '@framework.extras',
    'assets/javascript/app.js'
]|theme }}"></script>
```

Поддерживаются следующие псевдонимы:

Псевдоним | Описание
------------- | -------------
`@framework` | Дополнения AJAX-фреймворка, замена тега `{% framework %}` (JavaScript)
`@framework.extras` | Дополнения AJAX-фреймворка, замена тега `{% framework extras %}` (JavaScript, CSS)
`@framework.turbo` | Turbo AJAX-фреймворка, замена тега `{% framework turbo %}` (JavaScript)
`@framework.bundle` | Набор AJAX-фреймворка, замена тега `{% framework extras turbo %}` (JavaScript, CSS)

:: tip
Один и тот же псевдоним можно использовать для JavaScript или CSS, например `@framework.extras`. В массиве должна быть как минимум ещё одна ссылка с расширением CSS или JS, чтобы определить тип.
:::

### Внешние пути комбайнера

Иногда нужно объединить файл вне темы. Для этого перед путём добавляется символ, формирующий динамический путь. Например, путь, начинающийся с `~/`, создаст путь относительно приложения:

```twig
<script src="{{ ['~/modules/system/assets/js/framework.js']|theme }}"></script>
```

Для создания динамических путей поддерживаются следующие символы:

Символ | Описание
------------- | -------------
`~` | Относительно каталога приложения
`$` | Относительно каталога плагинов
`#` | Относительно каталога тем
