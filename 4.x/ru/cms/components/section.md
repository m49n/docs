# Раздел

Компонент (component) `section` определяет раздел сайта с соответствующей записью. Этот раздел используется при предпросмотре записи из бэкенда.

## Доступные свойства

Компонент поддерживает следующие свойства.

Property | Description
-------- | -------------
**handle** | Служебное имя [blueprint-схемы записи](../tailor/blueprints.md).
**identifier** | Ключ идентификатора для поиска записи. Поддерживаемые значения: `slug`, `fullslug` или `id`. Значение по умолчанию: `slug`.
**value** | Значение идентификатора для поиска записи, необязательное. Оставьте пустым, чтобы использовать имя параметра URL, совпадающее с ключом идентификатора. Можно задать жёстко или через пользовательский параметр, например: `{{ :slug }}`.
**isDefault** | Делает страницу страницей по умолчанию при предпросмотре записи. Значение по умолчанию: `true`.

## Базовое использование

В следующем примере создаётся раздел для записи **Blog\\Author**, и запись ищется по параметру [URL](../themes/pages.md) `:slug` по умолчанию. Имя автора выводится в заголовке через Twig-переменную `{{ section.title }}`.

::: cmstemplate
```ini
url = "author/:slug"

[section]
handle = "Blog\\Author"
```
```twig
<h1>Posts by {{ section.title }}</h1>
```
:::

Если на странице используется несколько разделов, псевдоним компонента позволяет задать другое имя переменной, доступной на странице. В следующем примере псевдоним компонента **author** делает заголовок доступным через Twig-переменную `{{ author.title }}`.

::: cmstemplate
```ini
[section author]
handle = "Blog\\Author"
```
```twig
<h1>Posts by {{ author.title }}</h1>
```
:::

## Изменение идентификатора поиска

Идентификатор по умолчанию — `slug`. Его можно изменить, установив для свойства `identifier` другое значение, например `id`, чтобы искать запись по столбцу `id`. Обратите внимание, что URL страницы также меняется и теперь использует параметр `:id`.

```ini
url = "author/:id"

[section]
handle = "Blog\\Author"
identifier = "id"
```

Можно жёстко задать значение идентификатора через свойство `value`. Например, установка значения **7** покажет запись с фиксированным идентификатором.

```ini
url = "author/ceo"

[section]
handle = "Blog\\Author"
identifier = "id"
value = 7
```

Свойство `value` также принимает внешние параметры. В следующем примере для поиска записи используется параметр URL **foobar**.

```ini
url = "author/:foobar"

[section]
handle = "Blog\\Author"
identifier = "id"
value = "{{ :foobar }}"
```

::: warning
Ссылки предпросмотра и [виджет Page Finder](../../element/form/widget-pagefinder.md) не поддерживают идентификаторы с пользовательскими значениями.
:::

## Проверка существования записи

В большинстве случаев следует отображать страницу 404, если запись не найдена. Это можно сделать с помощью конструкции `{% if %}` и функции `abort(404)`.

```twig
{% if author is empty %}
    {% do abort(404) %}
{% endif %}
```

::: tip
[Функция Twig `abort()`](../../markup/function/abort.md) используется для отображения страницы 404, если запись не найдена.
:::

## Доступ к типу записи

Если в blueprint-схеме записи используются [группы контента](./blueprints.md), можно получить код группы через атрибут `content_group`. Например, запись может иметь группы контента **regular_post** и **markdown_post**, для которых контент обрабатывается по-разному.

```twig
{% if post.content_group == 'markdown_post' %}
    <!-- Render content as Markdown -->
    {{ post.content|md }}
{% else %}
    <!-- Render content as HTML -->
    {{ post.content|raw }}
{% endif %}
```

## Использование полного slug

Если тип записи — `structure`, доступен атрибут **fullslug**. Чтобы использовать полный slug в URL страницы, его следует определить как [подстановочный параметр URL](../themes/pages.md). Свойство `identifier` компонента нужно установить в **fullslug**.

```ini
url = "/wiki/:fullslug*"

[section article]
handle = "Wiki\\Article"
identifier = "fullslug"
```

В качестве альтернативы рекомендуется использовать **id**, размещая его в конце URL. Это позволяет свободно перемещать записи, не ломая ссылки на сайте. Следующий пример показывает, как реализовать такое поведение с перенаправлением для ранее используемых URL.

::: cmstemplate
```ini
url = "/wiki/:fullslug*/:id"

[section article]
handle = "Wiki\\Article"
identifier = "id"
```
```twig
{% if article is empty %}
    {% do abort(404) %}
{% elseif article.fullslug != this.param.fullslug %}
    {% do redirect(this|page({ fullslug: article.fullslug }), 301) %}
{% endif %}

<!-- Contents here -->
```
:::

::: tip
[Функция Twig `redirect()`](../../markup/function/redirect.md) выполняет постоянное перенаправление 301, если slug не совпадает. [Twig-фильтр `|page`](../../markup/filter/page.md) передаёт текущую страницу и переписывает параметр URL `fullslug` на корректное значение.
:::
