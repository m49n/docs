# Глобальные данные

Компонент (component) `global` делает глобальную запись доступной на странице, в макете (layout) или частичном представлении (partial). Компонент можно использовать на любой странице, в любом макете или частичном представлении.

## Доступные свойства

Компонент поддерживает следующие свойства.

Property | Description
-------- | -------------
**handle** | Служебное имя [глобальной blueprint-схемы](../tailor/blueprints.md).

## Базовое использование

Следующий пример добавляет на страницу глобальные данные с handle **Blog\\Config**. Компоненту присваивается имя **blogConfig** через псевдоним компонента, и под этим именем переменная становится доступна на странице. Страница обращается к текстовому полю `about_this_blog` и выводит его содержимое.

::: cmstemplate
```ini
[global blogConfig]
handle = "Blog\\Config"
```
```twig
<p>{{ blogConfig.about_this_blog }}</p>
```
:::
