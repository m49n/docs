# Multisite

<VideoBlockLink src="https://www.youtube.com/watch?v=_kX7P3SEHg8" title="Multisite Demo" description="Это видео демонстрирует создание многоязычных сайтов с помощью October CMS Multisite." prompt="Посмотреть демонстрацию" />

Функция Multisite позволяет управлять несколькими сайтами из одной установки October CMS и назначать контент в зависимости от имени домена. Например, интернет‑магазин с несколькими субсайтами для разных стран. Также Multisite можно использовать для управления переводами локализованного сайта.

## Управление сайтами

Создавать сайты можно на странице **Settings → Manage Sites** панели администрирования. Каждая установка включает основной сайт, который выступает сайтом по умолчанию для каждого запроса.

В конфигурации для каждого сайта задаются следующие параметры:

- **Enabled** — определяет, можно ли получить доступ к сайту на витрине и в панели администрирования.
- **Name** — задаёт имя сайта.
- **Unique Code** — задаёт уникальный код сайта для поиска через API.
- **Theme** — тема CMS, которая используется, когда этот сайт активен.
- **Locale** — локаль приложения для данного сайта.
- **Timezone** — часовой пояс для этого сайта.
- **Custom application URL** — URL, который используется при активном сайте, например, для шаблонов писем или когда политика ссылок принудительно задаёт URL.
- **Use a CMS route prefix** — определяет префикс, который добавляется перед каждым маршрутом страницы. Можно использовать для идентификации сайта при общем имени хоста.
- **Define matching hostnames** — сопоставляет сайт по указанным именам хостов. Включение рекомендуется для боевых сайтов по соображениям безопасности. Поддерживаются шаблоны с подстановочными знаками, например `*.mydomain.tld`.
- **Display a color for this site** — при включении показывает баннер в верхней части панели администрирования. Полезно для идентификации активного сайта или различения сред, например красный — для разработки, зелёный — для стейджинга и без цвета — для боевой среды.

Когда создано более одного сайта, каждый из них можно выбрать в панели администрирования с помощью выпадающего списка выбора сайта.

## Компонент sitePicker

Компонент (component) `sitePicker` позволяет управлять ссылками на другие сайты. Добавлять его лучше всего в шаблон страницы или макета (layout).

::: cmstemplate
```ini
[sitePicker]
```
```twig
{% set availableSites = sitePicker.sites %}
```
:::

Ознакомьтесь со статьёй о [компоненте sitePicker](../components/sitepicker.md), чтобы узнать, как выводить URL сайтов и генерировать альтернативные ссылки страниц.

## Определение языка браузера

October CMS автоматически определяет подходящий сайт на основе предпочитаемого языка браузера, когда выполняются следующие условия.

- У всех сайтов в группе задан префикс
- Нет других сайтов, соответствующих базовому URL

Например, если основной сайт — **English** с префиксом маршрута `/en`, а у другого сайта **French** префикс `/fr`, поведение будет следующим.

Base URL | Поведение
-------- | --------
https://yoursite.tld/en | Отображается сайт **English**
https://yoursite.tld/fr | Отображается сайт **French**
https://yoursite.tld | Перенаправление в зависимости от предпочтительного языка

Когда пользователь посещает базовый URL, его предпочтительный язык определяется автоматически, и выполняется перенаправление на соответствующий сайт. Совпадение выполняется по значению локали. Если совпадений нет, используется основной сайт.

::: tip
Это поведение можно изменить с помощью значения `redirect_policy` в файле **config/cms.php**.
:::

## Группы сайтов

В базовой конфигурации Multisite помогает создавать несколько сайтов на одном языке или один сайт с несколькими языками. Группировка сайтов позволяет развить эту концепцию и создавать несколько сайтов с несколькими языками. Создайте группы сайтов на странице **Settings → Manage Sites → Manage Site Groups**, после чего для каждого сайта появится поле выбора группы.

Практически каждая группа сайтов представляет веб‑сайт, а определения сайтов, принадлежащие группе, представляют сайт на альтернативном языке. Ниже приведён пример конфигурации сгруппированных сайтов для веб‑сайта о собаках и кошках с двумя языками для каждого.

Site Group | Site Name
---------- | -----------
Dogs       | English
Dogs       | French
Cats       | English
Cats       | French

Сайты в группе будут синхронизировать поля только внутри своей группы. Например, если [чертёж Tailor](../tailor/introduction.md) использует опцию `multisite: sync`, записи синхронизируются только между сайтами в одной группе.

## Ограничения по ролям

Определения сайтов могут ограничивать видимость в зависимости от роли администратора, что позволяет использовать отдельные роли для управления конкретными сайтами. Чтобы включить ограничение Multisite по ролям:

1. Перейдите в **Manage Sites** и выберите определение сайта.
2. Установите флажок **Define administrator roles**.
3. Выберите роли, которым разрешён просмотр сайта.
4. Нажмите **Save**.

После включения сайт будет отображаться в бэкенде только администраторам, указанным в поле. Например, чтобы создать сайт, доступный только разработчикам, выберите в поле роль **Developer**.

## Возможности Multisite

Некоторые базовые возможности изначально не поддерживают Multisite, например настройки почты. Можно выборочно включать возможности Multisite в файле **config/multisite.php** в секции `features`. Следующие ключи возможностей доступны для использования с несколькими определениями сайтов.

Feature | Описание
------- | --------------------------
`cms_maintenance_setting` | Настройки режима обслуживания уникальны для каждого сайта
`backend_mail_setting` | Настройки почты уникальны для каждого сайта
`system_asset_combiner` | Ключи кэша объединителя ресурсов уникальны для сайта

### Отключение Multisite

Функцию Multisite можно полностью отключить, установив для параметра `enabled` значение `false`.

```php
'enabled' => false
```

## PHP-интерфейс

[Сервис сайта](../../extend/services/site.md) включает глобальный фасад Site, который предоставляет инструменты для работы с Multisite. Например, следующий код находит модель в контексте сайта с идентификатором **2**.

```php
$model = Site::withContext(2, function() {
    return Model::find(1);
});
```

Подробнее см. в [статье о сервисе Site](../../extend/services/site.md).
