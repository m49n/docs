# Темы с хранением в базе данных

Иногда нет возможности записывать на файловую систему, чтобы изменить тему. Темы с хранением в базе данных позволяют сохранять все изменения шаблонов CMS в базе данных.

:::aside
Файлы ресурсов — например изображения и таблицы стилей — не сохраняются в базе данных и не могут быть изменены без доступа к файловой системе.
:::

Чтобы включить эту функцию для конкретной темы, откройте **Settings → Frontend Theme**, выберите **Edit Properties** и установите флажок **Save Changes in Database**.

Также можно включить функцию глобально для всех тем, задав конфигурационный параметр `cms.database_templates` или переменную окружения.

```text
CMS_DB_TEMPLATES=true
```

## Импорт из базы данных в файловую систему

Команда `theme:copy` копирует версию темы из базы данных в файловую систему. Просто вызовите команду с опцией `--import-db`.

```bash
php artisan theme:copy demo --import-db
```

Чтобы удалить все шаблоны в базе данных, добавьте опцию `--purge-db`.

```bash
php artisan theme:copy demo --import-db --purge-db
```
