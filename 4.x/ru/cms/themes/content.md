# Контент-блоки

Контент-блоки (content blocks) могут содержать текст, HTML или [Markdown](http://daringfireball.net/projects/markdown/syntax). Их редактируют отдельно от страницы или макета. Контент-блоки предназначены только для статического содержимого и поддерживают базовые шаблонные переменные. [Частичные представления (partials)](./partials.md) гибче и подходят для генерации динамического содержимого.

## Введение

Файлы контент-блоков располагаются в подкаталоге **/content** каталога темы. Контент-файлы поддерживают следующие расширения.

Extension | Description
------------- | -------------
**html** | Используется для HTML-разметки (WYSIWYG-редактор).
**htm** | Используется для HTML-разметки (редактор кода).
**txt** | Используется для обычного текста.
**md** | Используется для Markdown.

Расширение влияет на режим отображения контент-блока в интерфейсе бэкенда: WYSIWYG-редактор, редактор кода или редактор Markdown. Оно также определяет рендеринг блоков на сайте; например, блоки Markdown преобразуются в HTML перед выводом.

## Рендеринг контент-блоков

Используйте тег `{% content 'file.htm' %}`, чтобы вывести контент-блок на [странице](./pages.md), в [частичном представлении](./partials.md) или [макете](./layouts.md).

Ниже показан пример страницы, которая выводит контент-блок полностью.

::: cmstemplate
```ini
url = "/contacts"
```
```twig
<div class="contacts">
    {% content 'contacts.html' %}
</div>
```
:::

Ещё один пример — вывод Markdown-файла с расширением `md`.

```twig
{% content 'my-markdown.md' %}
```

## Передача переменных в контент-блоки

Иногда нужно передать переменные в контент-блок из внешнего кода. Хотя контент-блоки не поддерживают разметку Twig, они умеют работать с переменными в базовом синтаксисе. Переменные передаются, если указать их после имени контент-блока в теге `{% content %}`.

Передача переменной `name` со значением **John** в контент-блок.

```twig
{% content 'welcome.htm' name='John' %}
```

Внутри контент-блока переменные доступны через одинарные *фигурные скобки*.

```html
<h1>This is a demo for {name}</h1>
```

::: tip
Подробнее об использовании переменных см. в [руководстве по разметке](../../markup/tag/content.md).
:::

### Глобальные переменные

Можно зарегистрировать переменные, доступные во всех контент-блоках глобально, с помощью метода `View::share`.

```php
View::share('site_name', 'October CMS');
```

Такой вызов обычно размещают в методе register или boot [файла регистрации плагина](../../extend/system/plugins.md). В этом примере переменная `{site_name}` будет доступна во всех контент-блоках.

```html
<p>Welcome to {site_name}</p>
```
