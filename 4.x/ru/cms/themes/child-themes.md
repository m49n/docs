# Дочерние темы

Дочерние темы (child themes) позволяют использовать наследование тем. Это полезно, если есть сторонняя тема или тема только для чтения. Дочерняя тема ссылается на родительскую и использует её как резервный источник.

Если страница `home.htm` существует в родительской теме, но отсутствует в дочерней, она всё равно доступна: URL активен, и страницу можно открыть как обычно. При сохранении страницы в бэкенде в дочерней теме создаётся новый файл, который переопределяет содержимое.

Чтобы включить функцию для темы, откройте **Settings → Frontend Theme**, выберите **Edit Properties** и укажите родителя в выпадающем списке **Parent Theme**.

## Файл блокировки темы

При установке сторонней темы через Composer важно помнить, что при обновлении темы файлы могут быть перезаписаны. Это может привести к потере любых изменений. В качестве защитного механизма в тему включают файл `.themelock`, который оберегает её от изменений, способных потеряться при обновлении системы.

Если файл `.themelock` присутствует в каталоге темы:

- тему можно выбрать только как родительскую;
- тема не отображается в интерфейсе бэкенда;
- тему нельзя сделать активной.

## Создание новой дочерней темы

Команда `theme:copy` подходит для создания новых тем, в том числе дочерних. Следующая команда создаёт новую тему `demo-copy` из исходной темы `demo`, копируя каталог и содержимое. Файл `.themelock` при этом удаляется.

```bash
php artisan theme:copy demo demo-copy
```

Чтобы создать дочернюю тему, наследующую родительскую, добавьте опцию `--child`.

```bash
php artisan theme:copy demo demo-child --child
```
