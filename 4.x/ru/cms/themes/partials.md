# Частичные представления

Частичные представления (partials) — это мощные элементы, которые позволяют повторно выводить HTML на разных страницах или макетах, например подвал на нескольких [макетах страницы](./layouts.md). Они также полезны для динамического [обновления содержимого страницы через AJAX](../../ajax/update-partials.md).

Файлы шаблонов частичных представлений находятся в каталоге **partials** темы. Они должны иметь расширение **htm**. Ниже приведён пример максимально простого частичного представления.

```html
<p>This is a partial</p>
```

Секция конфигурации для частичных представлений необязательна и может содержать параметр **description**, отображаемый в интерфейсе бэкенда. Ниже пример частичного представления с описанием.

::: cmstemplate
```ini
description = "Demo partial"
```
```html
<p>This is a partial</p>
```
:::

В секции конфигурации частичного представления также можно объявлять компоненты. Подробнее о них см. в статье [Компоненты](./components.md).

## Рендеринг частичных представлений

::: aside
Если используется частичное представление из подкаталога, нужно указать имя подкаталога.
:::

Тег Twig `{% partial "partial-name" %}` выводит частичное представление. У тега один обязательный параметр — имя файла частичного представления без расширения. Тег `{% partial %}` можно использовать в странице, макете или другом частичном представлении. Ниже пример страницы, которая подключает частичное представление.

```twig
<div class="sidebar">
    {% partial "sidebar-contacts" %}
</div>
```

## Передача переменных в частичные представления

Часто возникает потребность передать переменные в частичное представление из внешнего кода. Это делает частичные представления ещё полезнее. Например, частичное представление может выводить список записей блога. Если передать в него коллекцию записей, одно и то же частичное представление можно использовать на странице архива блога, странице категории блога и т. д. Переменные передаются, если указать их после имени частичного представления в теге `{% partial %}`.

```twig
<div class="sidebar">
    {% partial "blog-posts" posts=posts %}
</div>
```

Можно передавать и новые переменные, доступные только в частичном представлении.

```twig
<div class="sidebar">
    {% partial "sidebar-contacts" city="Vancouver" country="Canada" %}
</div>
```

Внутри частичного представления переменные доступны так же, как и любые другие переменные разметки.

```twig
<p>Country: {{ country }}, city: {{ city }}.</p>
```

### Область видимости переменных

Содержимое частичного представления получает доступ к переменным текущего контекста и к переданным дополнительно.

```twig
{% partial "mypartial" foo="bar" %}
```

В следующем примере переменная `foo` будет доступна внутри шаблона `mypartial`.

```twig
{% set foo = "bar" %}
{% partial "mypartial" %}
```

Чтобы запретить доступ к контексту, добавьте ключевое слово `only`. В этом примере будет доступна только переменная `foo`.

```twig
{% partial "mypartial" foo="bar" only %}
```

В примере ниже не будет доступно ни одной переменной.

```twig
{% partial "mypartial" only %}
```

### Передача разметки как переменной

Можно передать разметку в частичное представление, добавив атрибут `body` к тегу частичного представления.

```twig
{% partial "card" body %}
    This is the card contents
{% endpartial %}
```

Содержимое доступно внутри частичного представления через переменную `body`.

```twig
{{ body|raw }}
```

В сочетании с [тегом разметки placeholder](../../markup/tag/placeholder.md) это позволяет создавать составные частичные представления.

```twig
{% partial "card" image="img.jpg" body %}
    {% put header %}
        <h2>This is the card header</h2>
    {% endput %}
    This is the card contents
{% endpartial %}
```

Частичное представление **card** состоит из двух областей содержимого и переменной изображения.

```twig
<div class="header">
    <div class="image">
        <img src="{{ image }}" />
    </div>
    {% placeholder header %}
</div>
<div class="body">
    {{ body|raw }}
</div>
```

## Динамические частичные представления

Частичные представления, как и страницы, могут использовать любые возможности Twig. Подробности см. в разделе [Динамические страницы](pages.md) документации.

### Жизненный цикл частичного представления

В секции PHP частичного представления можно определить специальные функции: `onStart` и `onEnd`. Функция `onStart` выполняется перед рендерингом частичного представления и до запуска [компонентов частичного представления](./components.md). Функция `onEnd` выполняется перед рендерингом частичного представления и после выполнения компонентов. В `onStart` и `onEnd` можно передавать переменные в окружение Twig. Используйте `$this` с синтаксисом массива, чтобы передавать переменные странице.

::: cmstemplate
```ini
```
```php
<?
function onStart()
{
    $this['hello'] = "Hello world!";
}
?>
```
```twig
<h3>{{ hello }}</h3>
```
:::

Переменные, переданные в частичное представление извне, доступны в PHP через объект `$this`.

::: cmstemplate
```ini
```
```php
<?
function onStart()
{
    $this['location'] = $this->city . ', ' . $this->country;
}
?>
```
```twig
<p>{{ location }} is the same as {{ city }}, {{ country }}.</p>
```
:::

Язык шаблонов October CMS описан в [руководстве по разметке](../../markup/templating.md). Общая последовательность выполнения обработчиков приведена в разделе [Динамические макеты](./layouts.md) документации.

### Вызов AJAX-обработчиков в частичных представлениях

Поскольку они инициализируются поздно, во время рендеринга страницы, жизненный цикл обычных частичных представлений имеет ряд ограничений. Чтобы их обойти, используйте тег `{% ajaxPartial %}`, позволяющий вызывать AJAX-обработчики внутри частичного представления.

```twig
{% ajaxPartial "contact-form" %}
```

::: tip
Подробнее о теге `{% ajaxPartial %}` см. в [статье об AJAX Partial](../../markup/tag/ajax-partial.md).
:::

При вызове обработчика из AJAX-частичного представления жизненный цикл работает иначе по сравнению с обычным AJAX-обработчиком.

1. Обработчик выполняется после функции `onEnd` частичного представления.
1. Выполняется весь жизненный цикл страницы, включая логику макета, страницы и родительских частичных представлений.
1. Во время запроса доступны все переменные, включая заданные в Twig.
1. Функции жизненного цикла частичного представления не могут возвращать значения.
