# Локализация

::: aside
См. статью [Multisite](../resources/multisite.md), чтобы узнать, как выбрать активный язык сайта.
:::

Темы могут предоставлять ключи локализации в файлах, размещённых в подкаталоге **lang** каталога темы. Эти ключи регистрируются автоматически и могут использоваться в содержимом темы или как подписи полей бэкенда, аналогично [локализации плагинов](../../extend/system/localization.md).

### Структура файлов локализации

Ниже приведён пример каталога **lang** темы.

::: dir
├── themes
|   └── website
|       └── `lang`  _← Каталог локализации_
|           ├── en.json  _← Файл локализации_
|           └── fr.json  _← Файл локализации_
:::

Файл локализации — это JSON, где строковые ключи используют «перевод по умолчанию» строки. Например, если в приложении есть французский перевод, создайте файл `lang/fr.json`.

```json
{
    "I love programming.": "j'adore programmer"
}
```

Можно определять ключи, основанные на коде, указав полный языковой ключ в JSON-файле. Например, для темы **acme** можно использовать ключ `theme.options.website_name`.

```json
{
    "theme.options.website_name": "October CMS"
}
```

Строки локализации доступны в файлах темы через фильтр Twig `trans`.

::: tip
Подробнее о переводах в Twig см. в [руководстве по разметке](../../markup/filter/trans.md).
```twig
<!-- j'adore programmer -->
{{ 'I love programming.'|trans }}

<!-- October CMS -->
{{ 'theme.options.website_name'|trans }}
```
:::
