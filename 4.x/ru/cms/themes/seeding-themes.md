# Наполнение тем

Темы поддерживают импорт демонстрационного содержимого из скриптов наполнения (seed), включая данные базы и [чертежи Tailor](../../cms/tailor/introduction.md). Для этого используется специальный каталог **seeds** внутри темы и соответствующая структура каталогов.

## Наполнение темы

Для наполнения темы используется команда Artisan `theme:seed`.

```bash
php artisan theme:seed <theme name>
```

Можно указать опцию `--root`, чтобы импортировать чертежи в корневой каталог, а не во вложенный.

```bash
php artisan theme:seed <theme name> --root
```

:::tip
Тему можно наполнить и через панель управления: **Settings → Frontend Theme → Manage → Seed Content**.
:::

## Структура каталогов

Ниже показан пример структуры каталога seeds. В каталоге **blueprints** лежат чертежи, которые использует тема; они автоматически импортируются в каталог **app/blueprints** во вложенную директорию **mywebsite**. Файл **data.yaml** содержит инструкции по импорту содержимого в базу данных.

::: dir
├── themes
|   └── mywebsite
|       └── `seeds`  _← Каталог наполнения темы_
|           ├── blueprints
|           |   └── post.yaml  _← Файл чертежа_
|           ├── lang
|           |   └── en.json  _← Файл локализации_
|           ├── media
|           |   └── banner.jpg  _← Медиафайл_
|           ├── data
|           |   ├── blog-posts.json  _← Файл данных_
|           |   └── media-files.json
|           └── data.yaml  _← Скрипт наполнения_
:::

## Импорт локализаций

Опционально можно импортировать языки в каталог **app/lang**, поместив [JSON-файлы локализации](../../extend/system/localization.md) в каталог **lang**. Это позволяет переводить подписи и описания в чертежах. Если языковой файл уже существует в каталоге приложения, строки объединяются.

## Импорт данных

Файл **data.yaml** использует специальный формат для импорта содержимого в базу данных. В примере ниже в базу импортируются два набора данных для записей Tailor.

```yaml
-
    name: Blog Post Data
    class: Tailor\Models\RecordImport
    file: seeds/data/blog-posts.json
    attributes:
        file_format: json
        blueprint_uuid: edcd102e-0525-4e4d-b07e-633ae6c18db6
-
    name: Media File Data
    class: Media\Models\MediaLibraryItemImport
    file: seeds/data/media-files.json
    attributes:
        file_format: json
```

YAML-файл должен содержать массив, где каждый элемент поддерживает следующие свойства.

Property | Description
------------- | -------------
**name** | имя шага импорта, отображаемое пользователю.
**class** | модель, реализующая интерфейс `Backend\Models\ImportModel`.
**file** | JSON-файл данных с содержимым для импорта.
**attributes** | список атрибутов, которые нужно установить в модели импорта до запуска.

### Данные чертежей Tailor

Используйте класс `Tailor\Models\RecordImport`, чтобы импортировать чертежи Tailor в каталог приложения. Ниже пример JSON-файла для импорта категорий блога. Каждый элемент массива создаёт запись в базе данных с указанными атрибутами. Атрибут **id** позволяет связывать записи между несколькими импортами.

```json
[
    {
        "id": 1,
        "title": "Announcements",
        "slug": "announcements"
    },
    {
        "id": 2,
        "title": "News",
        "slug": "news"
    }
]
```

### Данные медиафайлов

Используйте `Media\Models\MediaLibraryItemImport`, чтобы импортировать изображения в медиатеку. Следующий JSON демонстрирует импорт файлов. Атрибут **rootPath** задаёт префикс для медиатеки; можно указать пустую строку, чтобы импортировать в корень. Атрибут **type** принимает значения `file` или `folder` для импорта соответствующего типа, при этом **path** задаёт путь назначения, а **source** — исходный файл относительно каталога темы.

```json
[
    {
        "type": "folder",
        "path": "my-theme/announcements",
        "source": "seeds/media/announcements"
    },
    {
        "type": "folder",
        "path": "my-theme/news/2025",
        "source": "seeds/media/news"
    },
    {
        "type": "file",
        "path": "my-theme/banner.jpg",
        "source": "seeds/media/banner.jpg"
    }
]
```

## Импорт чертежей

::: aside
Поскольку чертежи не зависят от конкретной структуры файлов, их можно свободно перемещать.
:::

Чтобы импортировать чертежи, просто поместите файлы в каталог **seeds/blueprints**. Дополнительная конфигурация не требуется: при наполнении все чертежи копируются в каталог **app/blueprints**. Внутри него создаётся новая директория с именем темы, куда помещаются чертежи.

:::tip
Чертежи не всегда нужно импортировать через наполнение. Можно разместить их в каталоге темы **/blueprints**. Подробнее см. [вводную статью](../tailor/introduction.md).
:::
