# Контроллер дашборда

October CMS предлагает гибкую систему дашбордов, способную размещать несколько дашбордов с настраиваемым доступом. Каждый дашборд может содержать несколько виджетов для отображения различных типов данных. В October CMS имеется несколько типов виджетов, включая график, таблицу и другие. Стандартные виджеты достаточно гибкие, чтобы покрывать большинство типовых сценариев отчётности, например отображение данных о продажах или трафике. Кроме того, разработчики могут создавать новые типы виджетов для сценариев, где стандартные виджеты не подходят.

## Источники данных

Большинство встроенных виджетов дашборда в October CMS работают с серверными источниками данных. Эти источники поставляют структурированные данные в виде измерений, метрик и значений метрик. Такой подход позволяет разработчикам использовать одни и те же типы виджетов с разными данными. Например, виджет Table может отображать данные о трафике CMS или о продажах в интернет‑магазине. В этом сценарии виджет Table должен быть подключён к разным источникам данных и ссылаться на различные измерения и метрики, предоставляемые этими источниками.

Для большинства задач построения отчётности разработчикам следует включать источники данных в свои плагины, а не создавать пользовательские виджеты.

В этой документации используются следующие термины при описании источников данных и виджетов:

- **Измерение** — аспект или категория данных, применяемые для организации и группировки информации в отчёте. Измерения часто представляют качественные данные, такие как названия товаров или страниц, которые помогают сегментировать данные на более значимые и понятные единицы. Например, в отчёте о продажах измерением может быть Product, которое категоризирует данные о продажах по различным продуктам.
- **Метрика** — количественная величина, предоставляющая значения для измерения. Метрики отражают реальные измеряемые показатели, например объёмы продаж, количество посещений или коэффициенты конверсии. Метрики дают числовые значения каждой категории или единице, определённой измерением. Например, если Product Name — измерение, соответствующей метрикой может быть количество проданных единиц или полученная выручка по каждому продукту.
- **Поле измерения** — измерения могут включать поля измерения, которые представляют дополнительную информацию, связанную с измерением, и отображаются в отчётах. Для измерения Product логично зарегистрировать поле измерения Brand.

Важно отметить, что хотя необходимо указывать имена столбцов таблицы для объектов метрик и измерений, система дашборда не привязана к природе данных. Это означает, что в классе источника данных можно самостоятельно решать, как генерировать данные, и они необязательно должны загружаться из базы данных. Существует класс `ReportDataQueryBuilder`, который значительно упрощает создание источников данных, работающих с базой данных, но его использование необязательно.

::: tip
При создании источников данных, работающих с базой данных, убедитесь, что столбцы измерений, полей измерений и метрик проиндексированы для оптимальной производительности запросов.
:::

### Стандартные типы виджетов

October CMS включает следующие типы виджетов:

Type | Description
------------- | -------------
**Indicator** | отображает одно значение метрики источника данных, например общее количество просмотров страниц за выбранный период дашборда.
**Table** | способен отображать несколько значений измерений и метрик, например названия продуктов, количество проданных единиц и общую сумму продаж.
**Chart** | поддерживает линейные и столбчатые диаграммы. В линейных диаграммах горизонтальная ось показывает значения измерений, а вертикальная — значения метрик.
**Section Title** | показывает статический заголовок раздела, например «Информация о трафике». Этот виджет также может отображать выбранный интервал отчётности.
**Text Notice** | содержит статический заголовок и текст абзаца для представления любой информации, связанной с дашбордом.

## Создание стандартных дашбордов плагина

Плагины могут создавать и устанавливать пользовательские дашборды в October CMS с помощью [механизма загрузчиков данных (seeding)](https://docs.octobercms.com/3.x/extend/database/structure.html). Чтобы создать дашборд плагина, сначала создайте дашборд вручную, затем экспортируйте его с помощью встроенной функции Export Dashboard. Сохраните экспортированный JSON‑файл в каталоге плагина. После этого используйте метод `import` модели Dashboard, чтобы импортировать JSON‑файл как новый дашборд.

```php
use Backend\Models\Dashboard;

...

$content = file_get_contents(__DIR__.'/default-dashboard.json');
Dashboard::import($content, null, true);
```

Второй аргумент вызова всегда должен быть `null` для целей загрузчика данных. Третий аргумент определяет, должен ли дашборд быть доступен всем пользователям. Если установлено значение `false`, дашборд будет доступен только пользователям с правами управления дашбордами.
