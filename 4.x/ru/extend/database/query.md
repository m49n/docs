# Конструктор запросов

::: aside
Конструктор запросов использует привязку параметров PDO, чтобы защитить приложение от атак типа SQL-инъекция. Дополнительно очищать строки, передаваемые как значения привязки, не требуется.
:::

Конструктор запросов (query builder) базы данных предоставляет удобный и гибкий интерфейс для создания и выполнения запросов. Его можно использовать для большинства операций с базой данных в приложении, и он работает со всеми поддерживаемыми СУБД.

### Пример с «сырым» SQL

Иногда рациональнее выполнить запрос с помощью обычного SQL — для этого можно воспользоваться методом `Db::select`.

```php
Db::select('select * from sometable where name = :name', ['name' => 'Charles']);
```

Дополнительные сведения см. в статье о [выполнении «сырого» SQL](./basics.md).

## Получение результатов

Чтобы начать формировать запрос, используйте метод `table` фасада `Db`. Метод `table` возвращает экземпляр конструктора запросов для указанной таблицы, что позволяет дополнять запрос ограничениями и затем получить результаты. В приведённом примере `get` вернёт все записи таблицы.

```php
$users = Db::table('users')->get();
```

Подобно [«сырым» запросам](./basics.md), метод `get` возвращает массив (`array`) результатов, где каждая запись представлена экземпляром объекта PHP `stdClass`. Значение каждого столбца можно получить, обращаясь к нему как к свойству объекта.

```php
foreach ($users as $user) {
    echo $user->name;
}
```

Если нужно получить только одну строку из таблицы, используйте метод `first`. Он вернёт один объект `stdClass`.

```php
$user = Db::table('users')->where('name', 'John')->first();

echo $user->name;
```

### Извлечение отдельных значений

Если нет необходимости загружать всю строку, можно извлечь отдельное значение из записи методом `value`. Он возвращает значение столбца напрямую:

```php
$email = Db::table('users')->where('name', 'John')->value('email');
```

Чтобы получить массив значений одного столбца, используйте метод `pluck`. В примере ниже формируется массив названий ролей.

```php
$titles = Db::table('roles')->pluck('title');

foreach ($titles as $title) {
    echo $title;
}
```

Также можно задать столбец для пользовательских ключей возвращаемого массива.

```php
$roles = Db::table('roles')->pluck('title', 'name');

foreach ($roles as $name => $title) {
    echo $title;
}
```

::: warning
Результат `pluck` представляет собой объект `Collection`, который ведёт себя как массив. Чтобы преобразовать его в массив PHP, воспользуйтесь методом `all()`, например `pluck('name')->all()`.
:::

### Обработка результатов частями

Если необходимо работать с тысячами записей, используйте метод `chunk`. Он получает небольшую «порцию» результатов и передаёт каждую порцию в `Closure` для обработки. Метод особенно полезен при написании [консольных команд](../console-commands.md), обрабатывающих тысячи записей. Например, пройдём по всей таблице `users`, обрабатывая по 100 записей за раз.

```php
Db::table('users')->chunk(100, function($users) {
    foreach ($users as $user) {
        //
    }
});
```

Чтобы остановить дальнейшую обработку порций, верните `false` из `Closure`.

```php
Db::table('users')->chunk(100, function($users) {
    // Обработка записей...

    return false;
});
```

При обновлении записей в процессе обработки порций результаты могут меняться непредсказуемо. Поэтому при обновлениях внутри порций предпочтительнее использовать метод `chunkById`. Он автоматически постранично разбивает выборку по первичному ключу.

```php
Db::table('users')->where('active', false)
    ->chunkById(100, function ($users) {
        foreach ($users as $user) {
            Db::table('users')
                ->where('id', $user->id)
                ->update(['active' => true]);
        }
    });
```

::: warning
При обновлении или удалении записей в колбэке порции любые изменения первичного или внешних ключей могут повлиять на запрос порции. Это потенциально приведёт к пропуску некоторых записей в результирующих данных.
:::

### Агрегатные функции

Конструктор запросов предоставляет ряд агрегатных методов, таких как `count`, `max`, `min`, `avg` и `sum`. Их можно вызывать после формирования запроса:

```php
$users = Db::table('users')->count();

$price = Db::table('orders')->max('price');
```

Разумеется, эти методы можно комбинировать с другими частями запроса:

```php
$price = Db::table('orders')
    ->where('is_finalized', 1)
    ->avg('price');
```

Вместо `count` для проверки существования записей, удовлетворяющих условиям запроса, можно использовать методы `exists` и `doesntExist`:

```php
return Db::table('orders')->where('finalized', 1)->exists();

return Db::table('orders')->where('finalized', 1)->doesntExist();
```

## Оператор select

Иногда требуется получить не все столбцы таблицы. Используйте метод `select`, чтобы указать собственный список столбцов в запросе.

```php
$users = Db::table('users')->select('name', 'email as user_email')->get();
```

Метод `distinct` заставляет запрос возвращать только уникальные результаты.

```php
$users = Db::table('users')->distinct()->get();
```

Если экземпляр конструктора запросов уже создан и нужно добавить столбец к существующему выражению select, воспользуйтесь методом `addSelect`:

```php
$query = Db::table('users')->select('name');

$users = $query->addSelect('age')->get();
```

### «Сырые» выражения

Иногда в запрос необходимо вставить «сырое» выражение. Для его создания используйте метод `Db::raw`.

```php
$users = Db::table('users')
    ->select(Db::raw('count(*) as user_count, status'))
    ->where('status', '<>', 1)
    ->groupBy('status')
    ->get();
```

Ещё один пример — конкатенация столбцов и/или строк.

```php
Db::raw("(first_name, ' ', last_name) as full_name");
```

::: warning
«Сырые» выражения вставляются в запрос как строки, поэтому нужно особенно внимательно избегать уязвимостей SQL-инъекций.
:::

### Методы для «сырых» выражений

Вместо `Db::raw` можно использовать специальные методы, вставляющие «сырое» выражение в разные части запроса.

Метод `selectRaw` можно применять вместо `addSelect(Db::raw(...))`. Вторым аргументом он принимает необязательный массив привязок:

```php
$orders = Db::table('orders')
    ->selectRaw('price * ? as price_with_tax', [1.0825])
    ->get();
```

Методы `whereRaw` и `orWhereRaw` добавляют «сырое» условие `where`. Вторым аргументом они также принимают необязательный массив привязок:

```php
$orders = Db::table('orders')
    ->whereRaw('price > IF(state = "TX", ?, 100)', [200])
    ->get();
```

Методы `havingRaw` и `orHavingRaw` позволяют задать «сырое» выражение для условия `having`. Второй аргумент — необязательный массив привязок:

```php
$orders = Db::table('orders')
    ->select('department', Db::raw('SUM(price) as total_sales'))
    ->groupBy('department')
    ->havingRaw('SUM(price) > ?', [2500])
    ->get();
```

Метод `orderByRaw` задаёт «сырое» выражение для `order by`:

```php
$orders = Db::table('orders')
    ->orderByRaw('updated_at - created_at DESC')
    ->get();
```

Метод `groupByRaw` задаёт «сырое» выражение для `group by`:

```php
$orders = Db::table('orders')
    ->select('city', 'state')
    ->groupByRaw('city, state')
    ->get();
```

## Соединения

Конструктор запросов также позволяет описывать соединения (join). Чтобы выполнить обычное SQL-соединение «inner join», вызовите метод `join` у конструктора. Первый аргумент метода `join` — имя таблицы, к которой выполняется соединение, остальные аргументы задают условия соединения. Как видно из примера, в одном запросе можно соединять сразу несколько таблиц.

```php
$users = Db::table('users')
    ->join('contacts', 'users.id', '=', 'contacts.user_id')
    ->join('orders', 'users.id', '=', 'orders.user_id')
    ->select('users.*', 'contacts.phone', 'orders.price')
    ->get();
```

Чтобы выполнить соединение «left join» или «right join» вместо «inner join», используйте методы `leftJoin` или `rightJoin` соответственно. Их сигнатура совпадает с методом `join`.

```php
$users = Db::table('users')
    ->leftJoin('posts', 'users.id', '=', 'posts.user_id')
    ->get();

$users = Db::table('users')
    ->rightJoin('posts', 'users.id', '=', 'posts.user_id')
    ->get();
```

Для «cross join» воспользуйтесь методом `crossJoin` и передайте имя таблицы. Такое соединение формирует декартово произведение первой и присоединяемой таблиц.

```php
$users = Db::table('sizes')
    ->crossJoin('colors')
    ->get();
```

### Расширенные соединения

Можно задавать и более сложные условия соединения. Для этого передайте `Closure` вторым аргументом метода `join`. В `Closure` поступает объект `JoinClause`, позволяющий описывать ограничения соединения.

```php
Db::table('users')
    ->join('contacts', function ($join) {
        $join->on('users.id', '=', 'contacts.user_id')->orOn(...);
    })
    ->get();
```

Если требуется использовать условия в стиле `where` внутри соединения, вызовите у него методы `where` и `orWhere`. Эти методы сравнивают столбец с конкретным значением, а не со столбцом.

```php
Db::table('users')
    ->join('contacts', function ($join) {
        $join->on('users.id', '=', 'contacts.user_id')
            ->where('contacts.user_id', '>', 5);
    })
    ->get();
```

### Соединения с подзапросами

Методы `joinSub`, `leftJoinSub` и `rightJoinSub` позволяют соединять запрос с подзапросом. Каждый из них принимает три аргумента: подзапрос, его псевдоним и `Closure`, в котором задаются связанные столбцы:

```php
$latestPosts = Db::table('posts')
    ->select('user_id', Db::raw('MAX(created_at) as last_post_created_at'))
    ->where('is_published', true)
    ->groupBy('user_id');

$users = Db::table('users')
    ->joinSub($latestPosts, 'latest_posts', function ($join) {
        $join->on('users.id', '=', 'latest_posts.user_id');
    })->get();
```

### Объединения

Конструктор запросов позволяет быстро объединять («union») два запроса. Например, можно создать первый запрос и объединить его со вторым методом `union`.

```php
$first = Db::table('users')
    ->whereNull('first_name');

$users = Db::table('users')
    ->whereNull('last_name')
    ->union($first)
    ->get();
```

Метод `unionAll` также доступен и имеет ту же сигнатуру, что и `union`.

## Условия where

Чтобы добавить условие `where`, используйте метод `where` конструктора запросов. Базовый вызов `where` принимает три аргумента. Первый — имя столбца. Второй — оператор, которым может быть любой поддерживаемый СУБД оператор. Третий — значение, с которым сравнивается столбец.

Например, запрос ниже проверяет, что значение столбца `votes` равно 100.

```php
$users = Db::table('users')->where('votes', '=', 100)->get();
```

Для удобства, если нужно просто сравнить столбец с конкретным значением, его можно передать вторым аргументом метода `where`.

```php
$users = Db::table('users')->where('votes', 100)->get();
```

В `where` доступны различные операторы, например «больше» (`>`), «не равно» (`<>`) и `like`.

```php
$users = Db::table('users')
    ->where('votes', '>=', 100)
    ->get();

$users = Db::table('users')
    ->where('votes', '<>', 100)
    ->get();

$users = Db::table('users')
    ->where('name', 'like', 'T%')
    ->get();
```

### Условия or

Можно объединять ограничения `where` и добавлять к запросу условия `or`. Метод `orWhere` принимает те же аргументы, что и `where`:

```php
$users = Db::table('users')
    ->where('votes', '>', 100)
    ->orWhere('name', 'John')
    ->get();
```

::: tip
К любому из методов `where`, описанных далее, можно добавить префикс `or`, чтобы условие стало «ИЛИ», например `orWhereBetween`, `orWhereIn` и т. д.
:::

### Дополнительные условия where

Метод `whereBetween` проверяет, что значение столбца находится между двумя границами.

```php
$users = Db::table('users')
    ->whereBetween('votes', [1, 100])->get();
```

Метод `whereNotBetween` удостоверяется, что значение столбца лежит вне указанного диапазона.

```php
$users = Db::table('users')
    ->whereNotBetween('votes', [1, 100])
    ->get();
```

Метод `whereIn` проверяет, содержится ли значение столбца в указанном массиве.

```php
$users = Db::table('users')
    ->whereIn('id', [1, 2, 3])
    ->get();
```

Метод `whereNotIn` проверяет, что значение столбца **не** входит в заданный массив.

```php
$users = Db::table('users')
    ->whereNotIn('id', [1, 2, 3])
    ->get();
```

Метод `whereNull` проверяет, что значение столбца равно `NULL`.

```php
$users = Db::table('users')
    ->whereNull('updated_at')
    ->get();
```

Метод `whereNotNull` проверяет, что значение столбца **не** равно `NULL`.

```php
$users = Db::table('users')
    ->whereNotNull('updated_at')
    ->get();
```

### Поисковое условие

Методы `searchWhere` и `orSearchWhere` выполняют поисковый запрос по значениям столбцов. Метод добавляет к запросу поисковую фразу (первый аргумент) и список столбцов (второй аргумент), используя регистронезависимое условие `like`.

```php
$pages = Db::table('posts')
    ->searchWhere('foo bar', ['title', 'content'])
    ->get();
```

Пример выше сформирует следующий SQL, где к каждому столбцу и значению применяется `lower()`:

```sql
select * from users where
    (title like '%foo%' and title like '%bar%') or
    (content like '%foo%' and content like '%bar%')
```

По умолчанию производится поиск по каждому слову в фразе, однако поведение можно изменить, передав режим (третий аргумент). Поддерживаются режимы:

- **all**: результат должен содержать все слова (по умолчанию)
- **any**: результат может содержать любое из слов
- **exact**: результат должен содержать точную фразу

```php
$query->searchWhere('foo bar', ['title', 'content'], 'exact');
```

Пример поиска `exact` выше сформирует следующий SQL:

```sql
select * from users where (title like '%foo bar%' or content like '%foo bar%')
```

## Составные условия where

Иногда необходимо формировать более сложные условия, такие как `where exists` или вложенные группы параметров. Конструктор запросов Laravel поддерживает и их. Рассмотрим пример группировки ограничений в скобках:

```php
Db::table('users')
    ->where('name', '=', 'John')
    ->orWhere(function ($query) {
        $query->where('votes', '>', 100)
            ->where('title', '<>', 'Admin');
    })
    ->get();
```

Передача `Closure` в метод `orWhere` сообщает конструктору запросов о начале группы условий. В `Closure` поступает экземпляр конструктора запросов, с помощью которого можно задать ограничения внутри группы. Пример выше сформирует следующий SQL:

```sql
select * from users where name = 'John' or (votes > 100 and title <> 'Admin')
```

### Условия exists

Метод `whereExists` позволяет формировать SQL-условия `where exists`. Он принимает `Closure`, которому передаётся экземпляр конструктора запросов для описания запроса внутри условия `exists`:

```php
Db::table('users')
    ->whereExists(function ($query) {
        $query->select(Db::raw(1))
            ->from('orders')
            ->whereRaw('orders.user_id = users.id');
    })
    ->get();
```

Приведённый запрос сформирует следующий SQL:

```sql
select * from users where exists (
    select 1 from orders where orders.user_id = users.id
)
```

### Условия JSON

October CMS поддерживает запросы к JSON-столбцам в базах данных, где это возможно. Чтобы выполнить запрос к JSON-столбцу, используйте оператор `->`:

```php
$users = Db::table('users')
    ->where('options->language', 'en')
    ->get();

$users = Db::table('users')
    ->where('preferences->dining->meal', 'salad')
    ->get();
```

Методы `whereJsonContains`, `whereJsonLength` и `whereJsonDoesntContain` позволяют фильтровать JSON-массивы. Они поддерживаются MySQL 5.7+, PostgreSQL 9.5+ и SQLite 3.9.0+:

```php
$users = Db::table('users')
    ->whereJsonContains('options->languages', 'en')
    ->get();
```

В MySQL и PostgreSQL метод `whereJsonContains` поддерживает несколько значений:

```php
$users = Db::table('users')
    ->whereJsonContains('options->languages', ['en', 'de'])
    ->get();
```

Метод `whereJsonDoesntContain` проверяет, что значение отсутствует в JSON-массиве (не поддерживается в SQLite).

```php
$users = Db::table('users')
    ->whereJsonDoesntContain('options->languages', 'en')
    ->get();
```

Метод `whereJsonLength` фильтрует JSON-массивы по длине:

```php
$users = Db::table('users')
    ->whereJsonLength('options->languages', 0)
    ->get();

$users = Db::table('users')
    ->whereJsonLength('options->languages', '>', 1)
    ->get();
```

### Условные выражения

Иногда требуется применять условия к запросу только при выполнении определённого требования. Например, добавлять `where` лишь тогда, когда во входящем запросе присутствует конкретное значение. Для этого используется метод `when`:

```php
$role = $request->input('role');

$users = Db::table('users')
    ->when($role, function ($query, $role) {
        return $query->where('role_id', $role);
    })
    ->get();
```

Метод `when` выполняет переданное замыкание только тогда, когда первый параметр имеет значение `true`. Если первый параметр равен `false`, замыкание не выполняется.

В качестве третьего аргумента методу `when` можно передать другое замыкание. Оно выполнится, если первый параметр оказался ложным. Пример ниже демонстрирует настройку сортировки по умолчанию:

```php
$sortBy = null;

$users = Db::table('users')
    ->when($sortBy, function ($query, $sortBy) {
        return $query->orderBy($sortBy);
    }, function ($query) {
        return $query->orderBy('name');
    })
    ->get();
```

## Сортировка, группировка и ограничения

### Сортировка

Метод `orderBy` сортирует результаты по указанному столбцу. Первый аргумент — столбец для сортировки, второй задаёт направление (`asc` или `desc`).

```php
$users = Db::table('users')
    ->orderBy('name', 'desc')
    ->get();
```

Методы `latest` и `oldest` упрощают сортировку по дате. По умолчанию используется столбец `created_at`, но можно передать другое имя столбца.

```php
$user = Db::table('users')
    ->latest()
    ->first();
```

Метод `inRandomOrder` сортирует результаты в случайном порядке. Например, так можно выбрать случайного пользователя.

```php
$randomUser = Db::table('users')
    ->inRandomOrder()
    ->first();
```

### Группировка

Методы `groupBy` и `having` группируют результаты. Сигнатура `having` похожа на метод `where`.

```php
$users = Db::table('users')
    ->groupBy('account_id')
    ->having('account_id', '>', 100)
    ->get();
```

Методу `groupBy` можно передать несколько аргументов для группировки по нескольким столбцам.

```php
$users = Db::table('users')
    ->groupBy('first_name', 'status')
    ->having('account_id', '>', 100)
    ->get();
```

Для более сложных условий `having` используйте метод `havingRaw`.

### Limit и offset

Чтобы ограничить количество возвращаемых записей или пропустить заданное число строк (`OFFSET`), используйте методы `skip` и `take`.

```php
$users = Db::table('users')->skip(10)->take(5)->get();
```

## Вставка записей

Конструктор запросов предоставляет метод `insert` для добавления записей в таблицу. Он принимает массив пар «столбец → значение»:

```php
Db::table('users')->insert(
    ['email' => 'john@example.tld', 'votes' => 0]
);
```

Чтобы вставить несколько записей одним вызовом `insert`, передайте массив массивов. Каждый внутренний массив соответствует отдельной строке:

```php
Db::table('users')->insert([
    ['email' => 'taylor@example.tld', 'votes' => 0],
    ['email' => 'dayle@example.tld', 'votes' => 0]
]);
```

### Автоинкрементируемые идентификаторы

Если в таблице есть автоинкрементируемый идентификатор, используйте метод `insertGetId`, чтобы добавить запись и получить её идентификатор:

```php
$id = Db::table('users')->insertGetId(
    ['email' => 'john@example.tld', 'votes' => 0]
);
```

::: tip
При использовании драйвера PostgreSQL метод `insertGetId` ожидает, что автоинкрементируемый столбец называется `id`. Чтобы получить идентификатор из другой «последовательности», передайте её имя вторым аргументом метода `insertGetId`.
:::

## Обновление записей

Помимо вставки записей, конструктор запросов позволяет обновлять существующие строки методом `update`. Подобно `insert`, он принимает массив пар «столбец → значение» с данными для обновления. Ограничить количество обновляемых строк можно условиями `where`.

```php
Db::table('users')
    ->where('id', 1)
    ->update(['votes' => 1]);
```

### Обновление или вставка

Иногда нужно обновить существующую запись или создать новую, если подходящей записи нет. Для этого предназначен метод `updateOrInsert`. Он принимает два аргумента: массив условий для поиска записи и массив пар «столбец → значение» для обновления.

Метод `updateOrInsert` сначала попытается найти запись по условиям первого аргумента. Если запись найдена, она обновится значениями из второго аргумента. Если запись не найдена, будет создана новая с объединёнными атрибутами обоих аргументов.

```php
Db::table('users')
    ->updateOrInsert(
        ['email' => 'john@example.tld', 'name' => 'John'],
        ['votes' => '2']
    );
```

### Upsert

Метод `upsert` вставляет отсутствующие строки и обновляет уже существующие новыми значениями. Первый аргумент содержит данные для вставки или обновления, второй — список столбцов, которые однозначно идентифицируют запись в таблице. Третий аргумент — массив столбцов, которые нужно обновить при нахождении совпадающей записи.

```php
Db::table('flights')->upsert([
    ['departure' => 'Oakland', 'destination' => 'San Diego', 'price' => 99],
    ['departure' => 'Chicago', 'destination' => 'New York', 'price' => 150]
], ['departure', 'destination'], ['price']);
```

::: tip
Все базы данных, кроме SQL Server, требуют, чтобы столбцы во втором аргументе метода `upsert` имели «первичный» или «уникальный» индекс.
:::

### Обновление JSON-столбцов

При обновлении JSON-столбца используйте синтаксис `->` для доступа к нужному ключу объекта. Операция поддерживается в MySQL 5.7+ и PostgreSQL 9.5+:

```php
$affected = Db::table('users')
    ->where('id', 1)
    ->update(['options->enabled' => true]);
```

### Инкремент и декремент

Конструктор запросов предоставляет методы для увеличения и уменьшения значения столбца. Это сокращённая, более выразительная запись по сравнению с явным вызовом `update`.

Оба метода принимают минимум один аргумент — имя столбца. Необязательный второй аргумент задаёт величину, на которую нужно увеличить или уменьшить значение.

```php
Db::table('users')->increment('votes');

Db::table('users')->increment('votes', 5);

Db::table('users')->decrement('votes');

Db::table('users')->decrement('votes', 5);
```

Во время операции можно обновить и другие столбцы:

```php
Db::table('users')->increment('votes', 1, ['name' => 'John']);
```

## Удаление записей

Конструктор запросов позволяет удалять строки таблицы методом `delete`.

```php
Db::table('users')->delete();
```

Удаление можно ограничить, добавив перед `delete` условия `where`.

```php
Db::table('users')->where('votes', '<', 100)->delete();
```

Чтобы очистить всю таблицу, удалить все строки и сбросить автоинкрементируемый идентификатор в ноль, используйте метод `truncate`.

```php
Db::table('users')->truncate();
```

## Пессимистические блокировки

Конструктор запросов содержит методы для выполнения «пессимистических блокировок» в операторах `select`. Чтобы выполнить запрос с «разделяемой блокировкой», вызовите метод `sharedLock`. Он предотвращает изменение выбранных строк до фиксации транзакции.

```php
Db::table('users')->where('votes', '>', 100)->sharedLock()->get();
```

Альтернативно можно использовать метод `lockForUpdate`. Блокировка «for update» запрещает изменять строки и выбирать их с другой разделяемой блокировкой.

```php
Db::table('users')->where('votes', '>', 100)->lockForUpdate()->get();
```

## Кэширование запросов

Результаты запроса можно легко закэшировать, используя [сервис кэша](../services/cache.md). Просто добавьте к подготовке запроса методы `remember` или `rememberForever`.

```php
$users = Db::table('users')->remember(10)->get();
```

В этом примере результаты будут закэшированы на десять минут. Пока данные находятся в кэше, запрос к базе выполняться не будет, а результаты будут загружаться из драйвера кэша, заданного по умолчанию в приложении.

## Отладка

Во время построения запроса можно использовать методы `dd` или `dump`, чтобы вывести SQL и привязки. Метод `dd` покажет отладочную информацию и остановит выполнение запроса. Метод `dump` также выведет отладочные данные, но позволит запросу продолжить работу.

```php
Db::table('users')->where('votes', '>', 100)->dd();

Db::table('users')->where('votes', '>', 100)->dump();
```
