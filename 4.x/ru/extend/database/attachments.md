# Прикреплённые файлы

Модели могут поддерживать прикрепление файлов, используя подмножество [полиморфной связи](./relations.md). Связи `$attachOne` или `$attachMany` предназначены для привязки файла к записи в базе данных, называемой «вложением». Почти во всех случаях для хранения этой связи используется модель `System\\Models\\File`, где ссылки на файлы сохраняются в таблице `system_files` и имеют полиморфную связь с родительской моделью.

В примерах ниже модель имеет одну связь Avatar и несколько связей Photo.

Одно вложение файла:

```php
public $attachOne = [
    'avatar' => \\System\\Models\\File::class
];
```

Несколько вложений файлов:

```php
public $attachMany = [
    'photos' => \\System\\Models\\File::class
];
```

::: warning
Чтобы избежать конфликта имён, убедитесь, что в таблице базы данных вашей модели нет атрибута с таким же именем, как у связи вложения.
:::

Защищённые вложения загружаются в каталог приложения **uploads/protected**, который недоступен для прямого доступа из веба. Защищённое вложение определяется установкой свойства `public` в значение `false`.

```php
public $attachOne = [
    'avatar' => [\\System\\Models\\File::class, 'public' => false]
];
```

## Создание вложений

Для одиночных связей (`$attachOne`) вложение можно создать напрямую через связь модели, присвоив значение с помощью функции `files`, которая считывает данные файла из загруженного ввода.

```php
$model->avatar = files('file_input');
```

Чтобы привязать новый файл с локального пути, используйте модель `System\\Models\\File` и метод `fromFile`.

```php
$model->avatar = (new File)->fromFile('/path/to/somefile.jpg');
```

Чтобы создать файл непосредственно из (сырых) данных, используйте метод `fromData`, передавая содержимое (первый аргумент) и имя файла (второй аргумент).

```php
$model->avatar = (new File)->fromData('Some content', 'sometext.txt');
```

Также можно добавить файл по URL с помощью метода `fromUrl`. Для его использования требуется установленное расширение PHP cURL.

```php
$model->avatar = (new File)->fromUrl('https://example.tld/path/to/avatar.jpg');
```

При необходимости можно указать пользовательское имя файла (второй аргумент).

```php
$model->avatar = (new File)->fromUrl('https://example.tld/avatar.jpg', 'customname.jpg');
```

### Работа с несколькими вложениями

Для множественных связей (`$attachMany`) можно передать массив значений из функции `files()`.

```php
$model->photos = (array) files('multi_file');
```

Можно использовать метод `create`, чтобы добавить файл к существующей связи. Обратите внимание, что объект файла привязывается к атрибуту `data`. Этот подход также подходит для одиночных связей, если он удобнее.

```php
$model->photos()->create(['data' => files('file_input')]);
```

Можно вызвать метод `add` у связи, чтобы работать напрямую с моделью `System\\Models\\File`.

```php
$model->photos()->add(
    $model->photos()->make()->fromFile('/path/to/somefile.jpg')
);
```

Либо подготовить модель File заранее и затем вручную связать её. Обратите внимание, что атрибут `is_public` при таком подходе нужно задавать явно.

```php
$file = new \\System\\Models\\File;
$file->data = files('file_input');
$file->is_public = true;
$file->save();

$model->photos()->add($file);
```

## Просмотр вложений

Метод `getUrl` возвращает полный URL загруженного публичного файла. Следующий код выведет что-то вроде **example.tld/uploads/public/path/to/avatar.jpg**.

```php
echo $model->avatar->getUrl();
```

Возврат путей к нескольким вложениям.

```php
foreach ($model->photos as $photo) {
    echo $photo->getUrl();
}
```

Вывод файла на странице с помощью Twig.

```twig
<img src="{{ model.avatar.url }}" alt="Description Image" />
```

### Доступ к локальному пути

Метод `getLocalPath` возвращает абсолютный путь загруженного файла в локальной файловой системе. При использовании внешнего драйвера, например S3, метод скачает содержимое во временное расположение в локальной файловой системе.

```php
echo $model->avatar->getLocalPath();
```

## Изменение размера миниатюр

Изображение можно изменить методом `getThumbUrl`. Метод принимает три параметра: ширину, высоту и параметр options.

Параметры **width** и **height** нужно указывать числом или словом **auto** для пропорционального масштабирования.

```php
echo $model->avatar->getThumbUrl(100, 100, ['mode' => 'crop']);
```

Вывод изображения на странице с помощью Twig.

```twig
<img src="{{ model.avatar.thumbUrl(100, 100, { mode: 'exact', quality: 80, extension: 'webp' }) }}" alt="Description Image" />
```

Подробнее о доступных параметрах `getThumbUrl` читайте в [статье про ресайзер изображений](../services/resizer.md).

## Вывод и загрузка

Чтобы вывести содержимое файла напрямую, используйте метод `output`. Он вернёт [объект ответа](../services/response-view.md) с заголовками, необходимыми для отображения файла в браузере.

```php
return $model->avatar->output();
```

Можно отправить содержимое в браузер, добавив вызов метода `send`.

```php
$model->avatar->output()->send();
```
