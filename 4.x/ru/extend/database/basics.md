# Базовое использование

Подключение к базам данных и выполнение запросов — простой процесс, доступный через чистый SQL, [конструктор запросов](./query.md) или [модели Active Record](./model.md). Управление таблицами базы данных и заполнение начальными данными выполняется с помощью [миграций и загрузчиков данных](./structure.md).

Чистый SQL и использование конструктора запросов работают быстрее и подходят для простых задач. Active Record — подход, применяемый популярным фреймворком Ruby On Rails. Он обеспечивает удобный интерфейс для повторяющихся операций — создания, чтения, обновления и удаления записей базы данных. Подробнее см. [статью об Active Record на Wikipedia](http://en.wikipedia.org/wiki/Active_record_pattern).

## Выполнение чистых SQL-запросов

После настройки подключения к базе данных можно выполнять запросы через фасад `Db`. Фасад `Db` предоставляет методы для каждого типа запроса: `select`, `update`, `insert`, `delete` и `statement`.

### Выборка записей

Чтобы выполнить простой запрос, используйте метод `select` фасада `Db`.

```php
$users = Db::select('select * from users where active = ?', [1]);
```

Первый аргумент, переданный методу `select`, — это SQL-запрос, второй аргумент содержит привязки параметров, которые необходимо подставить в запрос. Обычно это значения условий `where`. Привязка параметров защищает от SQL-инъекций.

Метод `select` всегда возвращает `array` с результатами. Каждый элемент массива — объект PHP `stdClass`, что позволяет обращаться к значениям результатов:

```php
foreach ($users as $user) {
    echo $user->name;
}
```

Вместо использования `?` для обозначения привязок параметров можно выполнить запрос, применяя именованные привязки.

```php
$results = Db::select('select * from users where id = :id', ['id' => 1]);
```

Если SQL-запрос возвращает единственное значение, его можно получить методом `scalar`.

```php
$count = Db::scalar('select count(*) as count from menu_items');
```

### Изменение записей

Для выполнения оператора `insert` используйте метод `insert` фасада `Db`. Как и `select`, этот метод принимает SQL-запрос первым аргументом и привязки вторым.

```php
Db::insert('insert into users (id, name) values (?, ?)', [1, 'Joe']);
```

Метод `update` применяют для обновления существующих записей в базе данных. Метод возвращает количество строк, затронутых оператором:

```php
$affected = Db::update('update users set votes = 100 where name = ?', ['John']);
```

Метод `delete` используют для удаления записей из базы данных. Как и `update`, он возвращает количество удалённых строк:

```php
$deleted = Db::delete('delete from users');
```

### Общие выражения

Некоторые операторы базы данных не должны возвращать значение. Для таких операций используйте метод `statement` фасада `Db`.

```php
Db::statement('drop table users');
```

## Несколько подключений к базе данных

При [использовании нескольких подключений](../../setup/database-config.md) можно обращаться к каждому через метод `connection` фасада `Db`. Имя, переданное методу `connection`, должно соответствовать одному из подключений, перечисленных в конфигурационном файле `config/database.php`.

```php
$users = Db::connection('foo')->select(...);
```

Также можно получить исходный экземпляр PDO через метод `getPdo` объекта подключения.

```php
$pdo = Db::connection()->getPdo();
```

## Транзакции базы данных

Чтобы выполнить набор операций в рамках транзакции, используйте метод `transaction` фасада `Db`. Если внутри переданного `Closure` произойдёт исключение, транзакция автоматически откатится. Если `Closure` завершится успешно, транзакция автоматически зафиксируется. При использовании метода `transaction` не нужно вручную заботиться об откате или фиксации.

```php
Db::transaction(function () {
    Db::table('users')->update(['votes' => 1]);

    Db::table('posts')->delete();
});
```

Если требуется вручную открыть транзакцию и полностью контролировать откаты и фиксацию, используйте метод `beginTransaction` фасада `Db`:

```php
Db::beginTransaction();
```

Откатить транзакцию можно методом `rollBack`:

```php
Db::rollBack();
```

Зафиксировать транзакцию позволяет метод `commit`:

```php
Db::commit();
```

::: tip
Методы фасада `Db` для транзакций также управляют транзакциями [конструктора запросов](./query.md) и [запросов моделей](./model.md).
:::

## События базы данных

Если требуется получать каждое SQL-выражение, выполняемое приложением, используйте метод `listen`. Он полезен для логирования запросов или отладки.

```php
Db::listen(function($sql, $bindings, $time) {
    //
});
```

Слушатель запросов можно зарегистрировать в методе `boot` [файла регистрации плагина](../extending.md). Также можно разместить эту логику в файле **init.php**, который плагин может предоставить в своей директории.

### Логирование запросов

Когда логирование запросов включено, в памяти хранится журнал всех запросов, выполненных в рамках текущего запроса. Вызовите метод `enableQueryLog`, чтобы активировать эту возможность.

```php
Db::connection()->enableQueryLog();
```

Чтобы получить массив выполненных запросов, используйте метод `getQueryLog`:

```php
$queries = Db::getQueryLog();
```

Однако в некоторых случаях, например при вставке большого числа строк, журнал может потреблять слишком много памяти. Чтобы отключить его, вызовите метод `disableQueryLog`:

```php
Db::connection()->disableQueryLog();
```

::: tip
Для быстрой отладки может быть полезнее вызвать [вспомогательную функцию](../services/log.md) `trace_sql`.
:::
