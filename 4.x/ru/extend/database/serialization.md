# Сериализация

При создании JSON-API часто требуется преобразовать модели и их связи в массивы или JSON. Модели предоставляют удобные методы для таких преобразований, а также позволяют управлять тем, какие атрибуты попадут в сериализованный результат.

## Базовое использование

#### Преобразование модели в массив

Чтобы преобразовать модель и загруженные [связи](./relations.md) в массив, используйте метод `toArray`. Он работает рекурсивно, поэтому в массив будут конвертированы все атрибуты и все связи (включая связи связей):

```php
$user = User::with('roles')->first();

return $user->toArray();
```

Можно преобразовать в массив и [коллекцию](./collections.md):

```php
$users = User::all();

return $users->toArray();
```

#### Преобразование модели в JSON

Чтобы преобразовать модель в JSON, используйте метод `toJson`. Как и `toArray`, этот метод рекурсивно конвертирует все атрибуты и связи в JSON:

```php
$user = User::find(1);

return $user->toJson();
```

Также можно привести модель или коллекцию к строке — автоматически будет вызван метод `toJson`:

```php
$user = User::find(1);

return (string) $user;
```

Поскольку модели и коллекции при приведении к строке конвертируются в JSON, объекты моделей можно возвращать напрямую из маршрутов, AJAX-обработчиков или контроллеров:

```php
Route::get('users', function () {
    return User::all();
});
```

## Сокрытие атрибутов в JSON

Иногда необходимо исключить определённые атрибуты, например пароли, из массивного или JSON-представления модели. Для этого добавьте в модель свойство `$hidden`:

```php
namespace Acme\Blog\Models;

use Model;

class User extends Model
{
    /**
     * Атрибуты, скрываемые при преобразовании в массив.
     *
     * @var array
     */
    protected $hidden = ['password'];
}
```

Либо используйте свойство `$visible`, чтобы перечислить атрибуты, которые должны присутствовать в массиве и JSON:

```php
class User extends Model
{
    /**
     * Атрибуты, видимые при преобразовании в массив.
     *
     * @var array
     */
    protected $visible = ['first_name', 'last_name'];
}
```

## Добавление значений в JSON

Иногда нужно добавить в вывод атрибуты, для которых нет отдельной колонки в базе данных. Для этого сначала определите [аксессор](./mutators.md) для значения:

```php
class User extends Model
{
    /**
     * Получить флаг администратора для пользователя.
     *
     * @return bool
     */
    public function getIsAdminAttribute()
    {
        return $this->attributes['admin'] == 'yes';
    }
}
```

После создания аксессора добавьте имя атрибута в свойство `appends` модели:

```php
class User extends Model
{
    /**
     * Аксессоры, добавляемые к массивному представлению модели.
     *
     * @var array
     */
    protected $appends = ['is_admin'];
}
```

После добавления в список `appends` атрибут будет включён и в массивное, и в JSON-представление модели. Он также учитывает настройки `visible` и `hidden`, заданные для модели.
