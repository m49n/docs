# Пользователи

Управление пользователями бэкенда работает с администраторами, а модель `Backend\Models\User` хранит всю важную информацию о пользователе. Она включает функции ролей, групп, прав, сброса паролей и защиты от частых попыток входа. Плагины также могут [регистрировать права](./permissions.md), которые контролируют доступ к функциям бэкенда.

## Вспомогательный фасад пользователей бэкенда

Глобальный фасад `BackendAuth`, в основе которого лежит класс `October\Rain\Auth\Manager`, используется для работы с администраторами. Чтобы зарегистрировать нового пользователя-администратора, примените метод `BackendAuth::register`.

```php
$user = BackendAuth::register([
    'first_name' => 'Some',
    'last_name' => 'User',
    'login' => 'someuser',
    'email' => 'some@website.tld',
    'password' => 'changeme',
    'password_confirmation' => 'changeme'
]);
```

Метод `BackendAuth::check` — быстрый способ проверить, вошёл ли пользователь. Чтобы вернуть модель пользователя, который вошёл в систему, используйте `BackendAuth::getUser`. Кроме того, активный пользователь доступен как `$this->user` в любом [контроллере бэкенда](../system/controllers.md).

```php
// Возвращает true, если выполнен вход
$loggedIn = BackendAuth::check();

// Возвращает вошедшего пользователя
$user = BackendAuth::getUser();
```

Можно найти пользователя по логину методом `BackendAuth::findUserByLogin`.

```php
$user = BackendAuth::findUserByLogin('someuser');
```

Можно аутентифицировать пользователя, передав его логин и пароль в `BackendAuth::authenticate`. Также можно авторизоваться от имени пользователя, передав модель `Backend\Models\User` в `BackendAuth::login`.

```php
// Аутентификация по учётным данным
$user = BackendAuth::authenticate([
    'login' => post('login'),
    'password' => post('password')
]);

// Вход под конкретным пользователем
BackendAuth::login($user);
```

## Группы

Группы пользователей используют модель `Backend\Models\UserGroup` и служат для организационного объединения администраторов; они не связаны с [правами пользователей](./permissions.md) и применяются исключительно для организационных задач, например уведомлений.

Например, если требуется отправить электронное письмо всем пользователям из группы `Head Office Staff`, найдите группу вместе с её пользователями.

```php
$group = UserGroup::where('code', 'head-office-staff')->first();

Mail::sendTo($group->users, 'author.plugin:important_notification');
```

## Смена пароля пользователя бэкенда

Команда `october:passwd` позволяет сменить пароль администратора бэкенда через командную строку. Это полезно, если нет доступа к установке October CMS или нужно изменить пароль учётной записи администратора по умолчанию.

```bash
php artisan october:passwd username password
```

В качестве первого аргумента можно указать логин или адрес электронной почты. Вторым аргументом можно передать нужный пароль, иначе команда предложит ввести его вручную.
