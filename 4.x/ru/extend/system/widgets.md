# Виджеты

Виджеты — это повторно используемые элементы управления с пользовательским интерфейсом и бэкенд-контроллером (классом виджета), который подготавливает данные и обрабатывает AJAX-запросы, генерируемые интерфейсом виджета.

## Универсальные виджеты

Виджеты в бэкенде — эквивалент [компонентов CMS](../../cms/themes/components.md). Они похожи тем, что представляют собой модульные наборы функциональности, предоставляют частичные представления и используют псевдонимы. Ключевое отличие: виджеты бэкенда используют YAML-разметку для конфигурации и привязываются к контроллерам вручную.

Классы виджетов размещаются в каталоге **widgets** плагина. Имя вложенного каталога совпадает с именем класса виджета, записанным строчными буквами. Виджеты могут поставлять ресурсы и частичные представления. Пример структуры каталога виджета:

::: dir
├── `widgets`
|   ├── form
|   |   ├── partials
|   |   |   └── _form.php  _← Частичное представление_
|   |   └── assets
|   |       ├── js
|   |       |   └── form.js  _← JavaScript_
|   |       └── css
|   |           └── form.css  _← Таблица стилей_
|   └── Form.php  _← Класс виджета_
:::

### Определение класса

Универсальные виджеты должны наследовать `Backend\Classes\WidgetBase`. Как и другие классы плагина, контроллеры виджетов должны принадлежать [пространству имён плагина](./plugins.md). Пример определения класса виджета:

```php
namespace Backend\Widgets;

use Backend\Classes\WidgetBase;

class Lists extends WidgetBase
{
    /**
     * @var string defaultAlias to identify this widget.
     */
    protected $defaultAlias = 'list';

    // ...
}
```

Класс виджета должен содержать метод **render()**, который выводит разметку, рендеря частичное представление:

```php
public function render()
{
    return $this->makePartial('list');
}
```

Для передачи переменных в частичные представления добавьте их в свойство `$vars`:

```php
public function render()
{
    $this->vars['var'] = 'value';

    return $this->makePartial('list');
}
```

Либо передайте переменные вторым аргументом метода `makePartial()`:

```php
public function render()
{
    return $this->makePartial('list', ['var' => 'value']);
}
```

## Привязка виджетов к контроллерам

::: aside
Привязка к контроллеру также необходима, чтобы [AJAX-обработчики](./ajax.md) стали доступными.
:::

Перед использованием виджет нужно привязать к контроллеру бэкенда. Для привязки используйте метод `bindToController`. Наилучшее место для инициализации — метод `beforeDisplay` контроллера, вызываемый из конструктора.

Пример создания экземпляра виджета и привязки к контроллеру. Обратите внимание: конструктор принимает контроллер первым аргументом.

```php
public function beforeDisplay()
{
    $myWidget = new MyWidgetClass($this);
    $myWidget->alias = 'myWidget';
    $myWidget->bindToController();
}
```

После привязки к контроллеру виджет доступен в представлениях и частичных представлениях по своему псевдониму через свойство `$this->widget`.

```php
<?= $this->widget->myWidget->render() ?>
```

## Выполнение кода до AJAX-обработчиков

Иногда требуется выполнить код до запуска AJAX-обработчика. Определите метод `init` в виджете, чтобы код выполнялся перед каждым обработчиком.

```php
function init()
{
    // From a widget class
}
```
