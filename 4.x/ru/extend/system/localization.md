# Локализация

::: aside
Строки, определённые здесь, загружаются только в панели бэкенда. Для перевода содержимого фронтенда см. статью [Локализация темы](../../cms/themes/settings.md).
:::

Плагины могут содержать файлы локализации в подкаталоге **lang**. Файлы локализации плагинов используют формат JSON и автоматически обнаруживаются системой в панели бэкенда. Строки локализации поддерживаются нативно в пользовательском интерфейсе бэкенда: меню, метках форм и т. д.

## Активный язык

Язык по умолчанию хранится в параметре `locale` конфигурационного файла `config/app.php`. Значение можно изменить под нужды приложения. Каждый пользователь может выбрать предпочитаемую локаль через пункт **User Menu → Backend Preferences**.

Проверить активный язык в PHP можно методом `App::getLocale`, а установить активный язык — методом `App::setLocale`, который принимает код языка первым аргументом.

```php
App::getLocale();

App::setLocale('fr');
```

## Структура файлов локализации

Ниже приведён пример каталога **lang** плагина.

::: dir
├── plugins
|   └── acme
|       └── todo
|           └── `lang`
|               ├── en.json  _← Файл локализации_
|               └── fr.json  _← Файл локализации_
:::

Для локализации предпочтительнее использовать JSON-файлы, где ключом служит «базовый» перевод строки. Например, если приложение имеет французский перевод, создайте файл `lang/fr.json`.

```json
{
    "I love programming.": "j'adore programmer"
}
```

::: tip
Laravel предоставляет альтернативный вариант перевода на основе PHP-файлов. Подробнее см. статью [Laravel Localization](https://laravel.com/docs/12.x/localization).
:::

## Доступ к строкам локализации

Строки локализации загружаются через хелпер `__()`, в который передаётся базовый перевод строки.

```php
echo __('I love programming.');
```

Чтобы заменить параметры в переводе, передайте массив вторым аргументом. Каждый параметр начинается с символа `:`.

```php
echo __(':name loves programming.', ['name' => 'Jeff']);
```

### Формы множественного числа

В разных языках используются сложные правила множественного числа. С помощью символа `|` можно разделить формы единственного и множественного числа.

```json
{
    "There is one apple|There are many apples": "Il y a une pomme|Il y a beaucoup de pommes"
}
```

Более сложные правила позволяют задавать переводы для диапазонов значений.

```json
{
    "{0} There are none|[1,19] There are some|[20,*] There are many": "..."
}
```

Для обработки форм множественного числа используется функция `trans_choice`.

```php
echo __('There is one apple|There are many apples', 3);
```

## Переопределение строк локализации

Пользователи системы могут переопределять строки локализации плагинов без изменения их файлов. Для этого добавьте файлы локализации в каталог **lang**. Например, чтобы переопределить французские переводы, создайте файл по следующему пути:

::: dir
├── app
|   └── `lang`
|       └── fr.json  _← Файл переопределения_
:::

Файл может содержать только строки, которые нужно заменить; нет необходимости копировать весь файл. Пример:

```json
{
    "I love programming.": "Coding is the best!"
}
```

Некоторые плагины поставляются с собственными PHP-файлами локализации. Их можно переопределить в том же каталоге. В JSON-файле используйте полный ключ локализации, например, чтобы переопределить значение `rainlab.blog::lang.post_label`.

```json
{
    "rainlab.blog::lang.post_label": "Article"
}
```

Можно также использовать вложенную структуру каталогов для переопределения файла в PHP-формате. Например, плагин **Acme.Blog** размещает файл по пути `lang/acme/blog/en/lang.php`.

::: dir
├── app
|   └── lang
|       └── `acme`  _← Автор плагина_
|           └── `todo`  _← Имя плагина_
|               └── en
|                   └── lang.php  _← Файл переопределения_
:::

### Переопределение строк программно

Переопределить строки локализации в PHP можно методом `Lang::set`. Он принимает ключ локализации и новое значение перевода.

```php
Lang::set('I love programming.', 'Coding is the best!');
```

По умолчанию изменяется активная локаль; третий аргумент позволяет указать конкретную локаль. В следующем примере заменяется значение для французского языка.

```php
Lang::set('I love programming.', 'Le codage est le meilleur!', 'fr');
```

## Внесение строк локализации

October CMS использует сервис Crowdin для управления переводами популярных языков. Для остальных языков выполняется автоматический машинный перевод через API Google Translate. Если обнаружены отсутствующие или некорректные переводы в October CMS, выполните действия ниже.

### Использование Crowdin

Проверьте, поддерживается ли ваш язык в проекте Crowdin, по ссылке ниже. Сервис позволяет вносить переводы через удобный интерфейс.

- [Страница проекта October CMS на Crowdin](https://crowdin.com/project/octobercms)

Если вашего языка нет на странице, следуйте GitHub-инструкции ниже. Языки добавляются в Crowdin, когда мы видим их активность на GitHub.

### Использование GitHub

Предложить обновления для языка можно в [репозитории на GitHub](https://github.com/octobercms/october/tree/develop/modules), отправив pull request. Файлы локализации находятся в различных модулях, поэтому может понадобиться проверить несколько файлов, чтобы найти нужную строку. В этом примере мы изменяем голландский перевод (`nl`) и знаем, что строка находится в модуле Tailor.

1. Откройте [репозиторий на GitHub](https://github.com/octobercms/october/tree/develop/modules).
2. Нажмите **tailor**, затем **lang**, чтобы открыть каталог локализации модуля Tailor.
3. Откройте файл **nl.json** — это языковой файл для голландского языка.
4. В правом верхнем углу нажмите значок карандаша, чтобы **Edit this file**.

В файле слева отображается английский вариант, справа — голландский, например:

```json
{
  "Manage Entries": "Invoer beheren",
  "Create :name Entry": "Maak :name invoer"
}
```

При обновлении изменяйте только правую часть со значением перевода. Некоторые значения содержат переменные, например `:name`, — их следует оставить без изменений. По завершении нажмите **Commit changes**, чтобы отправить новый pull request. Команда проверит его и включит в последующие релизы.

::: tip
Если ключ локализации отсутствует или вы не можете его найти, [свяжитесь с нами](https://octobercms.com/contact).
:::
