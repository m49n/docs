# AJAX

Панель бэкенда использует ту же [AJAX-библиотеку, что и страницы CMS](../../ajax/introduction.md). Библиотека подключается и загружается автоматически на страницах бэкенда.

## AJAX-обработчики бэкенда

AJAX-обработчики бэкенда можно определить в классе контроллера или виджетах. В контроллере AJAX-обработчики задаются как публичные методы с именами, начинающимися со строки «on»: **onCreateTemplate**, **onGetTemplateList** и другие.

AJAX-обработчики бэкенда могут возвращать массив данных, выбрасывать исключение или перенаправлять на другую страницу. Можно использовать `$this->vars` для установки переменных и метод `makePartial` контроллера, чтобы отрисовать частичное представление и вернуть его содержимое как часть данных ответа.

```php
public function onOpenTemplate()
{
    if (post('someVar') !== 'someValue') {
        throw new ApplicationException('Invalid value');
    }

    $this->vars['foo'] = 'bar';

    return [
        'partialContents' => $this->makePartial('some-partial')
    ];
}
```

### Инициирование AJAX-запросов

AJAX-запрос можно инициировать с помощью API дата-атрибутов или JavaScript-API. См. [фронтенд-библиотеку AJAX](../../ajax/introduction) для подробностей. В следующем примере показано, как инициировать запрос с кнопки бэкенда.

```html
<button
    type="button"
    data-request="onDoSomething"
    class="btn btn-default">
    Do Something
</button>
```

## AJAX-обработчики поведений

Поскольку поведение (behavior) объединяет свои методы с родительским контроллером, все AJAX-обработчики, определённые в поведении, доступны контроллеру. В некоторых случаях требуется переопределить AJAX-обработчик в контроллере — это можно сделать, вызвав метод `asExtension`.

AJAX-обработчик контроллера имеет приоритет, затем запрашивается поведение `Backend\Behaviors\FormController` и вызывается его обработчик.

```php
function onDoSomething()
{
    // Custom logic here
    // ...

    // Call the extension handler
    return $this->asExtension('FormController')->doSomething();
}
```

## AJAX-обработчики виджетов

Виджеты используют тот же подход AJAX, что и контроллеры бэкенда. AJAX-обработчики — это публичные методы класса виджета с именами, начинающимися с префикса **on**. Единственное отличие AJAX-обработчиков виджетов от AJAX-обработчиков контроллеров бэкенда в том, что при обращении к ним из частичных представлений виджета нужно использовать метод `getEventHandler`, чтобы вернуть имя обработчика виджета.

```php
<a
    href="javascript:;"
    data-request="<?= $this->getEventHandler('onPaginate') ?>"
    title="Next page">Next</a>
```

При вызове из класса или частичного представления виджета AJAX-обработчик будет обращаться к самому себе. Например, если виджету присвоен псевдоним **mywidget**, обработчик будет вызван как `mywidget::onName`. В приведённом выше примере значение атрибута будет таким:

```html
data-request="mywidget::onPaginate"
```
