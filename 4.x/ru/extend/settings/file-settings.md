# Файловые настройки

Файловые настройки хранят значения в файлах и могут быть переопределены переменными окружения или файлами приложения.

## Структура конфигурационных файлов

Плагины могут использовать конфигурацию на файлах, размещая конфигурационные файлы в подкаталоге **config** каталога плагина. Ниже приведён пример каталога **config** плагина.

::: dir
├── plugins
|   └── acme
|       └── todo
|           └── `config`
|               ├── config.php  _← Конфигурационный файл_
|               └── custom.php  _← Конфигурационный файл_
:::

Конфигурационные файлы — это PHP-скрипты, которые определяют и возвращают **массив**. Ниже показан пример конфигурационного файла **config.php**.

```php
return [
    'maxItems' => 10,
    'display' => 5
];
```

## Доступ к значениям конфигурации

Для доступа к значениям конфигурации, заданным в файле, используйте фасад `Config`. Метод `get` принимает имя плагина и конфигурации (первый аргумент) в формате **acme.demo::maxItems**. Можно также задать значение по умолчанию (второй аргумент), которое вернётся, если параметр конфигурации отсутствует.

```php
$maxItems = Config::get('acme.demo::maxItems', 50);
```

Использование другого имени файла конфигурации влияет на имя ключа. Например, файл конфигурации **custom.php** добавит префикс `custom`, создавая ключ в формате **acme.demo::custom.maxItems**. Следующий пример основан на конфигурационном файле **custom.php**.

```php
$maxItems = Config::get('acme.demo::custom.maxItems', 50);
```

## Переопределение значений конфигурации

Конфигурацию плагина можно переопределить на уровне приложения, создав локальный конфигурационный файл с таким же именем. Например, чтобы переопределить **plugins/acme/demo/config/config.php**, создайте файл **config/acme/todo/config.php**.

::: dir
├── config
|   └── `acme`
|       └── `todo`
|           └── config.php  _← Файл переопределения_
:::

В переопределённом конфигурационном файле можно возвращать только те значения, которые требуется изменить.

```php
return [
    'maxItems' => 20
];
```

Если нужно использовать разные конфигурации для окружений (например, **dev**, **production**), примените хелпер `env()` для получения значения из переменной окружения. Функция `env()` принимает имя переменной окружения (первый аргумент) и необязательное значение по умолчанию, если переменная отсутствует (второй аргумент).

```php
<?php

return [
    'maxItems' => env('ACME_TODO_MAX_ITEMS', 25)
];
```

Это изменит значение `maxItems`, когда переменная окружения `ACME_TODO_MAX_ITEMS` будет установлена в любое другое значение, например в файле приложения **.env**. См. [статью о конфигурации](../../setup/configuration.md), чтобы узнать, как менять эти значения в зависимости от окружения.

```ini
ACME_TODO_MAX_ITEMS=10
```
