# Session

Поскольку приложения на HTTP являются статeless, сессии позволяют сохранять сведения о пользователе между запросами. October CMS включает несколько интерфейсов сессий, доступных через унифицированный API. Из коробки поддерживаются популярные сервисы, такие как [Memcached](http://memcached.org), [Redis](https://redis.io) и базы данных.

## Конфигурация

Параметры сессий хранятся в `config/session.php`. Ознакомьтесь с вариантами настроек, доступными в этом файле.

- `file` — сессии сохраняются в `storage/framework/sessions`.
- `cookie` — сессии сохраняются в безопасных зашифрованных cookie.
- `database` — сессии сохраняются в базе данных приложения.
- `memcached` / `redis` — сессии сохраняются в одном из этих быстрых кеширующих хранилищ.
- `array` — сессии хранятся во внутреннем массиве PHP и не сохраняются между запросами.

По умолчанию October CMS использует драйвер `file`, который подойдёт большинству приложений. Драйвер `array` обычно применяют при запуске модульных тестов, чтобы данные сессии не сохранялись.

## Сохранение данных

Фасад `Session` предоставляет набор методов для работы с данными. Например, метод `put` сохраняет новое значение в сессии.

```php
Session::put('key', 'value');
```

::: warning
October CMS использует ключ сессии `flash` внутренне, поэтому не следует использовать его в качестве имени ключа.
:::

Метод `push` добавляет новое значение к элементу сессии, который является массивом. Например, если ключ `user.teams` содержит массив с названиями команд, можно добавить новое значение в массив следующим образом:

```php
Session::push('user.teams', 'developers');
```

## Получение данных

При получении значения из сессии можно передать значение по умолчанию вторым аргументом метода `get`. Оно будет возвращено, если указанный ключ отсутствует. Если передать `Closure` в качестве значения по умолчанию, будет выполнено замыкание и возвращён его результат.

```php
$value = Session::get('key');

$value = Session::get('key', 'default');

$value = Session::get('key', function() { return 'default'; });
```

Чтобы получить все данные сессии, используйте метод `all`.

```php
$data = Session::all();
```

Метод `has` проверяет наличие элемента в сессии. Он возвращает `true`, если элемент существует.

```php
if (Session::has('users')) {
    //
}
```

## Удаление данных

Метод `pull` возвращает значение и удаляет его из сессии.

```php
$value = Session::pull('key', 'default');
```

Метод `forget` удаляет значение из сессии. Чтобы удалить все данные сессии, применяется метод `flush`.

```php
Session::forget('key');

Session::flush();
```

## Регенерация сессии

При необходимости сменить идентификатор сессии используется метод `regenerate`.

```php
Session::regenerate();
```

Чтобы одновременно изменить идентификатор сессии и удалить все данные, применяют метод `invalidate`.

```php
Session::invalidate();
```

## Flash-данные

Иногда требуется сохранить данные в сессии только до следующего запроса. Для этого служит метод `Session::flash`. Значения, сохранённые таким способом, будут доступны только в течение следующего HTTP-запроса, после чего будут удалены. Flash-данные удобны для краткоживущих статусных сообщений.

```php
Session::flash('key', 'value');
```

Если нужно сохранить flash-данные ещё на несколько запросов, применяют метод `reflash`, который продлевает все flash-данные ещё на один запрос. Чтобы оставить только конкретные значения, используется метод `keep`.

```php
Session::reflash();

Session::keep(['username', 'email']);
```
