# Формы и HTML

## Введение

October CMS предоставляет различные полезные функции фасада `Html`, упрощающие работу с HTML и формами. Хотя в примерах используется PHP, все возможности напрямую доступны и в [разметке Twig](../../markup/templating.md) с простой конвертацией.

```
// PHP
<?= Form::open(..) ?>

// Twig
{{ form_open(...) }}
```

Как видно выше, в Twig все функции с префиксом `form_` напрямую привязаны к фасаду `Form` и предоставляют доступ к методам в формате *snake_case*. Подробности см. в [руководстве по разметке](../../markup/function/form.md) о применении хелпера форм на фронтенде.

## Открытие формы

Форму можно открыть методом `Form::open`, передав массив атрибутов первым аргументом:

```php
<?= Form::open(['url' => 'foo/bar']) ?>
    //
<?= Form::close() ?>
```

По умолчанию используется метод `POST`, но при необходимости можно указать другой метод:

```php
Form::open(['url' => 'foo/bar', 'method' => 'put'])
```

::: tip
Поскольку HTML-формы поддерживают только методы `POST` и `GET`, методы `PUT` и `DELETE` будут эмулированы путём автоматического добавления скрытого поля `_method` в форму.
:::

Можно передать и обычные HTML-атрибуты:

```php
Form::open(['url' => 'foo/bar', 'class' => 'pretty-form'])
```

Если форма должна принимать файлы, добавьте в массив параметр `files`:

```php
Form::open(['url' => 'foo/bar', 'files' => true])
```

Формы также можно открывать, указывая методы-обработчики на странице или в компонентах:

```php
Form::open(['request' => 'onSave'])
```

#### Формы с поддержкой AJAX

Аналогично, формы с поддержкой AJAX открываются методом `Form::ajax`, где первым аргументом выступает имя обработчика:

```php
Form::ajax('onSave')
```

Второй аргумент `Form::ajax` содержит атрибуты:

```php
Form::ajax('onSave', ['confirm' => 'Are you sure?'])
```

Можно также передать частичные представления для обновления отдельным массивом:

```php
Form::ajax('onSave', ['update' => [
        'control-panel' => '#controlPanel',
        'layout/sidebar' => '#layoutSidebar'
    ]
])
```

::: tip
Большинство [data-атрибутов AJAX-фреймворка](../../ajax/attributes-api.md) доступны здесь — достаточно опустить префикс `data-request-`.
:::

## Токены форм

#### Защита от CSRF

При включённой [защите](../../setup/configuration.md) использование метода `Form::open` с `POST`, `PUT` или `DELETE` автоматически добавит в форму скрытое поле с CSRF-токеном. Если требуется сгенерировать HTML для скрытого поля вручную, используйте метод `token`:

```php
<?= Form::token() ?>
```

#### Ключ сессии отложенного связывания

Ключ сессии для [отложенного связывания](../database/relations.md) добавляется в каждую форму как скрытое поле. Чтобы сгенерировать его вручную, используйте метод `sessionKey`:

```php
<?= Form::sessionKey() ?>
```

## Привязка форм к модели

#### Открытие формы модели

Иногда необходимо заполнить форму данными модели. Для этого используйте метод `Form::model`:

```php
<?= Form::model($user, ['id' => 'userForm']) ?>
```

Теперь при генерации элемента формы, например текстового поля, значение модели с именем, совпадающим с именем поля, автоматически станет значением поля. То есть для текстового поля `email` значение атрибута `email` модели пользователя будет установлено в поле. Если во flash-данных сессии есть элемент с таким же именем ввода, он имеет приоритет над значением модели. Порядок приоритета следующий:

1. Flash-данные сессии (старый ввод)
2. Явно переданное значение
3. Данные атрибутов модели
4. Существующее значение постбэка

Это позволяет быстро создавать формы, которые не только привязаны к значениям модели, но и легко восстанавливают введённые данные при ошибке валидации на сервере. Эти значения можно получить вручную через `Form::value`:

```php
<input type="text" name="name" value="<?= Form::value('name') ?>" />
```

Можно передать значение по умолчанию вторым аргументом:

```php
<?= Form::value('name', 'John Travolta') ?>
```

::: warning
При использовании `Form::model` не забудьте закрыть форму методом `Form::close`!
:::

## Метки

#### Создание элемента label

```php
<?= Form::label('email', 'E-Mail Address') ?>
```

#### Указание дополнительных HTML-атрибутов

```php
<?= Form::label('email', 'E-Mail Address', ['class' => 'awesome']) ?>
```

::: tip
После создания метки любой элемент формы с именем, совпадающим с именем метки, автоматически получит идентификатор с тем же именем.
:::

## Текстовые поля

#### Создание текстового поля ввода

```php
<?= Form::text('username') ?>
```

#### Указание значения по умолчанию

```php
<?= Form::text('email', 'emailaddress@example.tld') ?>
```

::: tip
Методы **hidden** и **textarea** имеют ту же сигнатуру, что и метод **text**.
:::

#### Создание поля пароля

```php
<?= Form::password('password') ?>
```

#### Создание других полей ввода

```php
<?= Form::email($name, $value = null, $attributes = []) ?>
<?= Form::file($name, $attributes = []) ?>
```

## Флажки и переключатели

#### Создание флажка или переключателя

```php
<?= Form::checkbox('name', 'value') ?>

<?= Form::radio('name', 'value') ?>
```

#### Создание отмеченного флажка или переключателя

```php
<?= Form::checkbox('name', 'value', true) ?>

<?= Form::radio('name', 'value', true) ?>
```

## Числовое поле

#### Создание числового поля

```php
<?= Form::number('name', 'value') ?>
```

## Поле загрузки файла

#### Создание поля для файла

```php
<?= Form::file('image') ?>
```

> **Примечание.** Форма должна быть открыта с параметром `files`, установленным в `true`.

## Выпадающие списки

#### Создание выпадающего списка

```php
<?= Form::select('size', ['L' => 'Large', 'S' => 'Small']) ?>
```

#### Создание выпадающего списка с выбранным значением по умолчанию

```php
<?= Form::select('size', ['L' => 'Large', 'S' => 'Small'], 'S') ?>
```

#### Создание сгруппированного списка

```php
<?= Form::select('animal', [
    'Cats' => ['leopard' => 'Leopard'],
    'Dogs' => ['spaniel' => 'Spaniel'],
]) ?>
```

#### Создание выпадающего списка с диапазоном

```php
<?= Form::selectRange('number', 10, 20) ?>
```

#### Создание выпадающего списка с диапазоном, выбранным значением и пустым вариантом

```php
<?= Form::selectRange('number', 10, 20, 2, ['emptyOption' => 'Choose...']) ?>
```

#### Создание списка с названиями месяцев

```php
<?= Form::selectMonth('month') ?>
```

#### Создание списка с названиями месяцев, выбранным значением и пустым вариантом

```php
<?= Form::selectMonth('month', 2, ['emptyOption' => 'Choose month...']) ?>
```

## Кнопки

#### Создание кнопки отправки

```php
<?= Form::submit('Click Me!') ?>
```

::: tip
Нужен элемент `button`? Используйте метод **button**. Его сигнатура совпадает с методом **submit**.
:::

## Пользовательские макросы

#### Регистрация макроса формы

Определить собственные хелперы класса Form, называемые «макросами», очень просто. Сначала зарегистрируйте макрос с выбранным именем и замыканием:

```php
Form::macro('myField', function() {
    return '<input type="awesome">';
})
```

Теперь можно вызывать макрос по имени.

#### Вызов пользовательского макроса формы

```php
<?= Form::myField() ?>
```
