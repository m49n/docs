# Resizer

## Введение

October CMS поставляется с инструментом изменения размера изображений, позволяющим изменять форму и размер поддерживаемых файлов.

## Изменение размера файла на диске

Для изменения размера изображения применяют метод `open` фасада `Resizer`, передавая путь к файлу.

```php
$image = Resizer::open('path/to/image.jpg');
```

Можно также передать загруженный файл из [входных данных HTTP-запроса](./request-input.md).

```php
$image = Resizer::open(Input::file('field_name'));
```

Изменение размера выполняет метод `resize`. Первый аргумент задаёт ширину изображения, второй — высоту, третий — массив параметров изменения размера.

```php
$image->resize(800, 600, ['mode' => 'crop']);
```

Аргументы ширины и высоты являются необязательными. Например, чтобы сохранить исходную ширину и изменить только высоту, вторым аргументом передают значение `null`. Это значение будет вычислено с учётом исходных пропорций изображения (автоматическое пропорциональное масштабирование) на основе опции `mode`.

```php
$image->resize(800, null, [...]);
```

Для сохранения изображения с новым размером в другом месте используется метод `save`.

```php
$image->save('path/to/new/file.jpg');
```

### Параметры изменения размера

В массиве параметров поддерживаются следующие элементы:

Key | Description | Default | Options
--- | --- | --- | ---
`mode` | Как изображение должно быть подогнано под размеры | `auto` | `exact`, `portrait`, `landscape`, `auto`, `fit` или `crop`
`offset` | Смещение кадрирования изменённого изображения | `[0,0]` | [left, top]
`quality` | Качество результирующего изображения | `90` | `0-100`
`sharpen` | Степень резкости изображения | `0` | `0-100`

### Доступные режимы

Опция `mode` позволяет указать способ изменения размера изображения. Доступные режимы:

Mode | Description
--- | ---
`auto` | Автоматически выбирает между `portrait` и `landscape` в зависимости от ориентации изображения
`exact` | Изменяет размер до указанных значений без сохранения пропорций
`portrait` | Подгоняет указанную высоту и адаптирует ширину с сохранением пропорций
`landscape` | Подгоняет указанную ширину и адаптирует высоту с сохранением пропорций
`crop` | Обрезает изображение до указанных размеров после максимального вписывания
`fit` | Вписывает изображение в заданные максимальные размеры, сохраняя пропорции

## Изменение размера для браузера

Класс `System\Classes\ResizeImages` позволяет изменить размер изображения и отдать его по URL:

```php
$url = \System\Classes\ResizeImages::resize($image, $width, $height, $options);
```

Если требуется изменить элемент медиатеки, сначала следует разрешить путь с помощью класса `Media\Classes\MediaLibrary` и метода `url`.

```php
$image = \Media\Classes\MediaLibrary::url('relative/path/to/asset.jpg');

$url = \System\Classes\ResizeImages::resize($image, $width, $height, $options);
```

::: tip
Существует также [фильтр разметки](../../markup/filter/resize.md) `|resize`, который можно использовать для изменения размера изображений в темах.
:::
