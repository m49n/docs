# Кэш

## Конфигурация

October CMS предоставляет унифицированный API для различных систем кэширования, а конфигурация кэша расположена в `config/cache.php`. В этом файле можно указать, какой драйвер кэша следует использовать по умолчанию во всём приложении. Популярные системы кэширования, такие как [Memcached](http://memcached.org) и [Redis](https://redis.io), поддерживаются из коробки.

Файл конфигурации кэша также содержит другие параметры, описанные внутри файла, поэтому следует внимательно изучить эти параметры. По умолчанию October CMS настроена на использование драйвера кэша `file`, который сохраняет сериализованные закэшированные объекты в файловой системе. Для более крупных приложений рекомендуется использовать кэш в памяти, такой как Memcached или APC. Можно даже настроить несколько конфигураций кэша для одного и того же драйвера.

### Предварительные требования к кэшу

#### Database

Драйвер кэша `database` использует базу данных вместо файловой системы. Дополнительная настройка не требуется, поскольку структура базы данных уже доступна.

#### Memcached

Для использования кэша Memcached необходимо установить [пакет Memcached PECL](http://pecl.php.net/package/memcached). Конфигурация по умолчанию использует TCP/IP на основе [Memcached::addServer](http://php.net/manual/en/memcached.addserver.php).

```php
'memcached' => [
    'servers' => [
        [
            'host' => env('MEMCACHED_HOST', '127.0.0.1'),
            'port' => env('MEMCACHED_PORT', 11211),
            'weight' => 100,
        ],
    ],
],
```

Можно также задать для параметра `host` путь к сокету UNIX. В этом случае параметр `port` должен быть равен `0`.

```php
'memcached' => [
    [
        'host' => '/var/run/memcached/memcached.sock',
        'port' => 0,
        'weight' => 100
    ],
],
```

#### Redis

::: tip
Перед использованием кэша Redis с Laravel нужно установить либо расширение PhpRedis через PECL, либо пакет `predis/predis` (~1.0) через Composer.
:::

Конфигурация Redis для приложения находится в файле `config/database.php`. В этом файле можно увидеть массив `redis`, содержащий серверы Redis, которые использует приложение:

```php
'redis' => [

    'cluster' => false,

    'default' => [
        'host'     => '127.0.0.1',
        'port'     => 6379,
        'database' => 0,
    ],

],
```

Можно определить значение массива `options` в настройках соединения Redis, что позволяет указать набор [параметров клиента](https://github.com/nrk/predis/wiki/Client-Options) Predis.

Если сервер Redis требует аутентификацию, можно указать пароль, добавив элемент конфигурации `password` в массив настроек сервера Redis.

#### DynamoDB

Перед использованием драйвера кэша DynamoDB следует создать таблицу кэша DynamoDB для хранения всех данных кэша, обычно она называется `cache`. Имя таблицы можно выбрать произвольно, исходя из значения параметра `stores.dynamodb.table` в конфигурационном файле `cache` приложения.

```php
'dynamodb' => [
    'table' => env('DYNAMODB_CACHE_TABLE', 'cache'),
],
```

В таблице также должен быть строковый разделяющий ключ (partition key) с именем, соответствующим значению параметра конфигурации `stores.dynamodb.attributes.key` в файле конфигурации кэша приложения. По умолчанию разделяющий ключ должен называться `key`.

## Использование кэша

Хотя основное кэширование выполняется внутри October, фасад (facade) `Cache` предоставляет простые методы для кэширования собственных данных.

### Получение элементов из кэша

Метод `get` фасада `Cache` используется для извлечения элементов из кэша. Если элемент отсутствует в кэше, будет возвращено значение `null`. При желании можно передать вторым аргументом методу `get` пользовательское значение по умолчанию, которое будет возвращено, если элемент не найден:

```php
$value = Cache::get('key');

$value = Cache::get('key', 'default');
```

Можно даже передать `Closure` в качестве значения по умолчанию. Результат выполнения `Closure` будет возвращён, если указанного элемента нет в кэше. Передача `Closure` позволяет отложить получение значений по умолчанию из базы данных или другого внешнего сервиса:

```php
$value = Cache::get('key', function() {
    return Db::table(...)->get();
});
```

#### Проверка существования элемента

Метод `has` позволяет определить, существует ли элемент в кэше:

```php
if (Cache::has('key')) {
    //
}
```

#### Увеличение и уменьшение значений

Методы `increment` и `decrement` позволяют изменять значение целочисленных элементов в кэше. Оба метода могут принимать второй аргумент, задающий величину, на которую следует увеличить или уменьшить значение элемента:

```php
Cache::increment('key');

Cache::increment('key', $amount);

Cache::decrement('key');

Cache::decrement('key', $amount);
```

#### Получить или обновить

Иногда нужно получить элемент из кэша, но также сохранить значение по умолчанию, если элемент отсутствует. Например, можно получить всех пользователей из кэша или, если их нет, извлечь их из базы данных и добавить в кэш. Это можно сделать методом `Cache::remember`:

```php
$value = Cache::remember('users', $seconds, function() {
    return Db::table('users')->get();
});
```

Если элемента нет в кэше, `Closure`, переданный методу `remember`, будет выполнен, а его результат помещён в кэш.

Можно также комбинировать методы `remember` и `forever`:

```php
$value = Cache::rememberForever('users', function() {
    return Db::table('users')->get();
});
```

#### Получить и удалить

Если необходимо извлечь элемент из кэша и сразу удалить его, можно воспользоваться методом `pull`. Как и метод `get`, он вернёт `null`, если элемент отсутствует в кэше:

```php
$value = Cache::pull('key');
```

### Сохранение элементов в кэше

Метод `put` фасада `Cache` позволяет сохранять элементы в кэше. При добавлении элемента необходимо указать количество секунд, в течение которых значение должно храниться в кэше:

```php
Cache::put('key', 'value', $seconds);
```

Вместо передачи количества секунд до истечения элемента можно также передать экземпляр `DateTime`, представляющий время истечения срока хранения элемента в кэше:

```php
$expiresAt = Carbon::now()->addMinutes(10);

Cache::put('key', 'value', $expiresAt);
```

> **Примечание.** Рекомендуется использовать экземпляры `DateTime` для определения всех сроков действия, чтобы обеспечить совместимость с будущими версиями October CMS.

Метод `add` добавит элемент в кэш только в том случае, если он ещё не существует в хранилище кэша. Метод вернёт `true`, если элемент действительно добавлен в кэш. В противном случае метод вернёт `false`:

```php
Cache::add('key', 'value', $seconds);
```

Метод `forever` позволяет сохранять элемент в кэше постоянно. Такие значения нужно удалять вручную с помощью метода `forget`:

```php
Cache::forever('key', 'value');
```

### Удаление элементов из кэша

Удалять элементы из кэша можно методом `forget` фасада `Cache`:

```php
Cache::forget('key');
```

Очистить весь кэш можно методом `flush`:

```php
Cache::flush();
```

Очистка кэша **не учитывает** префикс кэша и удалит все записи из кэша. Следует учитывать это при очистке кэша, который используется другими приложениями.
