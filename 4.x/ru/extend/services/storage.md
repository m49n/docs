# Storage

October CMS предоставляет мощную абстракцию файловой системы благодаря Laravel и пакету PHP [Flysystem](https://github.com/thephpleague/flysystem). Интеграция с Flysystem упрощает использование драйверов для локальных файловых систем и Amazon S3. Более того, переключение между этими вариантами хранения выполняется предельно просто, поскольку API для каждой системы остаётся одинаковым.

## Конфигурация

Файл конфигурации файловой системы расположен в `config/filesystems.php`. В нём можно настроить все «диски». Каждый диск представляет конкретный драйвер и место хранения. В файле уже приведены примеры конфигураций для каждого поддерживаемого драйвера, поэтому достаточно изменить значения в соответствии с выбранным хранилищем и учётными данными.

Разрешается настроить сколько угодно дисков, в том числе несколько дисков с одним и тем же драйвером.

#### Драйвер Local

При использовании драйвера `local` все операции с файлами выполняются относительно каталога `root`, указанного в конфигурации. По умолчанию используется каталог `storage/app`. Например, следующий метод сохранит файл в `storage/app/file.txt`:

```php
Storage::disk('local')->put('file.txt', 'Contents');
```

#### Предварительные требования для других драйверов

Перед использованием драйвера S3 необходимо установить пакет Flysystem S3 через менеджер пакетов Composer.

```bash
composer require league/flysystem-aws-s3-v3 "^3.0"
```

Параметры драйвера S3 задаются в файле `config/filesystems.php`. В нём уже есть пример конфигурации для S3. Его можно изменить, указав собственные настройки и учётные данные.

## Базовое использование

### Получение экземпляров дисков

Фасад `Storage` позволяет работать с любым настроенным диском. Например, методом `put` можно сохранить аватар на диске по умолчанию. Если вызвать методы фасада `Storage`, не обращаясь предварительно к методу `disk`, вызов будет автоматически перенаправлен на диск по умолчанию:

```php
$user = User::find($id);

Storage::put(
    'avatars/'.$user->id,
    file_get_contents(Request::file('avatar')->getRealPath())
);
```

При работе с несколькими дисками определённый диск выбирается методом `disk` фасада `Storage`. После этого можно продолжить цепочку вызовов, выполняя операции над выбранным диском:

```php
$disk = Storage::disk('s3');

$contents = Storage::disk('local')->get('file.jpg')
```

### Получение файлов

Метод `get` возвращает содержимое указанного файла в виде строки.

```php
$contents = Storage::get('file.jpg');
```

Метод `exists` проверяет, существует ли файл на диске.

```php
$exists = Storage::disk('s3')->exists('file.jpg');
```

#### Метаинформация о файле

Метод `size` возвращает размер файла в байтах.

```php
$size = Storage::size('file1.jpg');
```

Метод `lastModified` возвращает отметку времени UNIX с моментом последнего изменения файла.

```php
$time = Storage::lastModified('file1.jpg');
```

### Сохранение файлов

Метод `put` записывает файл на диск. В него можно передать PHP-ресурс, и тогда будет использована потоковая поддержка Flysystem. Потоки особенно рекомендуются при работе с крупными файлами.

```php
Storage::put('file.jpg', $contents);

Storage::put('file.jpg', $resource);
```

Метод `copy` копирует существующий файл в новое расположение на диске.

```php
Storage::copy('old/file1.jpg', 'new/file1.jpg');
```

Метод `move` переносит существующий файл в новое место.

```php
Storage::move('old/file1.jpg', 'new/file1.jpg');
```

#### Добавление данных в начало или конец файлов

Методы `prepend` и `append` позволяют легко добавить содержимое в начало или конец файла.

```php
Storage::prepend('file.log', 'Prepended Text');

Storage::append('file.log', 'Appended Text');
```

### Удаление файлов

Метод `delete` принимает одно имя файла или массив имён для удаления с диска.

```php
Storage::delete('file.jpg');

Storage::delete(['file1.jpg', 'file2.jpg']);
```

### Каталоги

#### Получение всех файлов каталога

Метод `files` возвращает массив всех файлов в указанном каталоге. Чтобы получить список всех файлов, включая вложенные каталоги, используйте метод `allFiles`.

```php
$files = Storage::files($directory);

$files = Storage::allFiles($directory);
```

#### Получение всех каталогов внутри каталога

Метод `directories` возвращает массив всех каталогов в указанном каталоге. Метод `allDirectories` возвращает список всех каталогов, включая вложенные.

```php
$directories = Storage::directories($directory);

// Рекурсивно...
$directories = Storage::allDirectories($directory);
```

#### Создание каталога

Метод `makeDirectory` создаёт указанный каталог, включая необходимые вложенные каталоги.

```php
Storage::makeDirectory($directory);
```

#### Удаление каталога

Метод `deleteDirectory` удаляет каталог вместе со всеми его файлами с диска.

```php
Storage::deleteDirectory($directory);
```
