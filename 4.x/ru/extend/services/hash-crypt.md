# Хеширование и шифрование

## Конфигурация

При установке October должен быть сгенерирован случайный ключ. Это можно проверить в параметре `key` файла конфигурации `config/app.php`. Если ключ не изменён, задайте ему 32-символьную случайную строку. Если значение указано неверно, все зашифрованные данные будут небезопасны.

## Хеширование

Фасад `Hash` предоставляет безопасное хеширование Bcrypt для хранения паролей пользователей. Bcrypt — отличный выбор для хеширования паролей, поскольку его «коэффициент работы» можно изменять, увеличивая время генерации хеша по мере роста производительности оборудования.

Пароль можно захешировать, вызвав метод `make` фасада `Hash`:

```php
$user = new User;
$user->password = Hash::make('mypassword');
$user->save();
```

Также модели могут реализовать [трейт Hashable](../database/traits.md), чтобы атрибуты хешировались автоматически.

#### Проверка пароля по хешу

Метод `check` позволяет проверить, соответствует ли заданная строка в открытом виде указанному хешу.

```php
if (Hash::check('plain-text', $hashedPassword)) {
    // The passwords match...
}
```

#### Проверка необходимости повторного хеширования

Функция `needsRehash` определяет, изменился ли коэффициент работы хешировщика после создания хеша пароля:

```php
if (Hash::needsRehash($hashed)) {
    $hashed = Hash::make('plain-text');
}
```

## Шифрование

Для шифрования значения используйте фасад `Crypt`. Все данные шифруются с помощью OpenSSL и алгоритма `AES-256-CBC`. Кроме того, каждое зашифрованное значение подписывается кодом аутентификации сообщения (MAC), что позволяет обнаружить любые изменения в шифротексте.

Например, можно зашифровать секрет методом `encrypt` и сохранить его в [модели базы данных](../database/model.md):

```php
$user = new User;
$user->secret = Crypt::encrypt('shhh no telling');
$user->save();
```

#### Расшифровка значения

Разумеется, можно расшифровать данные методом `decrypt` фасада `Crypt`. Если значение не удаётся расшифровать (например, из-за неверного MAC), будет выброшено исключение `Illuminate\Contracts\Encryption\DecryptException`:

```php
use Illuminate\Contracts\Encryption\DecryptException;

try {
    $decrypted = Crypt::decrypt($encryptedValue);
}
catch (DecryptException $ex) {
    //
}
```

Также модели могут реализовать [трейт Encryptable](../database/traits.md), чтобы атрибуты шифровались и расшифровывались автоматически.
