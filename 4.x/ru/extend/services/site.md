# Site Manager

### Введение

Глобальный фасад `Site` входит в October CMS и предоставляет инструменты для работы с [многосайтовыми конфигурациями](../../cms/resources/multisite.md). Все необязательные многосайтовые функции включаются или отключаются в файле конфигурации **config/multisite.php**.

```php
'features' => [
    'cms_maintenance_setting' => false,
    // ...
]
```

Метод `hasFeature` проверяет, включена ли конкретная многосайтовая функция.

```php
$useMultisite = Site::hasFeature('cms_maintenance_setting');
```

## Проверка состояния конфигурации сайта

Метод `hasAnySite` сообщает, доступен ли хотя бы один включённый сайт.

```php
if (Site::hasAnySite()) {
    // ...
}
```

Метод `hasMultiSite` возвращает `true`, если определено несколько сайтов.

```php
if (Site::hasMultiSite()) {
    // ...
}
```

Метод `hasSiteGroups` возвращает `true`, если несколько сайтов используют групповые определения.

```php
if (Site::hasSiteGroups()) {
    // ...
}
```

## Получение сайта

Запрос сайта возвращает экземпляр `System\Models\SiteDefinition`, атрибуты которого загружаются из драйвера кеша или базы данных.

Метод `getPrimarySite` возвращает основной сайт, используемый в качестве резервного варианта во всех случаях.

```php
$site = Site::getPrimarySite();
```

Для фронтенд-темы выбран сайт, который используется при рендеринге CMS-страниц. Метод `getActiveSite` возвращает этот сайт.

```php
$site = Site::getActiveSite();
```

Аналогично, в панели управления можно выбрать сайт; его возвращает метод `getEditSite`.

```php
$site = Site::getEditSite();
```

Чтобы получить сайт по уникальному идентификатору, используйте `getSiteFromId` и передайте идентификатор.

```php
$siteFour = Site::getSiteFromId(4);
```

Чтобы найти сайт по коду локали, используйте `getSiteForLocale`, передав нужную локаль.

```php
$frenchSite = Site::getSiteForLocale('fr');
```

## Работа с несколькими сайтами

Если возвращаются несколько сайтов, это будет экземпляр `October\Rain\Database\Collection` с заполненными данными.

Метод `listSites` возвращает все сайты, включая отключённые.

```php
$sites = Site::listSites();
```

Метод `listEnabled` возвращает только включённые сайты.

```php
$sites = Site::listEnabled();
```

Метод `listEditEnabled` возвращает сайты, включённые в панели управления.

```php
$sites = Site::listEditEnabled();
```

## Контекст сайта

Контекст сайта определяет активный сайт, что автоматически ограничивает выборки данным сайтом. В некоторых случаях используется глобальное состояние, позволяющее обращаться к данным всех сайтов.

Метод `withContext` изменяет контекст на другой сайт; передайте идентификатор нужного сайта.

```php
Site::withContext(2, function() {
    // Модели сайта 2 теперь доступны.
});
```

Глобальный контекст активируется методом `withGlobalContext`, которому передаётся замыкание.

```php
Site::withGlobalContext(function() {
    // Здесь доступны все модели.
});
```

Метод `hasGlobalContext` позволяет проверить, активировано ли глобальное состояние.

```php
$global = Site::hasGlobalContext();
```
