# HTTP-клиент

Класс `Http` предоставляет возможности для установления соединений по протоколу HTTP. Его можно использовать для исходящих подключений к другим приложениям и сервисам. Клиент поставляется из фреймворка Laravel, поэтому все доступные функции описаны в [документации Laravel](https://laravel.com/docs/12.x/http-client).

## Базовое использование

Для выполнения запросов методы PHP соответствуют HTTP-методам: доступны `get`, `post`, `patch`, `put`, `options` и `delete`. Ниже пример простого запроса `GET` к URL. Возвращаемый результат содержит объект ответа.

```php
$response = Http::get('https://octobercms.com');
```

Содержимое запроса можно быстро изучить, добавив `dd()` перед вызовом метода. Это выведет содержимое запроса и завершит выполнение.

```php
Http::dd()->get('https://octobercms.com');
```

## Обработка ответа

Объект ответа предоставляет методы для анализа полученных данных.

```php
$result = Http::post('https://octobercms.com');
echo $result->body();                  // Вывод: <html><head><title>...
echo $result->status();                // Вывод: 200
echo $result->header('Content-Type');  // Вывод: text/html; charset=UTF-8
```

Объект поддерживает следующие методы.

Название метода | Тип возвращаемого значения | Назначение
------------- | ------------- | -------------
**body()** | `string` | Получить тело ответа.
**json($key)** | `array|mixed` | Получить тело ответа в виде декодированного JSON-массива или скалярного значения.
**object()** | `object` | Получить тело ответа в виде декодированного JSON-объекта.
**collect($key)** | [Collection](./collection.md) | Получить тело ответа в виде коллекции.
**status()** | `int` | Получить код состояния ответа.
**ok()** | `bool` | Определить, равен ли код ответа «OK».
**successful()** | `bool` | Определить, успешно ли выполнен запрос.
**redirect()** | `bool` | Определить, является ли ответ перенаправлением.
**failed()** | `bool` | Определить, произошла ли ошибка клиента или сервера.
**serverError()** | `bool` | Определить, произошла ли ошибка на стороне сервера.
**clientError()** | `bool` | Определить, произошла ли ошибка на стороне клиента.
**header($header)** | `string` | Получить отдельный заголовок из ответа.
**headers()** | `array` | Получить все заголовки ответа.

## Отправка данных запроса

Методы `post`, `put` и `patch` поддерживают передачу дополнительных данных. По умолчанию данные отправляются с типом содержимого `application/json`.

```php
Http::post('https://octobercms.com', [
    'name' => 'Jeff'
]);
```

Чтобы отправить данные с типом содержимого `application/x-www-form-urlencoded`, вызовите метод `asForm` перед выполнением запроса.

```php
Http::asForm()->post('https://octobercms.com', [
    'name' => 'Jeff'
]);
```

При передаче данных в запросе `get` массив параметров будет добавлен к строке запроса в URL.

```php
Http::get('https://octobercms.com', [
    'page' => '1'
]);
```

Метод `withHeaders` позволяет добавить к запросу пользовательские заголовки.

```php
Http::withHeaders([
    'Rest-Key' => '...'
])->post('https://octobercms.com', [
    'name' => 'Jeff'
]);
```

Метод `withBasicAuth` используется для передачи учётных данных вместе с запросом.

```php
Http::withBasicAuth('user', 'password')->post('https://octobercms.com', [
    'name' => 'Jeff'
]);
```

## Обработка ошибок

HTTP-клиент рассматривает все ответы как валидные, включая ошибки. Поэтому, чтобы определить наличие ошибки, используйте методы `successful`, `failed`, `clientError` или `serverError`.

```php
// Код состояния >= 200 и < 300
$response->successful();

// Код состояния >= 400
$response->failed();

// Ответ имеет код уровня 400
$response->clientError();

// Ответ имеет код уровня 500
$response->serverError();
```

Также можно использовать метод `onError`, чтобы выполнить колбэк при ошибке клиента или сервера.

```php
$response->onError(callable $callback);
```
