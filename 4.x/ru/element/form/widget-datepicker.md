# Поле Date Picker

Виджет формы `datepicker` выводит текстовое поле для выбора даты и времени.

```yaml
published_at:
    label: Published
    type: datepicker
    mode: date
```

Поддерживаются и часто используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя, отображаемое пользователю.
**default** | задаёт строковое значение по умолчанию, необязательное.
**comment** | размещает описательный комментарий под полем.
**mode** | ожидаемый результат: `date`, `datetime` или `time`. Значение по умолчанию — `datetime`.
**format** | задаёт явный формат отображения даты, например `Y-m-d`.
**minDate** | минимальная/самая ранняя дата, которую можно выбрать.
**maxDate** | максимальная/самая поздняя дата, которую можно выбрать.
**yearRange** | количество лет, отображаемых по обе стороны, или массив нижней/верхней границы, например `[1900,2015]`. Значение по умолчанию — `10`.
**disableDays** | дни, которые нельзя выбрать. Можно указать число, соответствующее воскресенью (`0`)—субботе (`6`), либо конкретную дату (`2024-10-01`).
**firstDay** | первый день недели. Значение по умолчанию — `0` (воскресенье).
**twelveHour** | отображает 12-часовой формат при выборе времени. Значение по умолчанию — `false`.
**hoursOnly** | позволяет выбирать только часы при выборе времени. Значение по умолчанию — `false`.
**showWeekNumber** | отображает номера недель в начале строки. Значение по умолчанию — `false`.
**useTimezone** | преобразует дату и время согласно настройке часового пояса, указанной в бэкенде.

Используйте режим `time`, чтобы вывести выбор времени, и переключайте 24-часовой или 12-часовой формат через свойство `twelveHour`.

```yaml
birth_time:
    label: Time Born
    type: datepicker
    mode: time
    twelveHour: true
```

Для упрощённого выбора времени используйте режим `hoursOnly`, чтобы отображать выбор часа без минут.

```yaml
birth_hour:
    label: Hour Born
    type: datepicker
    mode: time
    hoursOnly: true
```

Свойство `disableDays` позволяет запретить выбор конкретных дней.

```yaml
booking_date:
    label: Booking Date
    type: datepicker
    mode: date
    disableDays:
        - 0 # Sundays
        - 6 # Saturdays
        - "2023-08-10" # Specific date
```

Свойство `disableDays` также можно задать как статическую PHP-функцию для динамического определения запрещённых дней.

```yaml
booking_date:
    type: datepicker
    disableDays: App\Classes\BookingManager::getDisabledBookingDates
```
