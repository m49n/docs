# Поле Data Table

Виджет формы `datatable` выводит редактируемую таблицу записей в формате сетки. Содержимое ячеек можно редактировать непосредственно в сетке, что позволяет управлять несколькими строками и столбцами информации.

```yaml
data:
    type: datatable
    adding: true
    deleting: true
    columns: []
    recordsPerPage: false
    searching: false
```

::: tip
Чтобы использовать это поле с моделью, оно должно быть определено в [свойстве jsonable](../../extend/system/models.md) или где-либо ещё, где поддерживается хранение в виде массива.
:::

Поддерживаются и часто используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------ | -----------
**label** | имя, отображаемое пользователю.
**default** | задаёт строковое значение по умолчанию, необязательное.
**comment** | размещает описательный комментарий под полем.
**adding** | разрешает добавление записей в таблицу данных. Значение по умолчанию — `true`.
**btnAddRowLabel** | задаёт пользовательскую подпись кнопки «Add Row Above».
**btnAddRowBelowLabel** | задаёт пользовательскую подпись кнопки «Add Row Below».
**btnDeleteRowLabel** | задаёт пользовательскую подпись кнопки «Delete Row».
**columns** | массив с конфигурацией столбцов таблицы данных. См. раздел *Конфигурация столбцов* ниже.
**deleting** | разрешает удаление записей из таблицы данных. Значение по умолчанию — `true`.
**dynamicHeight** | если `true`, высота таблицы будет увеличиваться или уменьшаться в зависимости от количества записей, до максимума, указанного в параметре `height`. Значение по умолчанию — `false`.
**fieldName** | задаёт пользовательское имя поля, используемое в POST-данных, отправляемых из таблицы данных. Оставьте пустым, чтобы использовать псевдоним поля по умолчанию.
**height** | высота таблицы данных в пикселях. Если задано значение `false`, таблица растянется по размеру контейнера.
**keyFrom** | атрибут данных, используемый для ключей каждой записи. Обычно указывается `id`. Поддерживаются только целые значения.
**postbackHandlerName** | имя AJAX-обработчика, с которым будет отправляться содержимое таблицы данных. Если установлено значение `null` (по умолчанию), имя обработчика определяется автоматически по имени запроса, используемому формой, содержащей таблицу данных. Рекомендуется оставлять `null`.
**recordsPerPage** | число записей, отображаемых на странице. Если задано `false`, пагинация отключается.
**searching** | разрешает поиск записей через поле поиска. Значение по умолчанию — `false`.
**toolbar** | массив с конфигурацией панели инструментов таблицы данных.

#### Конфигурация столбцов

Виджет таблицы данных позволяет задать столбцы в виде массива через параметр конфигурации `columns`. Каждый столбец должен использовать имя поля в качестве ключа и следующие параметры конфигурации для настройки.

Пример:

```yaml
columns:
    id:
        type: string
        title: ID
        validation:
            integer:
                message: Please enter a number
    name:
        type: string
        title: Name
```

Параметр | Описание
------ | -----------
**type** | тип ввода для ячеек столбца. Допустимые значения: `string`, `checkbox`, `dropdown` или `autocomplete`.
**options** | только для столбцов `dropdown` и `autocomplete`. Указывает AJAX-обработчик, возвращающий доступные опции в виде массива. Ключ массива используется как значение опции, а значение массива — как подпись опции.
**readOnly** | признак, что столбец доступен только для чтения. Значение по умолчанию — `false`.
**title** | заголовок столбца.
**validation** | массив, задающий правила валидации содержимого ячеек столбца. См. раздел *Валидация столбцов* ниже.
**width** | ширина столбца в пикселях.

#### Валидация столбцов

Ячейки столбца можно валидировать типами правил, перечисленными ниже. Валидация задаётся в виде массива, где тип правила используется как ключ, а необязательное сообщение передаётся через атрибут `message` для этого правила.

Правило | Описание
---------- | -----------
**float** | Проверяет значение как число с плавающей точкой. Необязательный булев атрибут `allowNegative` разрешает отрицательные значения.
**integer** | Проверяет значение как целое число. Необязательный булев атрибут `allowNegative` разрешает отрицательные значения.
**length** | Проверяет, что значение имеет указанную длину. Требует целочисленных атрибутов `min` и `max`, задающих минимальное и максимальное количество символов.
**regex** | Проверяет значение по регулярному выражению. Требует строкового атрибута `pattern`, определяющего выражение для проверки.
**required** | Требует ввести значение перед сохранением.
