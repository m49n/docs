# Поле Sensitive

Виджет формы `sensitive` выводит раскрываемое поле пароля, которое можно использовать для конфиденциальных данных — ключей API, секретов, конфигурационных значений и т. п. Поле можно по запросу пользователя скрывать и показывать.

Если поле содержит ранее введённое значение, при загрузке оно заменяется заполнительным значением, чтобы невозможно было угадать длину или скопировать значение. При раскрытии поля исходное значение запрашивается по AJAX и подставляется в поле.

```yaml
api_secret:
    type: sensitive
    allowCopy: false
    hideOnTabChange: true
```

Поддерживаются и часто используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя, отображаемое пользователю.
**default** | задаёт строковое значение по умолчанию, необязательное.
**comment** | размещает описательный комментарий под полем.
**mode** | режим отображения виджета: `textarea` или `text`. Значение по умолчанию — `text`.
**allowCopy** | добавляет действие «copy», позволяющее скопировать значение без раскрытия. Значение по умолчанию — `true`.
**hiddenPlaceholder** | задаёт текст заполнителя, имитирующий скрытое значение. Можно указать строку любой длины, чтобы имитировать разные длины значений. Значение по умолчанию — `__hidden__`.
**hideOnTabChange** | при `true` поле автоматически скрывается, когда пользователь переключает вкладку или сворачивает браузер. Значение по умолчанию — `true`.
