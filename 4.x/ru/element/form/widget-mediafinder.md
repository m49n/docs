# Поле Media Finder

Виджет формы `mediafinder` выводит поле для выбора элемента из библиотеки медиаменеджера. При раскрытии поле открывает медиаменеджер для поиска файла. Результатом выбора будет строка с относительным путём к файлу.

```yaml
whitepaper_file:
    label: Whitepaper PDF
    type: mediafinder
```

Поддерживаются и часто используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя, отображаемое пользователю.
**default** | задаёт строковое значение по умолчанию, необязательное.
**comment** | размещает описательный комментарий под полем.
**mode** | ожидаемый тип файла: `file`, `folder` или `image`. Значение по умолчанию — `file`.
**imageWidth** | при использовании типа `image` превью изображение будет отображаться с этой шириной, необязательное.
**imageHeight** | при использовании типа `image` превью изображение будет отображаться с этой высотой, необязательное.
**maxItems** | максимальное количество элементов, которое можно выбрать.
**thumbOptions** | дополнительные [параметры изменения размера](../../extend/services/resizer.md) для генерации миниатюры либо значение `false` для отключения создания миниатюры.

Установите значение `mode` в **image**, чтобы показать превью выбранного изображения.

```yaml
background_image:
    label: Background Image
    type: mediafinder
    mode: image
```

Можно задать `mode` как **folder**, чтобы разрешить выбор только пути к папке медиа.

```yaml
media_folder:
    label: Media Folder
    type: mediafinder
    mode: folder
```

::: tip
В отличие от [виджета формы File Upload](./widget-fileupload.md), виджет Media Finder сохраняет данные в виде строки, представляющей путь к выбранным в медиабиблиотеке файлам. Поле должно быть связано с обычным атрибутом модели.
:::

## Выбор нескольких элементов

Виджет mediafinder пытается определить возможность выбора нескольких элементов по [атрибуту jsonable](../../extend/system/models.md) модели, что является обязательным требованием для хранения множества элементов.

Ограничить количество выбираемых элементов можно свойством `maxItems`.

```yaml
media_gallery:
    label: Image
    type: mediafinder
    mode: image
    maxItems: 10
```
