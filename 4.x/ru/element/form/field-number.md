# Поле Number

Поле `number` выводит однострочное текстовое поле, принимающее только числа.

```yaml
your_age:
    label: Your Age
    type: number
```

Поддерживаются и чаще всего используются следующие [свойства полей](../form-fields.md).

Property | Description
------------- | -------------
**label** | имя, отображаемое для поля формы.
**default** | указывает строковое значение по умолчанию (опционально).
**comment** | размещает поясняющий комментарий под полем.
**min** | минимальное значение на стороне клиента, значение по умолчанию — `null`.
**max** | максимальное значение на стороне клиента, значение по умолчанию — `null`.
**step** | шаг изменения на стороне клиента, значение по умолчанию — `any`.

Свойства `min` и `max` ограничивают ввод минимальным и максимальным значениями. В примере ниже допустим ввод только в диапазоне от 1 до 100.

```yaml
your_age:
    label: Your Age
    type: number
    min: 1
    max: 100
```

Свойство `step` управляет величиной шага, на который можно увеличивать или уменьшать число; по умолчанию оно равно **any**.

```yaml
your_age:
    label: Your Age
    type: number
    step: 10
```

## Проверка на стороне сервера

Чтобы при сохранении проверять, что значение является числом, при работе с полями tailor используйте свойство `validation`.

```yaml
your_age:
    label: Your Age
    type: number
    validation: numeric
```

При работе с моделями указывайте правило в свойстве `$rules` модели, например так.

```php
public $rules = [
    'your_age' => ['numeric'],
];
```

Дополнительные сведения о проверке моделей см. в [статье о сервисе валидации](../../extend/services/validation.md#rule-numeric).
