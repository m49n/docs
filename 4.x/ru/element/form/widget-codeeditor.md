# Поле Code Editor

Поле `codeeditor` выводит текстовый редактор для форматированного кода или разметки. Обратите внимание, что параметры могут наследоваться от настроек редактора кода, заданных администратором в бэкенде.

```yaml
css_content:
    type: codeeditor
    size: huge
    language: html
```

Поддерживаются и чаще всего используются следующие [свойства поля](../form-fields.md).

Property | Description
------------- | -------------
**label** | имя, отображаемое пользователю в форме.
**default** | задаёт строковое значение по умолчанию, необязательно.
**comment** | размещает поясняющий комментарий под полем.
**language** | язык кода, например php, css, javascript, html. По умолчанию — `php`.
**showGutter** | показывает поле с номерами строк. По умолчанию — `true`.
**wrapWords** | переносит длинные строки на новую строку. По умолчанию — `true`.
**fontSize** | размер шрифта текста. По умолчанию — 12.
