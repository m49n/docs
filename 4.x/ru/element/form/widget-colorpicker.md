# Поле Color Picker

Поле `colorpicker` выводит элементы управления для выбора шестнадцатеричного значения цвета.

```yaml
color:
    label: Background
    type: colorpicker
```

Поддерживаются и чаще всего используются следующие [свойства поля](../form-fields.md).

Property | Description
------------- | -------------
**label** | имя, отображаемое пользователю в форме.
**default** | задаёт строковое значение по умолчанию, необязательно.
**comment** | размещает поясняющий комментарий под полем.
**availableColors** | список доступных цветов в виде массива.
**allowEmpty** | разрешает пустое значение. По умолчанию — `false`.
**allowCustom** | разрешает выбрать пользовательский цвет. По умолчанию — `true`.
**showAlpha** | отображает ползунок прозрачности и устанавливает 8-значный hex-код. По умолчанию — `false`.
**showInput** | отображает текстовое поле рядом с выбором цвета и отключает доступные цвета. По умолчанию — `false`.

Предустановленные цвета можно определить, задав для `availableColors` массив значений hex. Свойство `allowCustom` позволяет отключить выбор пользовательского цвета; оно необязательно.

```yaml
color:
    label: Background
    type: colorpicker
    availableColors: ['#000000', '#111111', '#222222']
    allowCustom: false
```

::: tip
Если поле `availableColors` не определено в YAML-файле, colorpicker использует набор из 20 цветов по умолчанию.
:::

Используйте свойство `showAlpha`, чтобы добавить выбор непрозрачности; в этом случае формируется 8-значное hex-значение.

```yaml
color:
    label: Background
    type: colorpicker
    showAlpha: true
```

Используйте свойство `showInput`, чтобы показать текстовое поле рядом с цветом. В этом режиме доступные цвета отключаются, и основной упор делается на выбор и ввод пользовательского hex-значения.

```yaml
color:
    label: Primary Color
    type: colorpicker
    showInput: true
```

## Динамические доступные цвета

Список доступных цветов можно получить из класса модели, передав в `availableColors` имя метода, объявленного в модели. Этот метод должен возвращать массив hex-значений в том же формате, что и в примере выше. Первый аргумент метода — имя поля, второй — текущее значение поля, третий — текущий объект данных всей формы.

```yaml
color:
    label: Background
    type: colorpicker
    availableColors: myColorList
```

Передача доступных цветов в классе модели:

```php
public function myColorList($fieldName, $value, $formData)
{
    return ['#000000', '#111111', '#222222']
}
```
