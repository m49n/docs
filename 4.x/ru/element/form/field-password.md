# Поле пароля (password)

Поле `password` выводит однострочное поле для ввода пароля и используется для ввода конфиденциальных значений, например паролей.

```yaml
user_password:
    label: Password
    type: password
```

Ниже перечислены часто используемые [свойства поля](../form-fields.md).

Property | Description
------------- | -------------
**title** | заголовок для поля формы.
**comment** | размещает описательный комментарий под полем.

::: tip
Изучите [виджет формы Sensitive](./widget-sensitive.md), если нужно поле, которое сохраняет и отображает конфиденциальные значения.
:::
