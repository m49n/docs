# Поле Email

Поле `email` выводит однострочное текстовое поле с типом `email`, что вызывает специализированную клавиатуру для ввода адресов в мобильных браузерах.

```yaml
user_email:
    label: Email Address
    type: email
```

Чаще всего используются следующие [свойства полей](../form-fields.md).

Property | Description
------------- | -------------
**label** | имя, отображаемое для поля формы.
**placeholder** | текст, отображаемый в поле, когда оно пусто.
**default** | указывает строковое значение по умолчанию (опционально).
**comment** | размещает поясняющий комментарий под полем.

## Проверка на стороне сервера

Чтобы при сохранении проверять корректность формата email-адреса, при работе с полями tailor используйте свойство `validation`.

```yaml
user_email:
    label: Email Address
    type: email
    validation: email
```

При работе с моделями указывайте правило в свойстве `$rules` модели, например так.

```php
public $rules = [
    'user_email' => ['email'],
];
```

Дополнительные сведения о проверке моделей см. в [статье о сервисе валидации](../../extend/services/validation.md#rule-email).
