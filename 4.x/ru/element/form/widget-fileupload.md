# Поле File Upload

Виджет формы `fileupload` выводит загрузчик для изображений или произвольных файлов.

```yaml
avatar:
    label: Avatar
    type: fileupload
    mode: image
    imageHeight: 260
    imageWidth: 260
```

Поддерживаются и часто используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя, отображаемое пользователю.
**default** | задаёт строковое значение по умолчанию, необязательное.
**comment** | размещает описательный комментарий под полем.
**mode** | ожидаемый тип файла: `file` или `image`. Значение по умолчанию — `image`.
**size** | для множественной загрузки — размер контейнера. Доступные варианты: `tiny`, `small`, `large`, `huge`, `giant`. Значение по умолчанию — `large`.
**imageWidth** | при использовании типа `image` изображение будет изменено до этой ширины, необязательное.
**imageHeight** | при использовании типа `image` изображение будет изменено до этой высоты, необязательное.
**fileTypes** | расширения файлов, допускаемых загрузчиком, необязательное. Например: `zip,txt`.
**mimeTypes** | MIME-типы, допускаемые загрузчиком, можно указывать как расширение файла или полное имя, необязательное. Например: `bin,txt`.
**maxFilesize** | размер файлов в мегабайтах, допускаемых загрузчиком, необязательный. Значение по умолчанию берётся из параметра `upload_max_filesize`.
**maxFiles** | максимальное количество файлов, которое можно загрузить.
**useCaption** | позволяет задать заголовок и описание для файла. Значение по умолчанию — `true`.
**thumbOptions** | дополнительные [параметры изменения размера](../../extend/services/resizer.md) для генерации миниатюры либо значение `false` для отключения создания миниатюры.
**deferredBinding** | использовать отложенное связывание при загрузке файла, если доступно. Отключите, чтобы прикреплять файл сразу при загрузке, а не при сохранении. Значение по умолчанию — `true`.

::: tip
В отличие от [виджета формы Media Finder](./widget-mediafinder.md), виджет File Upload использует [привязку файлов через базу данных](../../extend/database/attachments.md), поэтому имя поля должно совпадать с атрибутом связи `attachOne` или `attachMany` в связанной модели.
:::
