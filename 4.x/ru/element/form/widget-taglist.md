# Поле Tag List

Виджет формы `taglist` выводит поле для ввода списка тегов.

```yaml
tags:
    type: taglist
    separator: space
```

Поддерживаются и часто используются следующие [свойства поля](../form-fields.md).

Свойство | Описание
------------- | -------------
**label** | имя, отображаемое пользователю.
**default** | задаёт строковое значение по умолчанию, необязательное.
**comment** | размещает описательный комментарий под полем.
**mode** | управляет форматом возвращаемого значения: `string`, `array` или `relation`. Значение по умолчанию — `string`.
**nameFrom** | при использовании режима relation — имя атрибута модели для отображения названия тега. Значение по умолчанию — `name`.
**maxItems** | максимальное количество тегов, которые можно добавить или выбрать.
**separator** | разделитель тегов: `comma` или `space`. Значение по умолчанию — `comma`.
**options** | массив заранее определённых опций.
**optionsMethod** | имя метода, возвращающего заранее определённые опции. Метод может быть объявлен в модели или как статический метод, например `Class::method`. Установите `true`, чтобы использовать метод модели **get*Field*Options**.
**useKey** | использовать ключ вместо значения при сохранении и чтении данных. Значение по умолчанию — `true`.
**customTags** | разрешает пользователю вводить произвольные теги вручную. Значение по умолчанию — `false`.

Поле списка тегов поддерживает те же способы задания опций, что и [тип поля dropdown](./field-dropdown.md).

```yaml
tags:
    type: taglist
    options:
        - Red
        - Blue
        - Orange
```

Можно использовать режим `relation`, когда имя поля соответствует [связи многие-ко-многим](../../extend/database/relations.md). В этом случае теги автоматически берутся и назначаются через связь. Если разрешены произвольные теги, они будут созданы перед назначением.

```yaml
tags:
    type: taglist
    mode: relation
```
