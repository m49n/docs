# Область Switch

`switch` — переключатель между двумя предопределёнными условиями или запросами для списка, поддерживающий состояния «не определено», «включено» и «выключено».

```yaml
is_approved:
    label: Approved
    type: switch
    conditions:
        - is_approved <> true
        - is_approved = true
```

Поддерживаются следующие свойства фильтра.

Property | Description
------------- | -------------
**default** | установить `1` или `2`, чтобы фильтр был активен по умолчанию. Значение по умолчанию: `0`.
**select** | массив с произвольными SQL‑выражениями, используемыми фильтром: первый элемент — для неопределённого состояния условий, второй — для состояния «включено».

Можно указать значение `default`, чтобы задать состояние фильтра по умолчанию. Используйте `0` для выключенного, `1` для неопределённого и `2` для включённого состояния.

```yaml
is_approved:
    label: Approved
    type: switch
    default: 1
```
