# Доступные иконки

October CMS поставляется с собственной библиотекой иконок и включает сторонние библиотеки, чтобы было проще и быстрее подобрать подходящую иконку.

## Phosphor Icons

Набор [Phosphor Icon pack](https://phosphoricons.com/) доступен для использования в панели администрирования. Эта библиотека предоставляет гибкую подборку иконок для повседневных задач.

```html
<i class="ph ph-laptop"></i>
```

При использовании в качестве определения иконки имя иконки содержит префиксы `ph` и `ph-`.

```yaml
icon: ph ph-laptop
```

## October Icons

**Набор иконок October** — это собственная библиотека с иконками разных описаний. Набор в основном используется базовыми функциями системы и может обновляться время от времени.

```html
<i class="icon-october"></i>
```

При использовании в качестве определения иконки имя иконки содержит только префикс `icon-`.

```yaml
icon: icon-october
```
