# Тип инспектора String List

Тип инспектора `stringList` позволяет вводить списки строк. Редактор открывается во всплывающем окне и отображает текстовую область. Каждая строка соответствует элементу итогового массива. Необязательный параметр `default` должен содержать массив строк.

```php
public function defineProperties()
{
    return [
        'items' => [
            'title' => 'Items',
            'type' => 'stringList',
            'default' => ['String 1', 'String 2']
        ]
    ];
}
```

Сгенерированное значение — массив строк, например:

```json
"items": ["String 1", "String 2", "String 3"]
```

Чаще всего применяются следующие [параметры конфигурации](../inspector-types.md).

Property | Description
------------- | -------------
**title** | заголовок свойства.
**description** | краткое описание свойства, необязательно.
**default** | массив по умолчанию, необязательно.
