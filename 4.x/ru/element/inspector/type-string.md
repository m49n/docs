# Тип инспектора String

Тип инспектора `string` позволяет вводить одну строку текста и отображается как обычное текстовое поле. Специфических параметров у редактора нет. Необязательный параметр `default` должен содержать строку.

```php
public function defineProperties()
{
    return [
        'firstName' => [
            'title' => 'First Name',
            'type' => 'string',
            'default' => 'John'
        ]
    ];
}
```

Сгенерированное значение — строка, например:

```json
"firstName": "Sam"
```

Чаще всего применяются следующие [параметры конфигурации](../inspector-types.md).

Property | Description
------------- | -------------
**title** | заголовок свойства.
**description** | краткое описание свойства, необязательно.
**default** | строка по умолчанию, необязательно.
**showExternalParam** | определяет видимость редактора внешнего параметра для свойства в инспекторе. Значение по умолчанию: `true`.
