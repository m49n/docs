# Настройка почты

October CMS предоставляет драйверы SMTP, Mailgun, SparkPost, Amazon SES и `sendmail`, позволяя быстро организовать отправку почты через локальный или облачный сервис.

Настроить почтовые сервисы можно двумя способами: через панель администратора (**Настройки → Почтовые настройки**) или изменив значения конфигурации в файлах. В примерах ниже рассматривается файловая конфигурация.

::: tip
Экран почтовых настроек в админ-панели переопределяет значения из конфигурационных файлов. Нажатие кнопки **Сбросить на значения по умолчанию** применяет актуальные настройки по умолчанию. Если вы не нажмёте **Сохранить** на этой форме, настройки продолжат считываться из файлов конфигурации.
:::

## Требования драйверов

В большинстве случаев можно использовать драйвер SMTP — его поддерживают почти все почтовые провайдеры. Однако драйверы на основе API зачастую проще в настройке и работают быстрее.

### Драйвер Mailgun

Чтобы использовать драйвер Mailgun, установите транспорт Symfony Mailgun Mailer через Composer.

```bash
composer require symfony/mailgun-mailer symfony/http-client
```

Затем укажите `driver` со значением `mailgun` в файле `config/mail.php`. Также убедитесь, что в файле `config/services.php` заданы следующие параметры:

```php
'mailgun' => [
    'domain' => 'your-mailgun-domain',
    'secret' => 'your-mailgun-key',
    'endpoint' => 'api.mailgun.net', // api.eu.mailgun.net для региона EU
],
```

### Драйвер Postmark

Чтобы использовать драйвер Postmark, установите транспорт Symfony Postmark Mailer через Composer.

```bash
composer require symfony/postmark-mailer symfony/http-client
```

После установки установите `default` в файле `config/mail.php` равным `postmark`. Затем убедитесь, что в файле `config/services.php` указаны следующие параметры.

```php
'postmark' => [
    'token' => env('POSTMARK_TOKEN'),
],
```

### Драйвер SES

Чтобы использовать драйвер Amazon SES, сначала установите AWS SDK for PHP. Это можно сделать через менеджер пакетов Composer.

```bash
composer require aws/aws-sdk-php
```

Затем укажите `driver` со значением `ses` в файле `config/mail.php` и проверьте, что в файле `config/services.php` присутствуют следующие параметры:

```php
'ses' => [
    'key' => 'your-ses-key',
    'secret' => 'your-ses-secret',
    'region' => 'ses-region',  // например, us-east-1
],
```

## Почта и локальная разработка

При разработке приложения, которое отправляет электронные письма, зачастую нет необходимости отправлять их на реальные адреса. Существует несколько способов «отключить» фактическую отправку сообщений.

### Драйвер Log

Один из вариантов — использовать драйвер `log` в локальной среде. В этом режиме все письма записываются в файл журнала для проверки. Подробнее о конфигурации окружений см. в разделе [Конфигурация](../setup/configuration.md).

### Универсальный получатель

Другой вариант — назначить единого получателя для всех исходящих писем. Тогда все письма, которые генерирует ваше приложение, будут приходить на указанный адрес, а не на тот, что передан при отправке. Это настраивается параметром `to` в файле `config/mail.php`:

```php
'to' => [
    'address' => 'dev@example.tld',
    'name' => 'Dev Example'
],
```

### Режим имитации отправки

Можно динамически отключить отправку почты методом `Mail::pretend`. В этом режиме сообщения записываются в журналы приложения вместо отправки получателю.

```php
Mail::pretend();
```
