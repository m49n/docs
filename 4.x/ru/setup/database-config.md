# Конфигурация базы данных

Конфигурация базы данных приложения находится в файле `config/database.php`. В нём можно определить все подключения к базам данных и указать, какое из них использовать по умолчанию. В файле представлены примеры для всех поддерживаемых систем управления базами данных.

## Конфигурация SQLite

SQLite использует один файл в файловой системе. Чтобы создать новую базу данных SQLite, выполните команду `touch`.

```bash
touch storage/database.sqlite
```

Затем настройте переменные окружения, указав абсолютный путь к файлу базы данных в переменной `DB_DATABASE`.

```text
DB_CONNECTION=sqlite
DB_DATABASE=/absolute/path/to/database.sqlite
```

## Разделение подключений для чтения и записи

Иногда требуется использовать одно подключение к базе данных для операторов SELECT и другое для операторов INSERT, UPDATE и DELETE. Независимо от того, используете ли вы сырые запросы, конструктор запросов или модель, указать разные подключения очень просто.

Посмотрим, как настроить разделение подключений на примере:

```php
'mysql' => [
    'read' => [
        'host' => '192.168.1.1',
    ],
    'write' => [
        'host' => '196.168.1.2'
    ],
    'driver'    => 'mysql',
    'database'  => 'database',
    'username'  => 'root',
    'password'  => '',
    'charset'   => 'utf8',
    'collation' => 'utf8_unicode_ci',
    'prefix'    => '',
],
```

Обратите внимание, что в конфигурационный массив добавлены два ключа: `read` и `write`. Оба содержат массив с единственным ключом `host`. Остальные параметры подключений для чтения и записи наследуются из основного массива `mysql`.

В массивы `read` и `write` нужно помещать значения только тогда, когда требуется переопределить параметр из основного массива. В приведённом примере `192.168.1.1` будет использоваться для чтения, а `192.168.1.2` — для записи. Учетные данные, префикс, кодировка и все остальные параметры из массива `mysql` будут общими для обоих подключений.

## Длина индексов в MySQL / MariaDB

По умолчанию October CMS использует кодировку `utf8mb4`. Если вы работаете с MySQL версии ниже 5.7.7 или MariaDB ниже 10.2.2, необходимо вручную ограничить длину строк по умолчанию, которую создают миграции, чтобы MySQL мог создавать индексы. Добавьте в файл **config/database.php** под ключом `connections.mysql` следующий параметр:

```php
'mysql' => [
    // ...
    'varcharmax' => 191,
],
```
