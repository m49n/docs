# Развёртывание

::: aside
Перед публикацией сайта убедитесь, что применили рекомендуемую [конфигурацию для продакшна](./configuration.md).
:::

Проекты October CMS можно развёртывать с помощью Composer при наличии доступа к командной строке (shell), а также при помощи официального плагина Deploy, если доступ к shell ограничен.

## Развёртывание с Composer

Этот сценарий подходит, если вы имеете SSH-доступ и Composer установлен на целевом сервере. Развёртывание проектов October CMS с Composer не отличается от развёртывания любого другого проекта на Composer:

* клонируйте репозиторий проекта на сервер;
* скопируйте файл `auth.json` на сервер вручную;
* выполните `composer install` в каталоге проекта;
* обновите файлы конфигурации.

Помните, что файл [auth.json](https://getcomposer.org/doc/articles/http-basic-authentication.md) из исходной установки October CMS необходимо добавить на сервер. Он создаётся автоматически при первой установке October CMS, содержит информацию о лицензионном ключе и требуется для аутентификации запросов Composer к October CMS Gateway.

При необходимости можно пересоздать файл **auth.json** командой `project:set` до запуска composer install.

```bash
php artisan project:set <license key>
```

## Развёртывание без Composer

Если у вас нет SSH-доступа к серверу или вы не можете запускать команды Composer, воспользуйтесь официальным <LinkWithIcon text="плагином Deploy" icon="https://d2f5cg397c40hu.cloudfront.net/storage/app/uploads/public/optimized/local/c99/b52/eb1c99b52eb1dde393bb7ef60e4c861b062.png" href="https://octobercms.com/plugin/rainlab-deploy" />.

<VideoBlockLink src="https://www.youtube.com/watch?v=Lx9X3CfXwfw" title="Развёртывание без Composer" description="В этом видео показывается, как развернуть проект на удалённом сервере без использования Composer." prompt="Посмотреть урок"/>

Плагин Deploy использует локальную установку October CMS, чтобы выполнить команды Composer на вашем компьютере. Сгенерированные локально файлы затем передаются на сервер. После этого в October CMS доступен обновитель в один клик, которым можно пользоваться прямо на сервере. Если обновление не удалось, плагин Deploy позволит восстановить установку без доступа к командной строке.
