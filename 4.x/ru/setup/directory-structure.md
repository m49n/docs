# Структура каталогов

October CMS использует модульную архитектуру: большинство функций находятся в каталоге modules или plugins.

## Корневой каталог

### Каталог App

Каталог `app` содержит код, специфичный для приложения. В конце раздела он будет рассмотрен подробнее. В общих чертах, здесь размещается бизнес-логика, которая не подходит для традиционных плагинов. Большинство возможностей плагинов доступно и в этом каталоге.

### Каталог Bootstrap

Каталог `bootstrap` содержит сценарий app.php, который загружает фреймворк Laravel. Здесь же находится пользовательский автозагрузчик классов PHP. Обычно файлы в этом каталоге изменять не требуется.

### Каталог Config

Каталог `config` содержит все конфигурационные файлы приложения. Каждый файл управляет поведением приложения. Конфигурацию можно менять в соответствии с требованиями проекта; системные обновления не затрагивают эти файлы.

### Каталог Plugins

Каталог `plugins` предназначен для пакетов, расширяющих базовую функциональность October CMS. Плагины могут менять работу платформы, добавляя новые возможности. По умолчанию система загружает все плагины, найденные в файловой системе. Отдельные плагины можно отключить с помощью параметра конфигурации `system.disable_plugins`.

### Каталог Storage

Каталог `storage` содержит журналы, кэши, сессии и другие файлы, которые генерирует October CMS. Он включает несколько подкаталогов:

* `app` — файлы, специфичные для приложения: медиа, загруженные пользователями файлы и автоматически генерируемые ресурсы (например, изменённые изображения и объединённые ассеты).
* `framework` — файлы и кэши, которые создаёт фреймворк Laravel.
* `cms` — файлы и кэши, генерируемые платформой October CMS.
* `logs` — журналы приложения.
* `temp` — временные файлы приложения.

### Каталог Modules

Каталог `modules` содержит основные пакеты October CMS, предоставляющие ядро функциональности. По умолчанию модули загружаются автоматически при наличии в файловой системе, но при необходимости можно указать, какие модули загружать, параметром `system.load_modules`. Для работы приложения как минимум должен быть загружен модуль `system`.

* `system` — определяет базовую функциональность October CMS и обязателен.
* `cms` — реализует рендеринг фронтенд-темы сайта. Отвечает за маршрутизацию запросов к страницам, их отображение и обработку AJAX-запросов.
* `backend` — отвечает за отображение страниц панели управления.
* `editor` — предоставляет интерфейс редактирования шаблонов CMS в панели управления.
* `media` — предоставляет интерфейс управления медиафайлами в панели управления. Позволяет загружать изображения и видео и использовать их, например, в публикациях.
* `tailor` — содержит возможности Tailor для October CMS.

### Каталог Themes

Каталог `themes` включает подкаталоги фронтенд-тем CMS. В темах находятся шаблоны страниц, макеты, партиалы, ассеты и другие файлы. Активная тема задаётся параметром конфигурации `cms.active_theme` и может быть переопределена на странице настроек в панели управления.

### Каталог Vendor

Каталог `vendor` содержит пакеты, подключённые через Composer. Некоторые плагины также могут включать собственный каталог vendor. Приоритет имеют пакеты из системного каталога vendor, а не из плагинов.

## Каталог App

Каталог `app` содержит файлы, специфичные для приложения, включая контент, ассеты и бизнес-логику, не предназначенную для [традиционного плагина](../../extend/system/plugins.md). В него входит файл поставщика служб (Service Provider), который загружается стандартной конфигурацией.

### Каталог Assets

Каталог `app/assets` содержит ресурсы — JavaScript, CSS и изображения. Этот каталог должен быть доступен публично.

### Каталог Blueprints

Каталог `app/blueprints` хранит файлы [blueprint-схем](../../cms/tailor/introduction.md), используемых Tailor.

### Другие каталоги

Вы можете создать здесь любые каталоги, как в плагине, например `models` или `controllers`. Они будут автоматически загружаться в пространстве имён `App`. Например, файл **app/models/Customer.php** будет доступен в PHP как `App\\Models\\Customer`.
