## Минимальные системные требования

Перед установкой October CMS убедитесь, что целевая система соответствует минимальным требованиям:

* PHP версии 8.0.0 или выше
* Composer 2.0 или выше
* Расширение PDO для PHP
* Расширение cURL для PHP
* Расширение OpenSSL для PHP
* Расширение Mbstring для PHP
* Расширение ZipArchive для PHP
* Расширение GD для PHP
* Расширение SimpleXML для PHP.

Поддерживаемые серверы баз данных:

* MySQL 5.7 или MariaDB 10.2. Для более старых версий MySQL или MariaDB может потребоваться [настроить длину индексов](../setup/database-config.md#oc-index-lengths-using-mysql-mariadb) для поддержки кодировки utf8mb4.
* PostgreSQL 9.6
* SQLite 3.8.8.

Поддерживаемые веб-серверы:

* Apache
* Nginx
* Lighttpd
* Microsoft IIS

## Установка October CMS

::: aside
Настройте виртуальный хост на веб-сервере, чтобы получить доступ к каталогу установки. Для локальной разработки можно использовать [Laravel Sail](../../resources/using-laravel-sail.md), [Valet](https://laravel.com/docs/valet), [Laragon](https://laragon.org/) или встроенный сервер разработки Laravel.
:::

October CMS — это веб-приложение на PHP, использующее [Composer](http://getcomposer.org/) для управления зависимостями. Перед началом установки убедитесь, что Composer установлен. Также потребуется [лицензионный ключ](https://octobercms.com/help/site/projects#project-id), чтобы завершить установку.

Чтобы установить платформу, инициализируйте проект командой `create-project` в терминале. Следующая команда создаёт новый проект в каталоге с именем *myoctober*:

```bash
composer create-project october/october myoctober
```

После завершения команды перейдите в каталог проекта:

```bash
cd myoctober
```

Запустите команду установки:

```bash
php artisan october:install
```

Последним шагом выполните команду миграции, чтобы инициализировать базу данных. В качестве альтернативы October CMS может автоматически подготовить базу данных при первом входе в панель управления.

```bash
php artisan october:migrate
```

После завершения процесса откройте панель управления в браузере и создайте учётную запись администратора. Если используется встроенный веб-сервер, его можно запустить следующей командой:

```bash
php artisan serve
```

::: warning
Если установка выполняется на боевом сервере, ознакомьтесь с рекомендациями из статьи [Конфигурация для продакшна](../setup/configuration.md#production-configuration).
:::

## Установка с мастером

<VideoBlockLink src="https://www.youtube.com/watch?v=ypyOiVCxaQg" title="Установка с мастером" description="Это видео показывает, как установить October CMS с помощью простого мастера установки." prompt="Посмотреть урок" />

Мастер установки — это альтернативный способ установки October CMS без использования Composer. Он проще командной строки и не требует специальных навыков.

1. Подготовьте пустой каталог на сервере. Это может быть подкаталог, корневая директория домена или поддомен.
1. [Скачайте архив установщика](https://octobercms.com/download).
1. Распакуйте архив в подготовленный каталог.
1. Предоставьте права на запись каталогу установки, всем его подпапкам и файлам.
1. Откройте скрипт `install.php` в браузере.
1. Следуйте инструкциям установщика.

## Устранение неполадок при установке

Ниже приведены типовые проблемы, которые могут возникнуть во время или после установки.

::: details Установка зависает после ввода лицензионного ключа
В некоторых окружениях это может произойти при вставке содержимого лицензионного ключа. Нажмите клавишу ENTER несколько раз, чтобы установка продолжилась.
:::

::: details Во время установки отображается ошибка «Unable to get local issuer certificate»
Полный текст ошибки может выглядеть как `cURL error 60: SSL certificate problem: unable to get local issuer certificate`.

Скачайте [этот файл сертификата](https://curl.se/ca/cacert.pem) и сохраните его как `cacert.pem`. Откройте файл **php.ini** и добавьте или измените следующую строку. После этого может понадобиться перезапустить Apache.
``` 
curl.cainfo = "/path/to/cacert.pem"
```
:::

::: details Во время миграции отображается ошибка «Specified key was too long»
Полный текст ошибки может выглядеть как `SQLSTATE[42000]: Syntax error or access violation: 1071 Specified key was too long; max key length is 767 bytes`

Это может произойти на старых версиях MySQL или MariaDB. [Настройка длины индексов](../setup/database-config.md#index-lengths-using-mysql-mariadb) для поддержки кодировки utf8mb4 обычно решает проблему.
:::

::: details При открытии приложения отображается пустой экран
Проверьте, что каталоги и файлы в /storage имеют корректные права доступа. Веб-сервер должен иметь возможность записи в эту директорию.
:::

::: details При входе возникает ошибка Invalid security token
Убедитесь, что в каталоге storage/framework не отсутствуют подкаталоги. Возможно, потребуется создать [каталоги sessions, cache и views](https://github.com/octobercms/october-private/tree/develop/storage/framework).
:::

::: details Панель управления показывает «Page not found» (404)
Если приложению не удаётся подключиться к базе данных, то для бэкэнда будет отображена страница 404. Попробуйте включить [режим отладки](../setup/configuration.md#debug-mode), чтобы увидеть исходное сообщение об ошибке.
:::

::: details При обновлении приложения появляется ошибка 500
Необходимо увеличить или отключить таймаут веб-сервера. Например, у Apache FastCGI параметр -idle-timeout иногда установлен в 30 секунд.
:::

::: details Zend OPcache API ограничен директивой конфигурации «restrict_api»
Проблема возникает, когда внутренние компоненты пытаются использовать функции OPcache. Отключите её, установив параметр **force_bytecode_invalidation** в значение `false` в файле **config/cms.php**.
:::

::: details Invalid credentials (HTTP 403) for '...', aborting.
Эта ошибка возникает в Composer, когда на сервере отсутствует файл **auth.json** или срок действия лицензии проекта истёк. Авторизуйтесь в своей учётной записи и убедитесь, что у проекта есть активная лицензия. Если лицензия активна, восстановите её командой `project:set`.
:::
