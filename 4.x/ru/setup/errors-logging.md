# Ошибки и журналирование

При первой установке October CMS обработка ошибок и исключений уже настроена. Существует два способа получить доступ к журналу событий:

1. Посмотреть журнал событий в файловой системе, открыв файл `storage/logs/system.log`.
1. Или просмотреть его через панель управления: **Настройки → Журнал событий**.

Записи журнала создаются всегда при отображении страницы ошибки и для некоторых [типов исключений](../../extend/system/exceptions.md).

## Конфигурация

#### Детализация ошибок

Объём сведений об ошибках, отображаемых в браузере, контролируется параметром `debug` в файле `config/app.php`. По умолчанию подробные сообщения включены, чтобы упростить отладку и поиск проблем. Если выключить эту функцию, при возникновении ошибки будет показано общее сообщение.

Для локальной разработки установите значение `debug` в `true`. На продакшне это значение всегда должно быть `false`.

```php
/*
|--------------------------------------------------------------------------
| Application Debug Mode
|--------------------------------------------------------------------------
|
| When your application is in debug mode, detailed error messages with
| stack traces will be shown on every error that occurs within your
| application. If disabled, a simple generic error page is shown.
|
*/

'debug' => false,
```

#### Режимы журналирования

October CMS поддерживает различные драйверы журналирования: `single`, `daily`, `syslog` и `errorlog`. Например, чтобы использовать отдельный файл на каждый день вместо одного общего файла, установите значение `default` в файле `config/logging.php`:

```php
'default' => env('LOG_CHANNEL', 'daily'),
```
